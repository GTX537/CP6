## 二、单个生产单元的标准作业流程（每个单元都这样做）

```
① 深挖真实代码  → 并行 agent 读 views/子组件/api/Controller/Service/Entity/DTO/Enum + codemap
② 按模板撰写    → A 总册 / B 单页SOP 对应模板，不复制原文、改写成业务可照做
③ 自检          → 节数齐 / SOP数达标 / 用例数达标 / 无占位符 / Mermaid 可渲染
④ 诚实标注      → 待业务确认 / 待实现 / 代码未发现 / 代码现状与文档差异
⑤ 交付并停      → 输出"文件路径+行数+SOP数+用例数+待确认项"，等用户验收再下一单元
```

**质量门禁 checklist（每单元交付前过一遍）**
- [ ] 结构节数与模板一致（B=16 节 / A=0~13+7.1）
- [ ] SOP 场景数达标（B≥5；A 各页按总册既定数量）
- [ ] 测试用例数达标（B≥25；A §7.1≥10）
- [ ] 每个字段有"怎么填/谁提供/填错影响/测试关注点"；每个按钮有"点后动作/是否影响状态·库存·生产·财务·下游"
- [ ] 完成后检查点含**下游验证**（受注类页面必含 MES/WMS/注文追溯三处）
- [ ] 所有不确定项已标注，未编造
- [ ] §15/§16 溯源到真实路径
- [ ] 无 `PLACEHOLDER`/`续写中` 残留
