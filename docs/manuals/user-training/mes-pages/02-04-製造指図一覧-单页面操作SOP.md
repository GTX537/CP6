# 製造指図一覧 单页面操作 SOP（手把手版）

> **用途**：给**计划员/现场/管理操作、培训老师讲、测试人员拆用例**。对应模块总册（`02-生产管理MES` §5.4）。
> **页面**：製造指図一覧（MSBBME030 · 生产管理 MES）　**路由**：`/mes/work-order-list`　**前端**：`views/mes/WorkOrderListView.vue`　**API**：`api/mes/mes.ts workOrderApi.search/delete`　**后端**：`Mes/WorkOrderController.Search` → `WorkOrderService.SearchAsync`
> **基准**：分支 `feat/wfs-inbox-core`，2026-06-28；后端实测 `docs/codemap-mes/01-製造指図-workorder.md`，UI 经 agent 实读 view。
> **样例数据**：拠点 `BASE01`、製品 `PRD2026070001`、指図 `WO2026070001`、纳期 2026-07-10。

---

## 1. 页面一句话说明

**製造指図一覧，就是製造指図的台账与检索入口——按拠点/指図NO/製品/纳期/状态/遅延等条件查工单，看进度率、遅延天数、完了/工程进度，并跳到详情或实绩录入，还能删除未发行的工单、导出 CSV。** 它是计划员掌握"现在有哪些工单、做到哪了、哪些拖期"的窗口。

---

## 2. 这个页面在业务流程中的位置

```mermaid
flowchart LR
  WOE["製造指図入力"] -->|保存/发行| LIST["製造指図一覧<br/>(本页)"]
  LIST -->|詳細| WOE
  LIST -->|実績| PR["製造実績入力"]
  LIST -->|削除(仅≤1)| DEL["软删"]
```

- **上游**：製造指図入力（建/发行后在此可查）。
- **本页**：检索/监看/跳转/删除。
- **下游**：跳 製造指図入力（詳細）、製造実績入力（実績）。

## 6. 字段填写说明（检索条件）

| 条件 | 控件 | 说明 |
|---|---|---|
| 拠点CD | 输入框 | 如 `BASE01` |
| 指図NO | 输入框 | 占位 WOyyyyMMdd-NNNN（实际月级） |
| 手配NO | 输入框 | 命中 手配NO1/2/3 或 受注Web NO 任一 |
| 製品CD / 得意先CD | 输入框 | — |
| 納期 From-To / 計画開始 From-To | 日期 | 区间 |
| 優先度 | 下拉(可清) | 通常/急ぎ/特急 |
| 工程CD / WG | 输入框 | 走工程子表反查 |
| ステータス | **复选组(多选)** | 下書き/確定済/発行済/着手中/完了/中断中/検査済/取消 |
| 遅延のみ | 复选 | =PlanEndDate<today && Status∉{完了4,検査済6,取消9} |

## 7. 按钮操作说明

| 按钮 | 点了会怎样 | 影响 |
|---|---|---|
| 検索 | 按条件查询 | 否 |
| クリア | 重置条件并重查 | 否 |
| 新規作成 | 跳 `/mes/work-order`（新建） | 否 |
| CSV出力 | 导出当前结果（空结果 warning「検索結果がありません」） | 否 |
| 詳細（行） | 跳 `/mes/work-order?no=` | 否 |
| 実績（行） | 跳 `/mes/production-result?no=` | 否 |
| 削除（行） | 确认→软删→重查（仅 `status≤1` 显示） | **软删** |

## 8. 标准业务操作 SOP（照着点）

### 场景一：按条件检索工单（主流程）
- **背景**：计划员查某拠点/製品的工单。
- **样例数据**：拠点 `BASE01`、製品 `PRD2026070001`。
- **步骤**：填拠点+製品CD→検索→看结果（合计件数+进度率）。
- **检查**：命中行的 製品/状态/进度率/纳期正确。
- **用例**：TC-M05-WOLIST-002~004。

### 场景二：只看遅延工单
- **背景**：盯拖期工单。
- **步骤**：勾「遅延のみ」→検索。
- **检查**：结果均为 PlanEndDate<today 且未完了/検査済/取消；遅延天数列标红。
- **用例**：TC-M05-WOLIST-005、006。

### 场景三：按状态多选过滤
- **步骤**：ステータス 勾 発行済+着手中→検索。
- **检查**：仅这两类状态出现（tag 着色）。
- **用例**：TC-M05-WOLIST-007。

### 场景四：跳详情/实绩
- **步骤**：行「詳細」→製造指図入力；行「実績」→製造実績入力（带 `?no=`）。
- **检查**：正确带号跳转、载入该工单。
- **用例**：TC-M05-WOLIST-008、009。

### 场景五：删除未发行工单
- **背景**：建错的下書き/確定済要删。
- **步骤**：找 status≤1 的行→「削除」→确认。
- **检查**：软删消失；status≥2 行无删除按钮。
- **用例**：TC-M05-WOLIST-010、011。

### 场景六：CSV 导出
- **步骤**：检索出结果→CSV出力。
- **检查**：内容=当前查询结果（全件）；空结果 warning。
- **用例**：TC-M05-WOLIST-012。

---

## 9. 状态变化说明

本页不改业务状态（仅删除软删）。列以 tag 显示工单状态（见总册 §4 状态机 0~9）；进度率=完成工程/总工程；遅延=PlanEndDate 超期且未收尾。

---

## 10. 按钮不可用 / 灰色原因

| 现象 | 原因 |
|---|---|
| 行无「削除」 | status≥2（已发行不可删） |
| CSV 提示无结果 | 当前查询 0 件 |

---

## 11. 常见错误与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 查不到工单 | 条件太严/状态没勾 | 放宽条件、勾对状态 |
| 已发行单找不到删除 | status≥2 | 已发行不可删（设计） |
| 手配NO 查不准 | 它命中 NO1/2/3 或受注WebNO | 确认填的号 |

## 12. 操作完成后的检查清单

- [ ] 删除后列表消失（软删，DB IsDeleted=true，物理保留）。
- [ ] CSV 内容=当前查询结果。
