# 達成率 单页面操作 SOP（手把手版）

> **用途**：给**生产管理/主管查阅、培训老师讲、测试人员拆用例**。对应模块总册（`02-生产管理MES` §5.14）。
> **页面**：達成率（ME 分析 · 生产管理 MES）　**路由**：`/mes/plan-achievement`　**前端**：`views/mes/PlanAchievementView.vue`　**API**：`api/mes/planAchievement.ts`　**后端**：`Mes/PlanAchievementController` → `PlanAchievementService`
> **基准**：分支 `feat/wfs-inbox-core`，2026-06-28；后端实测 `docs/codemap-mes/05-計画板-主数据-分析.md §四`，UI 经 agent 实读 view。
> **样例数据**：近 90 天、按制品分组、onlyCompleted=on。

---

## 1. 页面一句话说明

**達成率，就是按 制品/月/客户 维度看"计划做了多少、实际做出多少良品"的达成率分析报表——达成率=Σ良品/Σ计划数量，配 KPI 卡、横向条形对比、明细表，可导出 CSV。纯只读分析（用 POST body 查询）。** 帮管理识别哪些制品/客户/月份达成不佳。

## 6. 字段填写说明（筛选）

| 字段 | 怎么填 | 说明 |
|---|---|---|
| dateFrom/dateTo | 日期 | 默认 今天-90 ~ 今天 |
| groupBy | radio | product/month/customer（默认 product） |
| 制品CD | 输入框(回车查) | 过滤制品 |
| onlyCompleted | 开关(默认 on) | on=只取完了/検査済；off=Status≥発行 |

> ⚠️ 类型里有 customerCd，但**模板未渲染客户输入框**（客户筛选仅靠 groupBy=customer）——客户CD 输入控件 `代码未发现`。

## 8. 标准业务操作 SOP（照着点）

### 场景一：按制品看达成率（主流程）
- **步骤**：groupBy=product→検索。
- **检查**：KPI 总达成率/达标数；条形+明细按达成率**升序**（要改善在上）。
- **用例**：TC-M05-ACH-002、003。

### 场景二：按月/客户分组
- **步骤**：groupBy 切 month/customer→検索。
- **检查**：分组键变（月 yyyyMM / 客户）。
- **用例**：TC-M05-ACH-004、005。

### 场景三：理解达成率口径②
- **检查**：达成率=Σ良品(CompletedQty)/Σ计划(ProductionQty)；不良率=不良/(良+不良)；达标数=Good≥Planned 的组数。
- **用例**：TC-M05-ACH-006~008。

### 场景四：onlyCompleted 过滤
- **步骤**：切 onlyCompleted on/off。
- **检查**：on 只取完了/検査済；off 取 Status≥発行。
- **用例**：TC-M05-ACH-009。

### 场景五：CSV 导出
- **步骤**：検索→CSV导出。
- **检查**：下载 `plan-achievement_{今日}.csv`，内容=当前汇总。
- **用例**：TC-M05-ACH-010。

## 11. 常见错误与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 找不到客户筛选框 | 未渲染 | 用 groupBy=customer |
| 达成率与预期不符 | 口径=Σ良品/Σ计划 + onlyCompleted | 核对过滤 |
| 数据不刷新 | 无自动刷新 | 手动刷新/查询 |
