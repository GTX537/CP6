# CP6 用户操作手册 · 页面盘点表（测试用例 / UAT / 自测 / 培训基线）

> **用途**：本表是「最详细用户操作培训手册」的总索引与拆分基线，供 ①业务培训 ②开发自测对照 ③测试用例拆分 ④我方验收 四类场景共用。
> **生成方式**：基于真实代码盘点——前端路由 `cp6.web/src/router/index.ts`（route→view 权威映射）+ 全部 view 文件（含代码行数甄别 stub）+ `CP6.WebApi/Controllers/**` + `CP6.Core/Services/**` + `CP6.Entity/DomainModels/**` + `cp6.web/src/api/**`。
> **基准快照**：分支 `feat/wfs-inbox-core`，2026-06-28。
> **诚实标注规则**：代码确有=具体填写；查不到=`待确认`；功能未写=`待实现`；仅前端/仅后端单边=`仅前端`/`仅后端`；仅设计文档=`仅设计文档`；代码里没有该字段=`代码未发现`。

## 0. 阅读说明（务必先读）

1. **页面口径**：本表的「页面」= 路由表 `viewModules` 中可路由的视图 + 登录/改密/2FA/SSO 等静态路由页。向导子步骤（`erp/order/Step*`、`erp/bp/*Tab`、`mes/work-order/steps/*` 等）是页面内部组件，不单列为页面，集中见 §附录 A。
2. **「菜单名称」列**：CP6 菜单为**数据驱动**（落 `Sys_Menu` 表 + 种子 SQL，未在本次代码盘点范围内逐条读取）。本列名称由路由注释与页面用途**推断**，统一视为 `待确认（以 Sys_Menu 种子为准）`。
3. **「主要DTO」列**：CP6 DTO 命名稳定遵循 `{实体}Dto` / `{实体}QueryDto` / `{实体}ListItemDto` 约定（已在 ERP 受注实测验证）。除已实测页面外，本列按约定推断并标 `(约定推断)`；未读取确认者标 `待确认`。
4. **「当前实现状态」判据**：view + Controller + Service 三者俱全且 view 行数充实（>100 行）= `已实现`；某子能力缺位 = `部分实现`；只有一侧 = `仅前端`/`仅后端`；只有迁移/实体无 API/UI = `仅设计文档/数据模型`。
5. **状态图例**：✅已实现　🟡部分实现　🟠仅数据模型/设计　🔲待实现。
