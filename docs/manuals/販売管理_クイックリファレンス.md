# 销售管理快速参考

## 1. 常用业务顺序

`交易先 -> 报价计算 -> 正式报价 -> 产品 -> 受注 -> 单价修正`

## 2. 模块速查

| 编号 | 功能 | 关键动作 |
|---|---|---|
| PA110 | 交易先主数据 | 新建客户/供应商 |
| PA010 | 报价计算单 | 录基础资料、工序、计算结果 |
| PA030 | 正式报价单 | 关联报价计算单，生成正式报价 |
| PA050 | 产品主数据 | 建产品、工序、材料、批量价格 |
| PA070 | 受注输入 | 建立订单与明细 |
| PA090 | 单价修正 | 批量改单价并送审 |
| PA100 | FSC检查清单 | 选择格式并发行 |
| PA130 | 纸板单价 | Excel 导入或查看 |
| PA140 | 版型/木型 | 建立或改定 Rev |

## 3. 关键必填

| 页面 | 必填重点 |
|---|---|
| 交易先 | 交易先CD、名称、拠点、至少1个属性标志 |
| 报价计算单 | 拠点、担当、客户、数量、客户品名1 |
| 正式报价单 | 拠点、担当、客户 |
| 产品主数据 | 客户CD、客户品名、套装比率 |
| 受注输入 | 客户CD、受注区分、至少1条明细、产品CD |
| FSC | 拠点、输出格式 |
| 纸板单价 | 基准日、拠点、Excel文件 |
| 版型/木型 | 拠点、决定报价NO、版型名、适用开始日 |

## 4. 常见按钮

| 按钮 | 含义 |
|---|---|
| 读取 | 按编号载入 |
| 新建 | 清空当前画面 |
| 保存/登记 | 写入数据 |
| 删除执行 | 删除当前记录 |
| 导入 | 从上游数据或 Excel 带入 |
| 发行 | 输出报表/标签 |

## 5. 常见异常

| 情况 | 处理 |
|---|---|
| 提示必填未录入 | 返回当前步骤补齐 |
| 提示数据已更新 | 重新读取后再保存 |
| 检索不到数据 | 放宽条件重新查询 |
| Excel 导入失败 | 检查模板列和主数据 |

## 6. 培训时最推荐演示的 5 个功能

1. 新建交易先
2. 新建报价计算单
3. 生成正式报价单
4. 建立产品并受注
5. 单价修正与审批
