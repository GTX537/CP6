## ① 多角色聚合 + 请求级缓存

**`PermissionAggregator.BuildAsync(userId)`**（`PermissionAggregator.cs:16-50`）：取用户(无→`E-PUB-404`)→取全部角色(附加 ∪ 主，去重 `:53-62`)→填四粒度：
```csharp
ctx.MenuKeys = Sys_RoleMenus.Where(roleIds.Contains).Join(Sys_Menus, ...).Select(m=>m.MenuKey).ToHashSet();
await FillActionKeysAsync(ctx, roleIds);   // 操作并集："menuKey:actionCode"
await FillDataScopesAsync(ctx, roleIds);   // 数据最宽：g.Max(x=>x.ScopeType)
await FillFieldPermsAsync(ctx, roleIds);   // 字段最可见：fg.Min(x=>x.Access)  ← 1可读写<2只读<3隐藏
```
> ⚠️ **数据取 MAX(最宽)、字段取 MIN(最可见)，方向相反**——易错点（`:83`/`:105`）。
**`CurrentPermissionContext.GetAsync`**（`CurrentPermissionContext.cs:27-39`）：`HttpContext.User.Identity.Name`→`IMemoryCache.GetOrCreateAsync(perm-ctx:{uid}, SlidingExpiration=30min, BuildAsync)`。`Invalidate(uid)` 单用户失效(改角色调)；`InvalidateByRole(roleId)`(`:50-57`)该角色全部用户失效(角色权限改调)。注释：`IMemoryCache 单机，多实例改 Redis`。

## ③ 操作粒度 — [RequirePermission] + v-permission

**后端** `RequirePermissionAttribute`（`Auth/RequirePermissionAttribute.cs`，`IAsyncAuthorizationFilter`，`RequestServices` 取 `IPermissionService`）：
```csharp
if (!await svc.HasActionAsync(_menu, _action))
    context.Result = new ObjectResult(new { code = 403, message = $"无权限：{_menu}:{_action}" }) { StatusCode = 403 };
```

## ④ 数据粒度 — DataScopeFilter 五范围

**`DataScopeFilter.Apply<T>`**（`DataScopeFilter.cs:12-37`，`T:IDataScoped`=Creator+DeptId）：
```csharp
var scope = ctx.DataScopes.TryGetValue(resource, out var s) ? s : DataScopeRegistry.DefaultScope(resource);
switch (scope) {
    case 5: return query;                                          // 全部
    case 2: return query.Where(x => x.DeptId == ctx.DeptId);       // 本部门
    case 3: return query.Where(x => x.DeptId != null && _db.Sys_Depts.Any(d => d.Id==x.DeptId && d.Path.StartsWith(ctx.DeptPath)));  // 及下级(物化路径)
    case 4: return query.Where(x => x.DeptId != null && ids.Contains(x.DeptId.Value));  // 自定义部门
    case 1: default: return query.Where(x => x.Creator == ctx.UserName);  // 本人(未配置/未知回落,最严)
}
```
默认范围 `Program.cs:217-218`：`order`默认2(本部门)、`product`默认5(全部)。调用点 `BaseCrudService.QueryAsync`(`:43-44`)自动注入。
**配置** `PUT /api/pub/role-perm/data-scope/{roleId}`→`SaveRoleDataScopesAsync`(`:131-159`)：范围须被资源支持(`E-PUB-031`)；Type4 须选部门(`E-PUB-032`)；自定义部门存 CSV；`InvalidateByRole`。

## ⑤ 字段粒度 — [FieldMask] 脱敏 + 拒写

**掩码(隐藏)** `FieldMaskAttribute`（`Auth/FieldMaskAttribute.cs:20-28`，`IAsyncResultFilter`）序列化前调 `IFieldPermService.MaskHiddenAsync`。`MaskHiddenAsync`(`FieldPermService.cs:18-38`)取 Access==3 字段反射置空(引用/可空→null，非可空值→default)。⚠️ **对 `{code,message,data}` 匿名信封无效**(无法写匿名属性)，注释自承；`BaseCrudController.Query` 直返 `Ok(new {rows,total})`，rows 元素为实体(非匿名)可写入。
**只读拒写** `StripReadOnly`(`:40-54`)取 Access≥2(只读2+隐藏3)字段，用 original 原值覆盖 incoming(拒写)。调用点 `BaseCrudService.UpdateAsync`(`:79`)。前端 `GET /my-readonly/{resourceKey}` 返 Access==2 字段置灰。
**配置** `PUT /api/pub/role-perm/field-perm/{roleId}`→`SaveRoleFieldPermsAsync`(`:186-212`)：字段须 ∈ 注册表(`E-PUB-041`)；**仅替换本次涉及资源**(防误删)；**可读写(1)=默认不落库**(`items.Where(Access != 1)`)；`InvalidateByRole`。资源/字段 `Program.cs:220-222`(`order` 含 `UnitPrice/Amount`)。

## 组织 — 部门 DeptService（物化路径）

**`MoveAsync`**（`DeptService.cs:63-91`，物化路径 `/{rootId}/.../{selfId}/`）：防成环 `if (np.Path.StartsWith(dept.Path)) throw E-PUB-004`；子树整体平移 `s.Path = newPrefix + s.Path.Substring(oldPrefix.Length)`。`CreateAsync`(DeptCode 唯一 `E-PUB-001`，`Path=$"{parentPath}{id}/"`)；`DeleteAsync`(有子部门 `E-PUB-002`/有在职用户 `E-PUB-003`)；`UpdateAsync`(DeptCode 只读)；`TreeAsync`(内存拼树+回填 LeaderName)。**物化路径是数据范围"及下级"(范围3)的查询基座**。
**用户-角色分配** `UserRoleService.SaveAsync`(`:35-65`)：主角色须 ∈ roleIds(`E-PUB-011`)；用户不存在(`E-PUB-404`)；diff `Sys_UserRoles`+写 `user.RoleId`；`Invalidate(userId)`。

## 错误码（grep 真搜，仅 `E-PUB-xxx`）
`E-PUB-001`(部门编码已存在/不存在) `002`(有子部门) `003`(有在职用户) `004`(移动成环) `011`(主角色须∈集合) `021`(操作点须属已授菜单) `031`(范围不被资源支持) `032`(自定义须选部门) `041`(字段不在注册表) `051`(未配置采番规则) `061`(附件超大) `062`(类型不许) `063`(无权访问附件403) `071`(导入必填列对不上) `404`(用户/附件不存在)。**未发现** `E-SYS-`/裸 `PUB-`。

## 关键发现
1. **手写控制器全只 `[Authorize]`**，操作强校验仅 CodeGen 产出的 `BaseCrudController` 子类承载。
2. **字段取 MIN(最可见)、数据取 MAX(最宽)**，方向相反——易错点。
3. **`[FieldMask]` 对 `{code,message,data}` 匿名信封无效**(代码注释自承)；`BaseCrudController.Query` 直返 `{rows,total}` 才可掩码 rows。
4. **数据范围3(及下级)依赖 DeptService 物化路径 Path**——组织与数据粒度的耦合接缝。
