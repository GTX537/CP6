# 业务域说明

## 销售 ERP

取引先 → 見積計算 → 御見積 → 製品マスタ → 受注 → 出荷回写。另含单价订正、FSC、版型木型、信用单、Backorder、OTD 和汇率。代码级说明位于 `docs/codemap-erp`。

## 制造 MES

生产计划 → 製造指図 → 製造実績 → 品质/不良 → 设备/OEE。与 ERP 订单及 WMS 材料、成品库存联动。代码级说明位于 `docs/codemap-mes`。

## 仓储 WMS

仓库/库位、库存、入库、出库、拣选、包装出货、盘点、补充、QC、期限和批次追溯。纸器行业扩展包括原纸、残材、油墨、版型、托盘、样品、VMI、WCS/IoT 等。库存台账是不变量核心，详见 `docs/codemap-wms/01-库存核心-铁律.md`。

## 财务 FIN

总账、期间关账、AP/AR、自动凭证、成本、三表、多币种、固定资产、预算和银行对账。领域设计在 `docs/finance`，代码导航在 `docs/codemap-fin`。

## 采购 PUR

供应商、采购申请、RFQ、PO、收货、三单匹配、外注和采购对账。详见 `docs/procurement` 与 `docs/codemap-pur`。

## OA / WF

电子表单、流程定义、待办信箱、审批、加签/退回/撤回/转办/委派、通知、定时器、服务任务、子流程和触发器。WF 是状态机内核；归属校验已下沉引擎，不能以 admin 身份绕过本人/委派规则。

## PUB / SYS / PLAN

- SYS：用户、角色、菜单、部门、字典、多语言、认证与操作日志。
- PUB：权限公共能力、附件、采番、导入导出、代码生成。
- PLAN：MRP 和物料计划策略；部分生成采购申请能力仍存在桩/接线边界，修改前读最新计划和测试。

## Space 3D

空间建模、编辑器、发布、查看器、库存覆盖、多楼层、路径查找与通行成本。设计真相集中在 `docs/space` 和对应 superpowers specs/plans。

## Integration

负责 ERP→MES→WMS 等跨域闭环、集成事件、健康状态及外部系统连接。新增跨模块动作应遵循 `docs/00-横切接线规范.md`。

## 用户手册

`docs/manuals/user-training` 有销售、MES、WMS、采购和财务的模块手册及大量单页 SOP，适合验证页面是否符合业务，而非作为代码实现的唯一事实源。
