# 销售管理 i18n 迁移指南

## 1. 背景

销售管理 15 个页面里有约 500+ 处硬编码日文字符串。需要逐步抽取为 i18n key 实现 5 语言切换（zh-CN/zh-TW/en/ja/ko）。

## 3. 迁移步骤（每个 Vue 文件）

### Step 1: 引入 i18n

如果文件还没引入 `useI18n`：

```ts
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
// ... 已有代码
</script>
```

### Step 2: 替换 template 中的硬编码字符串

**改动前：**
```vue
<el-button>登録</el-button>
<el-form-item label="拠点">...</el-form-item>
<el-divider>基本情報</el-divider>
<el-tag>承認待ち</el-tag>
```

**改动后：**
```vue
<el-button>{{ t('sales.btn.register') }}</el-button>
<el-form-item :label="t('sales.term.base')">...</el-form-item>
<el-divider>{{ t('sales.section.basicInfo') }}</el-divider>
<el-tag>{{ t('sales.status.pendingApproval') }}</el-tag>
```

### Step 3: 替换 script 中的字符串（消息提示）

**改动前：**
```ts
ElMessage.error('必須項目に値が指定されていません')
```

**改动后：**
```ts
ElMessage.error(t('sales.err.E10022'))
```

## 6. 测试方法

完成迁移后：
1. 在 PowerShell 终端按 `Ctrl+C` 停止 Vite，重新 `npm run dev`
2. 浏览器 `Ctrl+F5` 强制刷新
3. 右上角语言下拉切换 → 简体中文 / 日本語 / English
4. 切换菜单和按钮文字，确认翻译生效

## 7. 后续扩展

需要新关键字时，编辑 `D:\CP6\CP6.WebApi\Program.cs`：
- 在「販売管理 通用 i18n」块的 `AddRange(...)` 中添加 `new Sys_Lang { LangKey = "sales.xxx.yyy", ... }`
- 重启后端 → 关键字立即可用
