## 一、⭐ 成本归集（料工费真实计算）— POST /api/fin/cost/{workOrderNo}/collect

**前端**：`CostSheetView.vue`「归集成本」→`doCollect`(`:170-177`)→`costApi.collect(workOrderNo, laborStd, overheadStd)`。
**后端**：Controller `[RequirePermission("fin-cost","collect")]`→`CostCollectService.CollectAsync`：
1. 工单不存在`E-FIN-401`/成本单已结转`E-FIN-402`。
2. **料(MES真实消耗×BOM单价)**(`:45-71`)：单价字典按 `(ProcessCd,MaterialCd)` 取 `ProductMaterial.SupplyPrice`；逐料 `actualAmt = Round(m.ActualQty * price, 2)`(料实际=MES真实消耗)、`stdAmt = Round(PlanQty * price, 2)`(料标准=计划用量)。
3. **工费(工时×费率,跨模块吃 MES `ProcessCostRate`)**(`:72-132`)：基准日 `wo.ActualEndDate ?? PlanStartDate ?? CreateDate`；逐工序：
```csharp
var stdMachine = (pp?.SetupHour ?? 0m) + calcQty * (pp?.CycleTime ?? 0m);   // 标准机时
var stdLabor = stdMachine * (pp?.StandardCrewSize ?? 1m);                   // 标准人工工时
var rate = await _rateSvc.ResolveAsync(w.WgCd ?? "", baseDate);            // MES 费率(无→E-A2-RATE-002 strict 或整单回退)
var actMachine = w.ActualMachineHour ?? stdMachine;
var actLabor = w.ActualLaborHour ?? stdLabor;
var laborActLine = Round(actLabor * rate.LaborRate, 2);                    // 人工实际=实人工工时×LaborRate
var ohActLine = Round(actMachine * rate.OverheadRate, 2);                  // 制费实际=实机时×OverheadRate
```
4. **双模式回退** `StrictCostRate`(默认 false 迁移模式;true 生产/TDD 缺工序`E-A2-COST-001`/缺费率`E-A2-RATE-002`),回退打 `W-A2-COST-002`。
5. 落库 `Status=Collected`;计算属性 `TotalActual=料+工+费`、`Variance=TotalActual-StandardCost`、`FgUnitCost=Round(TotalActual/CompletedQty,4)`。
> 传入的 `laborStd/overheadStd` 仅作迁移模式缺工序/费率时的整单回退值。料工费非纯标准估算。
**错误码**：`E-FIN-401/402`、`E-A2-COST-001`、`E-A2-RATE-002`、`W-A2-COST-001/002`。

## 三、资产负债表（复用试算表期末余额）— GET /api/fin/report/balance-sheet/{periodId}

**后端**：`BalanceSheetService.BuildAsync`(`:25-55`)★复用试算表：
```csharp
var tb = await _trial.BuildAsync(periodId);   // 复用三栏试算表(含 E-FIN-140)
foreach (row in tb.Rows) switch (acc.Type) {
    case Asset: if(row.CloseBal!=0) Assets.Add(Code,Name,row.CloseBal); break;     // 用期末余额(带号)
    case Liability: ...; case Equity: ...;
    case Revenue: revenue += row.CloseBal; break;   // 收入费用不进表,转本年利润
    case Expense: expense += row.CloseBal; break;
}
CurrentProfit = revenue - expense;                              // 本年利润
TotalEquity = Equity.Sum + CurrentProfit;                       // 并入权益侧
IsBalanced = TotalAssets == TotalLiabEquity;                    // 恒平(源于借贷恒等)
```
> 报表无独立存储,永远与总账一致。期间不存在 `E-FIN-140`(试算表抛)。

## 四、损益表（复用试算表本期发生）— GET /api/fin/report/income-statement/{periodId}

**后端**：`IncomeStatementService.BuildAsync`(`:31-61`)★复用试算表【本期发生】区间：
```csharp
if (acc.Type == Revenue) { var amt = row.PeriodCredit - row.PeriodDebit; Revenue += amt; }   // 收入:本期贷方净发生
else if (acc.Type == Expense) {
    var amt = row.PeriodDebit - row.PeriodCredit;
    if (acc.Role == "COGS") Cost += amt; else OperatingExpense += amt;   // 费用按Role拆主营成本vs营业费用
}
GrossProfit = Revenue - Cost; NetProfit = GrossProfit - OperatingExpense;
```
> 与资产负债表关键差异：损益表用 `PeriodDebit/Credit`(本期区间发生额),非期末时点余额。

## 五、⭐ 银行对账·自动撮合引擎 — POST /api/fin/bank-recon/{statementId}/auto-match

**前端**：`BankReconciliationView.vue` 撮合工作台(左流水/右候选/调节表),`doAutoMatch`(`:220-234`)。
**后端**：`BankReconService.AutoMatchAsync`(`:80-141`)三阶撮合：守卫(流水单不存在`E-A4-MATCH-004`/非Open`E-A4-STATEMENT-LOCKED`)→候选载入(命中银行GL、Posted、非Reversal、窗口90天、未被占用)→
- **Phase1+2(1:1 与 1:N 子集和)**(`:96-117`)：每条流水取同号同方向候选池(按日期差排序 Take20)→`FindSubsetSums(pool, line.SignedAmount, K=8)`,**唯一解才自动撮合**(`solutions.Count==1`)。
- **Phase2b(N:1)**(`:120-138`)：每候选在未匹配流水池找唯一 size≥2 子集和。
- 子集和算法(`:143-163`)：有界 DFS,`current.Count>k` 剪枝,`solutions.Count>1` 早停(只判唯一性)。
落库 `PersistMatchAsync`(建 `BankReconMatch`+每候选 `BankReconJournalLink`,流水行 Matched)。候选排序 `Rank = |日期差| + (金额相等?0:100000)`。
**人工撮合** `ManualMatchAsync`(`:223-285`)：金额校验 `stmtSum != bookSum`→`E-A4-MATCH-001`;RowVersion 乐观锁`E-A4-CONCURRENCY-001`;凭证行已占用`E-A4-MATCH-002`。`UnmatchAsync`(删 Link+Match,流水复位,不自动删自动凭证走反冲)。

## 六、⭐ 银行对账·双向调节表 + 锁定 — GET .../reconciliation-statement + POST .../lock

**后端**：`GetReconciliationStatementAsync`(`:409-469`)双向调节表公式：
```csharp
StatementInternalDiff = Opening + ΣDeposit - ΣWithdrawal - Closing;   // 流水内部差
// 账面单边项(未占用银行GL凭证行):signed>0→BookOnlyDepositInTransit(在途存款);signed<0→BookOnlyOutstandingPayment(未取付支票)
// 银行单边项(流水MarkedPending):Deposit→BankOnlyDepositNotBooked;Withdrawal→BankOnlyWithdrawalNotBooked
BankAdjustedBalance = ClosingBalance + BookOnlyDepositInTransit - BookOnlyOutstandingPayment;
BookAdjustedBalance = GlBankEndingBalance + BankOnlyDepositNotBooked - BankOnlyWithdrawalNotBooked;
ReconciledDiff = BankAdjustedBalance - BookAdjustedBalance;   // =0 即对平
```
**锁定** `LockAsync`(`:471-518`)：实时重算后五重校验(`StatementInternalDiff!=0`→`E-A4-RECON-001`/`ReconciledDiff!=0`→`E-A4-RECON-001`/每组Σ流水==Σ银行侧/期间已结账`E-A4-RECON-002`)全过才写快照 `Status=Locked`+`LockSnapshotJson`。`UnlockAsync`(reason 空`E-A4-RECON-003`/已结账`E-A4-RECON-002`)。
**生成单边凭证** `GenerateBankOnlyVoucherAsync`(`:308-386`)：按方向建分录(Withdrawal 借对方/贷银行;Deposit 借银行/贷对方,`Source=BankRecon`)→`AutoPostAsync`,幂等`E-A4-BANKONLY-DUP`。**标记未达** `MarkPendingAsync`(`category=4 Pending`)。

## 九、汇兑重估 FxRevaluation（reversing 法,由结账触发,无独立前端/控制器）

**驱动**：`PeriodCloseService.CloseAsync`(`:76-81`)结账时调(折旧之后、置 Closed 之前)。`FxRevaluationService.RevalueAsync`(`:32-141`)reversing 双凭证：幂等(`docNo=FXREVAL-{年月}` 已存在 Pass)→AP/AR 未结外币 `DeltaAsync`(book→market 变化,`delta = market - book = origOpen*(endRate - frozenRate)`)→损益分录(负债增→贷应付/`FX_LOSS`;资产增→借应收/`FX_GAIN`)→**①重估凭证**(期末,`Source=FxReval`)+**②冲回凭证**(期末+1天,借贷对调)。两张全期累计净额零,子账↔GL 勾稽不受影响,仅落本期未实现汇兑损益。本位币不重估。
**错误码**：`E-FIN-140/141`。

## 关键发现
1. **三表复用试算表**：BalanceSheet 取 `CloseBal`(期末时点)、IncomeStatement 取 `PeriodDebit/Credit`(本期区间),同一 `TrialBalanceService` 两字段;报表无独立存储永与总账一致。
2. **成本料工费真实**：料=MES `ActualQty`×`SupplyPrice`,工费=MES `ActualLaborHour/MachineHour`×费率,非纯标准。
3. **撮合引擎"唯一解才自动撮合"**(有界子集和 DFS K=8,>1早停),三阶 1:1/1:N/N:1。
4. **双向调节表恒等** `BankAdjustedBalance == BookAdjustedBalance`(ReconciledDiff=0)是锁定前置。
5. **FxRevaluation/FinReconciliation 无独立 API/前端**(前者结账触发,后者24h Worker)。
6. **错误码族**：成本 `E-FIN-401/402/403`+`E-A2-*`;银行对账 `E-A4-*`;汇兑 `E-FIN-140/141`;每日对账无码。
