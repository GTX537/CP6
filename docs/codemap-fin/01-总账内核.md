# 01 · 总账内核（科目/凭证/月结/试算/自动凭证）

> 先读 [`README.md`](README.md)。全部 `文件:行号` 与代码片段 2026-06-22 实测、逐字引用。

## 0. 三铁律
1. **借贷恒等** — 整张凭证 Σ借==Σ贷(`ValidateBalance` 纯函数,decimal 精确比较)。
2. **凭证不可改不可删** — 无 PUT/DELETE,只能红冲(Controller 注释 `JournalEntryController.cs:11`)。
3. **maker-checker** — 手工过账 `MakerId==checkerId` 拒 `E-FIN-111`,自动凭证 SYSTEM 直过。
凭证状态机 `JournalStatus`(`JournalEntry.cs:97-109`)：Draft0→PendingReview1→Posted2,旁支 Rejected3/Reversed4。

## 二、凭证 CRUD + 状态机 — /api/fin/journal

**列表/查询** `GET`：`ListAsync`(`Include(Lines)`,按 periodId/status,降序);`Get` 不存在`E-FIN-130`。
**新建草稿** `POST`→`CreateDraftAsync`(`JournalEntryService.cs:39-56`)：
```csharp
entry.Status = JournalStatus.Draft;
entry.MakerId = makerId; entry.MakerAt = DateTime.Now;
var period = await _period.EnsureOpenAsync(entry.VoucherDate, makerId);  // ①按记账日确保期间Open
entry.PeriodId = period.Id;
entry.No = await _seq.NextAsync(SeqKey, entry.VoucherDate);              // ②采番 GL-yyyy-MM-NNNNN

```
> **草稿阶段不做借贷校验**(延后到 submit/post)。前端实时平衡 computed(`JournalEntryView.vue:156-158`,`<0.005` 容差)+借贷互斥UI仅预校。
**提交复核** `POST {id}/submit`→`SubmitForReviewAsync`(`:58-71`)：非 Draft`E-FIN-114`→`ValidateAsync`(触发完整借贷恒等)→PendingReview。

**⭐ 过账** `POST {id}/post`(`[RequirePermission("fin-journal","post")]`,过账人=CurrentUser≠制单人)→`PostAsync`(`:73-96`)逐字：
```csharp
if (e.Status != JournalStatus.PendingReview) return FinResult.Fail("E-FIN-110");
if (e.MakerId == checkerId) return FinResult.Fail("E-FIN-111");          // ★maker-checker
if (!await _period.IsOpenAsync(e.PeriodId)) return FinResult.Fail("E-FIN-112");  // ★锁期
var v = await ValidateAsync(e); if (!v.Ok) return v;                     // 过账前再校借贷恒等
var guard = await BankReconGuard.CheckPostingAsync(_db, e); if (!guard.Ok) return guard;     // A4守卫
var budgetGuard = await BudgetGuard.CheckPostingAsync(_db, e); if (!budgetGuard.Ok) return budgetGuard;  // A5预控
e.Status = JournalStatus.Posted; e.CheckerId = checkerId; e.CheckerAt = DateTime.Now;
```
**⭐ 借贷恒等纯函数 `ValidateBalance`**(`:219-239`)：
```csharp
if (e.Lines.Count < 2) return Fail("E-FIN-101");
foreach (var ln in e.Lines) {
    if (ln.Debit < 0 || ln.Credit < 0) return Fail("E-FIN-102", ln.LineNo);
    if ((ln.Debit > 0) == (ln.Credit > 0)) return Fail("E-FIN-103", ln.LineNo);  // 同>0或同=0都不行
    if (!accounts.TryGetValue(ln.AccountId, out var acc)) return Fail("E-FIN-108", ln.LineNo);
    if (!acc.IsLeaf) return Fail("E-FIN-104", acc.Code);
    if (!acc.IsActive) return Fail("E-FIN-105", acc.Code);
    if (acc.RequirePartner && string.IsNullOrEmpty(ln.PartnerId)) return Fail("E-FIN-106", acc.Code);
}
if (e.Lines.Sum(l=>l.Debit) != e.Lines.Sum(l=>l.Credit)) return Fail("E-FIN-107", totalDebit, totalCredit);  // ★借贷恒等
```
注释：纯函数不碰 DB 便于单测,decimal 比较防浮点。
**驳回** `POST {id}/reject`→`RejectAsync`(非 PendingReview`E-FIN-115`)。

**⭐ 红冲** `POST {id}/reverse`(autoPost=false)→`ReverseAsync`(`:142-194`)：
```csharp
if (origin.Status != JournalStatus.Posted) return Fail("E-FIN-120");
var reversal = new JournalEntry { No=NextAsync(...), Source=VoucherSource.Reversal, SourceDocNo=origin.No, ReverseOfId=origin.Id,
    Status = autoPost ? Posted : PendingReview, AutoPosted=autoPost, MakerId=autoPost?SystemUser:makerId,
    Lines = origin.Lines.Select(l => new JournalLine { AccountId=l.AccountId, Debit=l.Credit, Credit=l.Debit, ... }).ToList() };  // ★借贷对调

```

**错误码**：`E-FIN-101~108/110/111/112/114/115/120/130`。

## 三、会计期间 + 月结 — /api/fin/period

**列表** `GET`：`FiscalPeriodService.ListAsync`。**期间自动创建**：凭证首次记账 `EnsureOpenAsync`(跨年滚动归一,按 `ComputeFiscal` 算 FiscalYear/PeriodNo,财年起始月 `appsettings Fin:FiscalYearStartMonth` 默认1)。
**⭐ 结账预检** `GET {id}/pre-close-check`→`PreCloseCheckAsync`(`PeriodCloseService.cs:33-61`)四守卫：

## 四、试算平衡 — GET /api/fin/trial-balance/{periodId}

`TrialBalanceService.BuildAsync`(`:23-79`,三表共同基石)：期间不存在`E-FIN-140`→取全部 `Posted` 分录(实时滚算不存快照)→本期发生(`PeriodId==periodId`)+期初含历史(`VoucherDate<PeriodStart` 累计):
```csharp
var sign = acc.NormalSide == AccountSide.Debit ? 1 : -1;
var openBal = sign * (oD - oC);                  // 期初(正常方向带号)
var closeBal = sign * ((oD + mD) - (oC + mC));    // 期末=期初+本期
```
行 `TrialBalanceRow(Code, Name, OpenBal, PeriodDebit(mD), PeriodCredit(mC), CloseBal, NormalSide)`——BalanceSheet 取 `CloseBal`、IncomeStatement 取 `PeriodDebit/Credit`。两层平衡 `IsBalanced = MovementBalanced && ClosingBalanced`,不平 `LogError`。

## 五、⭐ 自动凭证引擎（规则即数据→AutoPost）

> 无独立 REST 端点——由业务服务构造 `FinBizEvent` 调 `IAutoVoucherEngine.GenerateAsync`。
**`AutoVoucherEngine.GenerateAsync`**(`AutoVoucherEngine.cs:23-95`)四步：
```csharp
// Step1 幂等：同Source+SourceDocNo已过账→Pass跳过
if (evt.Source != Manual && exists(Source && SourceDocNo && Posted)) return Pass();
// Step2 找规则
var rule = await _db.PostingRules.Include(Lines).FirstOrDefault(r => r.EventType==evt.EventType && r.IsActive);
if (rule == null) return Fail("E-FIN-150", evt.EventType);
// Step3 拼行(三模式)
foreach (var rl in rule.Lines) {
    if (rl.Source == FixedRole) { var accId = await ResolveRoleAsync(rl.AccountRole) ?? rl.FallbackAccountId; if(accId is not Guid) return Fail("E-FIN-141"); var orig = evt.GetAmount(rl.AmountField); if(orig==0) continue; entry.Lines.Add(BuildLine(rl, aid, Round(orig*rate), ...)); }
    else if (rl.Source == HeaderAccount) { var accId = evt.GetGuid(rl.LineAccountField) ?? rl.Fallback; ... }   // 科目来自事件头Guid(如银行存款)
    else { /* DocumentLines: 按科目+成本中心分组炸开 */ }
}
// Step4 直过
return await _journal.AutoPostAsync(entry);
```
`ResolveRoleAsync`(`:98-103`)`FirstOrDefault(a => a.Role==role && a.IsActive)`。
**AutoPost 兜底** `JournalEntryService.AutoPostAsync`(`:98-127`)：`Manual` 拒`E-FIN-113`→`EnsureOpenAsync`+采番+`ValidateAsync`(配错规则在此被拦)+锁期`E-FIN-112`+银行守卫→`Posted`,`MakerId=CheckerId=SystemUser`(可信直过绕 maker-checker 但仍校恒等)。
**规则种子 `PostingRuleSeed`** 幂等播 12 条：如 `AP.InvoicePosted`(借DocLines费用+借TAX_INPUT+贷AP_CONTROL)、`AR.Revenue`(借AR_CONTROL/贷REVENUE/贷TAX_OUTPUT)、`AP.Payment`(借AP_CONTROL/贷HeaderAccount银行)。
**采番 `FinSequenceService.NextAsync`**(`:15-39`)：`{key}{yyyy-MM}{D5}`,复合键 `SeqKey+SeqDate`,**按月归零**(如 `GL-2026-06-00012`)。
**错误码**：`E-FIN-150`(规则未找到)/`E-FIN-141`(科目角色未配)/`E-FIN-113`(手工不可直过)/`E-FIN-112`(锁期)+借贷恒等全套。

## 关键发现
1. **DTOs/Fin 目录不存在**：总账内核 Controller 直收发领域实体(`GlAccount`/`JournalEntry`),DTO 仅 AP/AR/Bank/Budget 等子模块有。
2. **借贷恒等只有一处实现**(`ValidateBalance` 纯函数),手工链+自动链共用,杜绝双实现漂移;`decimal !=` 精确比较无 epsilon(前端 UI 才用 `<0.005`)。
3. **自动凭证引擎无 REST 端点**,由业务服务内部调用,符合"规则即数据→AutoPost"设计。
