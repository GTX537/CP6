## 三、⭐ 折旧引擎四法（纯函数）— DepreciationCalculator.PeriodAmount

**位置** `DepreciationCalculator.cs`(无 DB)。统一前置 `depreciable = OriginalValue - SalvageValue`；`remain = UsefulLifeMonths - DepreciatedPeriods`。
- **①定额(StraightLine=1)**：`raw = depreciable / UsefulLifeMonths`。
- **②双倍余额(DoubleDeclining=2)**(`:20-38`)：`Y=ceil(月/12)`;`Y<=2` 退化定额;否则 `y=当前年, r=2/Y`；前 Y-2 年 `raw = NetBookValueAtYearStart * r / 12`；末两年 `raw = (entryNbv - SalvageValue)/2/12`(直线均摊)。
- **③年数总和(SumOfYears=3)**(`:40-48`)：`sum=Y(Y+1)/2; annual = depreciable*(Y-y+1)/sum; raw = annual/12`。
- **④工作量(UnitsOfProduction=4)**(`:50-54`)：`raw = depreciable * WorkloadThisPeriod / TotalWorkload`(缺量抛 `E-FA-008`,**全模块唯一带E-前缀码**)。
**统一兜底**(`:61-66`)：`amount = Round(raw, 2, AwayFromZero)`;封顶 `cap = depreciable - AccumulatedBefore`;非工作量法末期(`remain<=1`)补足残差;负数归零。

## 四、⭐ 月末折旧 Worker（备草稿不过账）— AssetDepreciationWorker

`BackgroundService`(启动延迟1min,每24h)。`ProcessOnceAsync`(`:38-59`)：按租户 `TenantScopeRunner`→**仅月末末日**→取本期 Open 期间→**本期已有批量批次则跳过**(`RunMode != DisposalFinal && Status != Reversed`)→`dep.RunAsync(period.Id, "worker", DepreciationRunMode.Worker)`(**只 Run 生成 Draft,不过账**,过账交人工/结账钩子)。

## 五、折旧服务三路 — POST /api/fin/asset-deprec/{run,post,reverse}

**前端**：`AssetDepreciationView.vue` 试算/计提 + 批次过账/反冲。api `asset.ts:29-49`。
**后端** `AssetDepreciationService`(仿 FxRevaluationService 直建凭证)：
- `EligibleAsync`(`:23-39`)：`InUse && DepreciationStartPeriod<=当期 && AccumulatedDepreciation<depreciable && 本期未提`。
- `RunAsync`(`:82-117`)：期间非Open`FA007`/本期已有批量`FA003`→逐卡 `BuildEntryAsync` 建 `DepreciationEntry`(草稿不过账,工作量法 amount=0 待 SetWorkload)→批次采番 `DEP`。
- **`PostAsync`**(`:144-201`)⭐汇总凭证：借方按 `(费用科目,成本中心)` 分组,贷方按累折科目分组,`Source=VoucherSource.Depreciation`(8),凭证日=期末末日,`AutoPostAsync`;过账后回写卡片 `AccumulatedDepreciation += amount; DepreciatedPeriods += 1`(达上限→FullyDepreciated)。工作量法 `WorkloadThisPeriod==null` 拒过账`FA008`。
- `ReverseAsync`(`:203-236`)：仅 Posted;DisposalFinal 不可单独反冲`FA011`;关联资产已有非Reversed处置单→`FA011`(反冲次序守卫);红冲+回退。
- `AccrueAsync`(结账钩子)：已Posted幂等放行;Draft→PostAsync;无批次→Run(CloseHook)+Post。挂接 `PeriodCloseService.cs:54-58`(预检)、`:70-74`(计提)。
**错误码**：`FA001/003/006/007/008/009/011`。

## 六、⭐ 资产处置（清理结转 + 处置月补提）— POST /api/fin/asset-disposal[/confirm]

**前端**：`AssetDisposalView.vue` 处置类型 `[1,2,3,4]`=出售/报废/转让/盘亏,价款/税/清理费,银行账户条件渲染。api `asset.ts:51-63`。
**后端** `AssetDisposalService`：
- 科目解析 `ResolveAccountsAsync`(`:25-40`)按 Role：清理=`InventoryLoss?PENDING_PROPERTY_LOSS:ASSET_CLEARING`;损益=`Sale/Transfer→ASSET_DISPOSAL_PL / InventoryLoss→NON_OP_EXPENSE / Scrap→收益?NON_OP_INCOME:NON_OP_EXPENSE`。
- `CreateAsync`(`:42-69`)：卡片须 InUse|FullyDepreciated(`FA002`)/无在途处置(`FA002`)/期间Open(`FA007`)/有价款须银行(`FA010`)→快照原值累计净值+`NetGainLoss=Proceeds-DisposalExpense-NetBookValue`→采番 `FAD`,Draft。
- **`BuildDisposalLinesAsync`**(`:72-113`)⭐清理结转(非盘亏)：借累计折旧 + 借清理(=净值)/贷固定资产(原值);有价款 借银行(含税)/贷清理(价款)+贷销项税;有清理费 借清理/贷银行;净收益 借清理/贷损益(损失反向)。盘亏独立路径(待处理财产损溢+营业外支出)。
- **`ConfirmAsync`**(`:115-156`)⭐处置月补提折旧接缝：

```csharp
card = await _db.AssetCards.FindAsync(d.AssetCardId);   // 重读(补提后累计已变)

d.NetGainLoss = d.Proceeds - d.DisposalExpense - d.NetBookValue;  // 用补提后净值重算损益
... BuildDisposalLinesAsync → AutoPostAsync(Source=AssetDisposal=9) ...
d.PriorStatus = priorStatus; card.Status = AssetStatus.Disposed;
```
- `ReverseAsync`(`:158-208`)：红冲处置凭证→红冲补提折旧→回退→按 `PriorStatus` 精确还原。
**错误码**：`FA001/002/006/007/009/010/011`。

## 九、⭐ 预算 vs 实际 + 预控守卫/预检

**报告** `GET /api/fin/budget/report/vs-actual`→`BudgetReportService.BuildVsActualAsync`(`:19-173`)：版本(显式或该财年 Active)→预算桶 key `{acctId}|{ccKey}|{coType}|{coId}`→实际侧仅 Posted(费用=借-贷/收入=贷-借)→**最具体匹配** `MatchBucketKey`(空维度通配,按非通配维度数排序)→**未编预算不丢弃**(无匹配→`|UB` key,`IsUnbudgeted=true`)。`Variance = Budget - Actual`。
**⭐ 预控守卫** `BudgetGuard.CheckPostingAsync`(静态,仿 BankReconGuard)挂 `JournalEntryService.PostAsync`(`:87-88`,**手工凭证过账**)：
```csharp
var budgetGuard = await BudgetGuard.CheckPostingAsync(_db, e);
if (!budgetGuard.Ok) return budgetGuard;
```
> ⚠️ **折旧/处置凭证走 `AutoPostAsync`,只调 BankReconGuard 不调 BudgetGuard**——**预算硬控制仅作用于手工过账**(load-bearing 边界)。
`BudgetEvaluator.EvaluateAsync`(`:45-141`)：仅费用科目,同 entry 同桶合并防拆行,`MostSpecific` 成本中心优先,YTD/Period 口径,超支 `used + inc > budget`→`E-A5-BUDGET-EXCEEDED`。**预检** `POST .../pre-check`→`PreCheckAsync`(复用 `BudgetEvaluator(blockOnly=false)` 返 Warn+Block 全量)。

## 关键发现
1. **错误码两套**：资产裸码 `FA001~012`(唯独 `DepreciationCalculator:52` 抛 `E-FA-008` 带 E-前缀)、预算 `E-A5-*`。
2. **预算硬控制不覆盖折旧/处置**：`BudgetGuard` 只挂手工 `PostAsync`,`AutoPostAsync`(自动凭证)不经——设计边界。
3. **OA 回调原子性**：`ActivateFromApprovalAsync`/`OnRejectedAsync` 刻意不 SaveChanges,依赖 OA 引擎统一持久化;`IServiceProvider` 延迟解析破 DI 循环。
4. **月末 Worker 只备草稿不过账**(交人工/结账钩子);处置 confirm 先补提处置月折旧再重算损益。
5. **未找到** `CostCenterView.vue`(无独立维护页);凭证 `VoucherSource` 折旧=8/处置=9。
