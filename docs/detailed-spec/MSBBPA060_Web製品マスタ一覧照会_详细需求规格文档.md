## 第1章 功能概述与业务定位

### 1.1 功能目的

本功能（MSBBPA060）用于**一览查询产品主数据（製品マスタ）**，并提供向产品主数据维护画面（[MSBBPA050]）的跳转入口（参照 / 訂正）。它是销售管理子系统里产品主数据的"查找入口"——按多维度抽出条件检索，结果以列表呈现，可导出 CSV，也可作为其他画面的"产品选择弹出"复用。

### 1.2 业务流程定位

```
见积阶段 → MSBBPA050 製品マスタ登録（产品规格正式注册）
                    ↑ 参照/訂正 跳转
            【MSBBPA060 製品マスタ一覧照会】← 本功能
                    ↓ 作为检索画面被复用
            其他业务画面（如受注入力）调用"产品选择"
```

### 1.3 核心功能点

- 多维度抽出条件检索：基本信息（得意先 / 案件NO / 製品CD / 品名 / 品番 / JAN）+ 构成信息（原纸 / 印刷 / 压纹 / 厂商 / 刃渡 / 张尺寸）+ 产品管理信息（约 30 个区分项）。
- 检索结果一览展示（约 51 列），并支持 **CSV 导出**（导出"画面当前已显示的数据"）。
- 双模式：**照会模式**（菜单进入，可跳详细）/ **检索模式**（被其他画面作为产品选择弹出，回传选中行）。
- 拠点（据点）数据访问控制（详见 MSBBPA000 共通仕様）。

### 1.4 操作种别

本画面的操作种别固定为**検索（检索）**——它是一个查询/照会画面，无登録/訂正/削除等数据变更操作（数据变更在 MSBBPA050）。

### 1.5 排序顺序（固定）

检索结果固定按：**担当 → 得意先 → 案件NO（親→子→部材）→ 製品CD** 排序。

### 1.6 数据访问控制

- 拠点（据点）による制御。
- ⚠️ 详细规则在 **【MSBBPA000】_共通設計書_アドオン(Webシステム共通仕様)** 中定义，本画面遵循其据点过滤口径。

## 第2章 两种调用模式（照会模式 / 检索模式）

本画面同一套界面，按"如何被打开"切换为两种模式，差异集中在**页脚按钮的显隐**与**返回行为**：

| 模式 | 触发来源 | 製品マスタ詳細 按钮 | 選択 按钮 | 行为 |
|---|---|---|---|---|
| **照会模式** | 从菜单直接进入 | 显示（E） | 隐藏（I） | 检索照会 + 可跳 MSBBPA050 参照 + CSV |
| **检索模式** | 被其他画面作为"产品选择"弹出（如从 MSBBPA050 / 受注入力调用） | 隐藏（I） | 显示（E） | 检索后选中 1 行，回传给遷移元画面 |

> 📌 模式判定在初期表示时完成：照会模式显示「製品マスタ詳細」、隐藏「選択」；检索模式相反（隐藏「製品マスタ詳細」、显示「選択」）。其余区域（抽出条件、一览）两模式一致。

## 第4章 抽出条件（检索条件）字段明细

控件类型（W）取值：**カ**=カレンダー(日期选择)、**C**=コンボボックス(下拉)、**A**=オートコンプリート(自动完成，带検索弹出)、**T**=テキスト(文本)、**B**=ボタン。数据型（型）：**D**=日期、**S**=字符串、**N**=数值。「あいまい」=模糊检索(LIKE)。「検」=带検索弹出按钮。

### 4.1 公共抽出条件

| 字段 | 日文名 | 控件(W) | 型 | 检索方式 | 数据来源/说明 |
|---|---|---|---|---|---|
| updatedAtFrom | 更新日時(From) | カ | D | >= | 初期=当日 − ログインマスタ.初期表示日数 |
| updatedAtTo | 更新日時(To) | カ | D | <= | 初期=当日 |
| updatedBy | 更新担当者 | C | S | = | 下拉，定义见 MSBBPACOM 共通ロジック；初期=登录担当者CD |

### 4.2 抽出条件 - 基本信息

| 字段 | 日文名 | 控件(W) | 型 | 检索方式 | 数据来源/说明 |
|---|---|---|---|---|---|
| customerCd | 得意先 | A | S | = | 带検索弹出（→MSBBPA120）；定义见 MSBBPACOM |
| projectNo | 案件NO | A | S | = | 带検索弹出；案件NO=親+子+部材；定义见 MSBBPACOM |
| productCd | 製品CD | T | S | LIKE | 模糊检索可 |
| customerProductName1 | 顧客品名1 | T | S | LIKE | 模糊检索可 |
| customerProductName2 | 顧客品名2 | T | S | LIKE | 模糊检索可 |
| cpProductName1 | CP品名1 | T | S | LIKE | 模糊检索可（注：SQL 抽出条件映射到 顧客品名1，见第10章） |
| cpProductName2 | CP品名2 | T | S | LIKE | 模糊检索可（注：SQL 抽出条件映射到 顧客品名2，见第10章） |
| customerProductCode | 顧客品番 | T | S | LIKE | 模糊检索可 |
| janCode | JANコード | T | S | LIKE | 模糊检索可 |

### 4.3 抽出条件 - 构成信息（表/中/裏 三层 × 4 类编码）

每层（表/中/裏）各 4 个编码，均为 **A（带検索弹出）/ S / =**，定义见 MSBBPACOM：

| 字段前缀 | 表 | 中 | 裏 |
|---|---|---|---|
| 原紙コード | baseSheetCdF | baseSheetCdM | baseSheetCdB |
| 印刷コード | printCdF | printCdM | printCdB |
| エンボスコード | embossCdF | embossCdM | embossCdB |
| メーカコード | makerCdF | makerCdM | makerCdB |

刃渡 / 张尺寸（范围检索，均 **T / N**）：

| 字段 | 日文名 | 检索方式 |
|---|---|---|
| bladeWidthFrom / To | 刃渡り_巾(From) / (To) | >= / <= |
| bladeFlowFrom / To | 刃渡り_流れ(From) / (To) | >= / <= |
| sheetWidthFrom / To | シート寸法_巾(From) / (To) | >= / <= |
| sheetFlowFrom / To | シート寸法_流れ(From) / (To) | >= / <= |

### 4.4 抽出条件 - 产品管理信息（区分类，均 C / S / =，定义见 MSBBPACOM）

受注区分、製品区分_大、製品区分_中、製品区分_小、製品用途、物流区分、機密情報、奪取区分、重要区分、Mチェン、品質区分、出荷検査、製品形状、ユネスコマーク、折鶴マーク、4M契約、TKP折れシワ基準、容リ支払、識別表示、食品安全、FSC製品区分、FSC材質区分。

## 第8章 初期表示逻辑

画面加载时执行：

1. **更新日時(From)** = 当日 − `ログインマスタ.初期表示`（初始天数）；**更新日時(To)** = 当日。
2. **更新担当者** = 登录担当者CD（默认显示当前登录用户）。
3. **下拉框初期化**：更新担当者、シート段、製品区分_大/中/小、製品用途、物流区分、機密情報、奪取区分、重要区分、Mチェン、品質区分、出荷検査、製品形状、ユネスコマーク、折鶴マーク、4M契約、TKP折れシワ基準、容リ支払、識別表示、食品安全、FSC製品区分、FSC材質区分 等下拉，均按 **MSBBPACOM「処理詳細(共通検索)」** 的 SQL リソース检索仕様初始化。
4. **页脚按钮显隐**：按第2章模式判定——照会模式显「製品マスタ詳細」隐「選択」；检索模式隐「製品マスタ詳細」显「選択」。
5. 初期表示**不自动执行检索**（需点「表示」）。

## 第9章 按钮处理详细

### 9.1 クリア

将画面恢复到初期表示状态（等同重新启动，见第8章），清空一览。

### 9.2 表示（检索）

```
Step 1  FROM~TO 整合性校验（见第11/15章）
        校验对象：更新日時、刃渡り_巾、刃渡り_流れ、シート寸法_巾、シート寸法_流れ
        若任一 From > To → 报错 E10036「FROM≦の関係で指定してください。」→ 取消后续
Step 2  以抽出条件执行检索（检索入出力仕様 NO.1 的 SQL，见第10章）
        - 0 件 → 提示 E10008「検索結果がありません。」
        - 命中件数 > 上限值 → 见第11章（一般用户报错 E10013 / 管理员警告 C00006）
        - 正常 → 结果填入製品マスタ一覧（按固定排序）
```

### 9.3 CSV出力

```
- 导出"一览当前已显示的全部数据"（非重新查询，导出画面快照）
- 调用 MSBBPACOM「処理詳細(各機能共通処理)」的共通 CSV 出力
- 设定 PageId = MSBBPA060（CSV 输出定义与文件名由 MSBBPACOM 共通定义）
```

### 9.4 製品マスタ詳細（仅照会模式）

```
- 未选中行 / 一览无数据 → 提示 E10009「選択行がありません。」
- 选中 1 行 → 跳 MSBBPA050 Web製品マスタ（操作种别=参照）
- 传递 key：选中行的 製品CD(セット製品CD)（见画面遷移 S01-NO1）
- 复数选择不允许
```

### 9.5 選択（仅检索模式）

```
- 未选中行 / 一览无数据 → 提示 E10009「選択行がありません。」
- 选中 1 行 → 将该行全部数据回传遷移元画面对应项目（见画面遷移 S01）
- 复数选择不允许
```

## 第10章 检索 SQL 规格

> 检索入出力仕様 NO.1 的 SQL リソース。所有联表均为**外连接（+）**，确保製品マスタ主表行不因从表缺失而丢失。

### 10.1 对象表

| 别名 | 表 | 说明 |
|---|---|---|
| M01 | WEB製品マスタ | 主表 |
| M02 | WEB案件管理トラン | 取案件名 |
| M03 | WEB取引先マスタ | 取得意先名（得意先FLG=1） |
| M04 | MC品目マスタ | 取構成名（品名） |

### 10.2 结合条件（均外连接）

```sql
-- 案件管理トラン（案件NO 三段）
M01.案件NO(親) = M02.案件NO(親)
AND M01.案件NO(子) = M02.案件NO(子)
AND M01.案件NO(部材) = M02.案件NO(部材)                         (+)

-- 得意先名
M01.得意先 = M03.取引先 AND M03.得意先FLG = '1'                (+)

-- 構成名（品目マスタ）
M01.製品CD = M04.製品CD                                        (+)
AND M01.品目CD = M04.品目CD AND M01.枝番1/2/3 = M04.枝番1/2/3

-- メーカ名（表/中/裏）
M01.メーカコード(表)CD = M05.取引先 AND M05.メーカFLG = '1'    (+)
M01.メーカコード(中)CD = M06.取引先 AND M06.メーカFLG = '1'    (+)
M01.メーカコード(裏)CD = M07.取引先 AND M07.メーカFLG = '1'    (+)
```
