# Day 2 · SQL / 数据库 + Vue 3 前端 详细版学习教程 —— 总览与学习路线

> **目标岗位**：制造业生产管理系统开发工程师（C# + SQL + Vue，WEB 程序 + 客户端程序，5 年经验强度）
> **本日定位**：JD 的另外两条硬技能——"熟悉 SQL 语言，了解关系型数据库结构" + "熟悉 JavaScript、CSS、VUE、ElementUI 等主流 WEB 前端开发技术"。

## 学习顺序建议

按 JD 权重和你的基础二选一：

- **路线 A（默认）**：按章节号顺序——上午 SQL 三章，下午 Vue 三章。SQL 手写是面试现场环节，优先保熟练。
- **路线 B（前端偏弱者）**：先 4→5→6 再回头 1→2→3。前端概念量大，趁精力好先啃。

无论哪条路线，**第 2 章（索引与事务）和第 5 章（axios 封装/路由守卫）是两侧的分水岭章节**，时间再紧也要精读。

## 全书踩坑实录索引（Day 2 新增的面试故事弹药）

| 事故/坑 | 所在章节 | 一句话版本 |
|---|---|---|
| LEFT JOIN 的 ON vs WHERE | 第 1 章 | 过滤条件写错位置，LEFT JOIN 退化成 INNER JOIN，报表少数据 |
| NULL 三值逻辑 | 第 1 章 | `<> 'x'` 过滤不出 NULL 行、NOT IN 遇 NULL 全空——生产报表差异的常见根因 |
| 唯一索引迁移回滚撞键 | 第 2 章 | Down() 先删重复副本再删索引，否则回滚失败（真实迁移 SysRoleMenuUniqueIndex） |
| GUID 聚集索引碎片 | 第 2 章 | 随机 GUID 导致页分裂，全 GUID 主键项目的代价与对策 |
| 磁盘满全栈停机 | 第 3 章 | WU 缓存→C 盘 0→WSL swap 分配失败→dockerd 崩→DB 不可用；看门狗自愈+扩容治本 |
| QA 环境 EF 日志刷爆磁盘 | 第 3 章 | EF Core 日志级别低于 Warning，SQL 全量落日志，容量告急——日志级别是容量治理的一部分 |
| reactive 解构丢响应性 | 第 4 章 | `const { x } = reactive(...)` 后 x 不再更新；storeToRefs 同理 |
| v-for 无 key / 用 index 做 key | 第 4 章 | 就地复用导致表单错位——列表渲染必须稳定 key |
| 前端藏按钮 ≠ 安全 | 第 6 章 | v-permission 只是 UX，绕过前端直接调 API 必须被后端 403 拦住 |

## 快速自检（学完全部章节后）

1. 能白板手写：每组取最新一条（三种写法）、条件聚合透视、递归 CTE 展开 BOM
2. 能讲 LEFT JOIN 里 ON 和 WHERE 的区别并举例
3. 能画 B+ 树并解释聚集/非聚集索引、覆盖索引、最左前缀
4. 能说出四个隔离级别各解决什么问题；库存扣减防超卖三方案对比
5. 能完整讲"系统突然变慢你怎么查"（止血→定位→根因→治本→复盘框架）
6. 能讲 ref vs reactive、computed 缓存、watch 清理副作用
7. 能讲组件通信全部方式及各自适用场景
8. 能逐行解释 http.ts 拦截器（JWT 注入、401/403 统一处理）
9. 能逐行解释 v-permission 指令实现，并说清前后端权限的分工
10. 能把"库存查询"从 Vue 页面到 SQL 的完整链路讲成 3 分钟故事
