## 面试当天作战手册

### 出发前物品清单
- [ ] 简历打印 3 份（面试官可能不止一人）
- [ ] **两张架构图打印**（A4）：①CP6 请求流水线图（Vue→中间件→Controller→Service→EF→SQL Server，标注 JWT/权限/审计/多租户四个横切点）②部署拓扑图（Docker 7 容器+Kafka/RabbitMQ 分工+备份/监控）——蓝本在 Day 1 附录 B，用 draw.io 重画。面试讲项目时主动拿出来，同时命中 JD"矢量绘图"
- [ ] 纸笔（现场手写 SQL/画表结构用）
- [ ] 充好电的手机（迟到联系、路线导航）

### 心态与节奏
1. **听完再答**：面试官问完停 2 秒组织结构（先结论→再展开→举 CP6 例子收尾），比抢答加分
2. **不会的题标准动作**：诚实（"这个我没有实际用过"）→ 给思路（"但按我的理解应该是……"）→ 迁移（"类似的问题我在 XX 里是这么解决的"）。绝不硬编——技术面试官一眼识破
3. **每个技术答案尽量落到项目**："……比如我们项目里就是这么处理的"是 5 年经验感的口头禅
4. **被追问到底层是好事**：说明面试官感兴趣。答到自己边界时主动说"再往下我只了解到 X 层"
5. **手写 SQL 慢一点没关系**：边写边说思路，思路对比语法完美更重要

### 高频送命题速查（详细版在各章）
| 题 | 30 秒答案骨架 | 详见 |
|---|---|---|
| Java 会吗 | 主力 C#，了解 Java 生态对应（Spring Boot↔ASP.NET Core、JPA↔EF），概念同构可快速上手 | 第 1 章 |
| 桌面客户端做过吗 | Web 为主；C# 转 WinForm/WPF 是同语言平移，事件模型我熟（SignalR/前端事件），愿意补 | 第 1 章 |
| 期望薪资 | 区间策略+依据（市场价+现薪+岗位价值），首轮尽量不报死数 | 第 5 章 |
| 为什么离职 | 只说向前的理由（想深耕制造业信息化），不贬前东家 | 第 4/5 章 |
| 讲一次生产故障 | 磁盘满停机 STAR 2 分钟版 | 第 2 章 |
| 你们怎么保证质量 | 测试金字塔（2600+ 测试）+多层审查+线上实证清单 三层 | 第 4 章 |

### 反问环节（挑 2-3 个问）
- "目前生产系统最让车间头疼的环节是哪个？"（业务思考）
- "这个岗位前 3 个月最希望我解决什么问题？"（落地导向）
- "系统的用户主要是车间现场还是办公室计划员？现场终端是什么形态？"（暗示你懂现场）
- 更多见第 4 章反问清单；薪资福利问题留给 HR 轮

### 结束动作
- 无论感觉好坏，礼貌收尾："今天聊到的 XX 问题很有启发，回去我会再研究"
- 24 小时内若有 HR 微信，简短致谢+补充一句面试中没讲透的亮点（一次机会，别刷屏）
