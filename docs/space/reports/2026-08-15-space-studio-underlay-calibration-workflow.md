# Space Studio 两点实距标定工作流实现报告

日期：2026-08-15
任务分支：`codex/space-studio-underlay-calibration-workflow`

## 结论

详细 Spec LM-FR-021 的仓库实现已闭环。底图标定保留既有 Design V1 三控制点合同和确定性变换：用户在底图上依次选择 P1 原点、P2 比例点和独立验证点 V，只需输入 P1/P2 的真实距离、P1 世界原点、旋转角及 V 的世界坐标；工作台据此生成服务端实际接收的世界毫米控制点，不再要求用户手工换算 P2 坐标。

标定保存仍复用现有租约、Floor/Content Revision、数据库 UTC、幂等 CommandBatch 和可逆历史。该任务优化既有工作流，没有替换领域模型或建立第二条标定权威。

## 实现范围

- 新增强类型两点放置计算，以栅格 Y-up 坐标确定 P1→P2 方向，再叠加显式旋转和真实距离，得到 P2 世界坐标。
- 工作台把 P1 明确为世界原点，把 P2 明确为比例点，把 V 明确为不参与拟合的验证点；原点、距离、旋转和验证坐标均提供 44px 输入热区。
- 标定预览使用与请求相同的整数世界坐标，展示比例、原点、旋转、第三点验证误差及冻结阈值 `max(50mm, 实距×0.2%)`。
- 未完成三点选择、控制点过近、距离/坐标无效或验证误差超限时失败关闭；显式“验证并保存”前 Draft 零写入。
- 保存成功继续进入公共撤销/重做栈，既有底图替换、移除、租约丢失和 Revision 冲突行为不变。
