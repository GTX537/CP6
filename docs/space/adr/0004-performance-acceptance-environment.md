# ADR-0004：性能、容量与验收环境

- 状态：**Accepted**
- 日期：2026-07-25
- 关联：E02-S01、E07-S04、E08-S06、E13-S14～S15、D15

## 1. 决策

现有性能数字是冻结门槛，不再标记为“待技术试验决定”。技术试验只负责固定测量环境、复现方法和证据，不能自行放宽指标。

## 2. 冻结门槛

| 场景 | 门槛 |
|---|---:|
| 标准仓规模 | 500 货架、10,000 库位 |
| 冷缓存打开到首个可见场景 | ≤15 秒 |
| 场景可拾取和搜索 | ≤20 秒 |
| 连续平移/缩放中位帧率 | ≥30 FPS |
| 单对象拾取反馈 P95 | ≤150ms |
| 库存批量刷新到着色完成 P95 | ≤3 秒 |
| 50MB CAD 到可审查 AI 提案 P95 | ≤15 分钟 |
| 上传到版本首次 Ready | ≤60 分钟 |
| 1,000 项批量审查提交 P95 | ≤3 秒 |
| CAD 平台硬上限 | 200MB |
| 租户默认文件上限 | 100MB |
| 单图图元 | ≤100万 |
| 单租户并发 Generation Run | ≤3 |

## 3. 客户端参考环境

最低验收档：

- Windows 11 23H2 或更新受支持版本。
- 4 核/8 线程 CPU，性能不低于 Intel Core i5-1135G7 或 AMD Ryzen 5 5500U。
- 16GB RAM。
- 支持 WebGL2 的集成显卡，性能不低于 Intel Iris Xe 同级。
- 1920×1080、设备像素比 1.0、浏览器缩放 100%。
- Chrome Stable 与 Edge Stable；报告记录精确版本。
- 禁用开发者工具和浏览器扩展，使用全新 Profile。

增强档可以用于定位瓶颈，但不能替代最低档 GA 证据。

## 4. 服务端参考环境

- API：4 vCPU、8GB RAM。
- Space Worker：8 vCPU、32GB RAM，单任务 CPU/内存/时限隔离。
- SQL Server 2022 或当前生产认证版本：8 vCPU、32GB RAM。
- 对象存储与数据库位于同一批准区域。
- 性能报告记录容器/VM 限额、数据库版本、网络区域和 Provider 版本。

外部 Provider 的服务时间计入 15 分钟 P95；不得从用户端指标中扣除。

## 5. 数据与运行方法

- 使用版本化验收包，不临时生成对实现有利的数据。
- 浏览器每场景至少 30 次冷启动和 100 次拾取。
- CAD/AI 每个黄金样本至少 5 次；50MB 样本至少 20 次用于 P95。
- 首次预热结果不计入稳定分布，但必须单独报告。
- 错误、取消和超时运行进入可靠性统计，不能从样本中删除。
- 测试期间记录 CPU、工作集、GC、GPU 帧时间、网络、SQL、Provider 和 Job Step。

## 6. 证据格式

每份报告必须包含：

- 应用提交 SHA、Migration ID、数据包语义版本。
- Chrome/Edge、OS、GPU 驱动、.NET、Node、SQL Server 版本。
- 机器/容器资源和网络区域。
- 每个指标的样本量、P50、P95、最大值和失败率。
- 原始结果文件哈希、执行命令和时间。
- 与上一基线的回归百分比。

## 7. 阻断与变更

- Alpha、Beta、GA 使用 [`06-mvp-scope-freeze-baseline-v1.0.md`](../requirements/06-mvp-scope-freeze-baseline-v1.0.md) 的统一关卡。
- 指标失败时先优化、分块、实例化、缓存或限流。
- 无法达标不能通过修改测试环境、排除失败样本或提高最低硬件来规避。
- 确需放宽时必须提交 Scope Change RFC，并由产品、架构、QA 和安全负责人批准。
