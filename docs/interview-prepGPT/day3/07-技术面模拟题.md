# 第一部分：C# 与异步，15 分钟

## T1 值/引用/参数

问题：值类型和引用类型区别？下面三个方法会怎样影响调用者？

```csharp
void A(int x) { x++; }
void B(Box x) { x.Value++; }
void C(Box x) { x = new Box(); }
```

合格点：默认按值、复制内容、对象变更 vs 变量重绑；不以“都在栈/堆”作定义。

追问：`ref Box`；struct 字段；闭包捕获局部变量。

## T2 decimal

问题：金额为什么用 decimal？库存数量 `decimal(21,8)` 有什么含义和风险？

合格点：二进制浮点、十进制舍入、数据库 p/s、除法/溢出/业务舍入。

## T3 泛型仓储

问题：解释 `where T : BaseEntity` 和开放泛型 DI。评价 CP6 泛型仓储。

合格点：编译期能力、闭合类型解析、复用边界、orderBy 未使用/全实体修改/领域写入口。

## T4 异步

问题：async 是否开线程？为什么 Web API 用异步？

合格点：I/O completion、释放线程、吞吐 vs 延迟、状态机。

追问：Task.Run、ConfigureAwait、`.Result`、ValueTask。

## T5 并发与取消

问题：三个独立查询如何并发？为什么不能共享 DbContext？如何限流和取消？

合格点：先启动再 WhenAll、独立 scope、SemaphoreSlim、token 透传、超时区别。

## T6 Kafka Worker

问题：分析 CP6 Kafka 消费者的线程、scope 和投递语义。

合格点：阻塞 Consume 隔离、scope factory、手动 commit、至少一次、重复/幂等窗口。

# 第五部分：现场综合，时间允许

## T30 代码审查

```csharp
public async Task Move(MoveDto dto)
{
    var from = await db.Stocks.FirstAsync(x => x.Id == dto.FromId);
    var to = await db.Stocks.FirstAsync(x => x.Id == dto.ToId);
    from.Qty -= dto.Qty;
    await db.SaveChangesAsync();
    to.Qty += dto.Qty;
    await db.SaveChangesAsync();
    _ = hub.Clients.All.SendAsync("moved", dto);
}
```

要求找：验证、租户、权限、事务、并发、两次提交、库存不变量、流水、通知异常、取消、幂等、测试。
