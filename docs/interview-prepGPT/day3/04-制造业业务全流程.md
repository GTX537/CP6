# 04 · 制造业业务全流程

## 1. 系统边界

| 系统 | 核心问题 |
|---|---|
| CRM | 客户、机会、销售活动 |
| ERP | 订单、采购、库存账、财务与企业资源 |
| APS/计划 | 需求、物料、产能和排程优化 |
| MES | 工单执行、报工、设备、质量、在制 |
| WMS | 库位、入出库、批次、拣配、盘点 |
| QMS | 质量标准、检验、不合格、CAPA |
| PLM | 产品、图纸、BOM、工艺版本生命周期 |

企业实现边界会重叠。面试不要死背“MES 绝对不管库存”；说明主责、数据权威和接口边界。

## 2. 一条订单到回款主线

```text
询价/报价
→ 销售订单
→ 订单评审
→ 产品/BOM/工艺确认
→ MRP 净需求
→ 采购与到货 / 生产计划
→ 工单下达
→ 领料/备料
→ 工序报工
→ 质检
→ 完工入库
→ 拣货/发货
→ 开票/应收/收款
→ 成本与毛利
```

每一箭头都是系统集成风险：单号关联、状态机、幂等、重试、对账。

## 3. 报价与订单

报价输入可能有客户、产品规格、材料、工艺、损耗、数量阶梯、交期。订单确认后形成承诺：数量、价格、交期、质量和交付地点。

订单评审要检查：

- 信用和欠款。
- 产能/物料可达性。
- 工艺可制造性。
- 价格与特殊条款。
- 交期。

状态不是普通字符串，应有允许转移、权限、审计和撤销规则。

## 4. BOM

BOM 表示产品由哪些组件、各需要多少。生产 BOM 还要考虑：

- 版本与生效日期。
- 替代料。
- 损耗率。
- 单位换算。
- 虚拟件/phantom。
- 联副产品。
- 工厂/客户特定版本。

“展开 BOM”不仅递归查询，还要选择正确版本并累计数量。

## 5. 工艺路线

工艺路线描述工序顺序、工作中心、准备/加工时间、标准产能、质检点和外协节点。

排产时换型顺序很重要。纸器/印刷中换纸、换版、洗墨产生准备时间和损耗，单纯按订单交期排序可能造成频繁换型。

## 6. MRP

简化公式：

```text
净需求 = 毛需求
       + 安全库存需求
       - 可用库存
       - 已确认在途/计划入库
```

再按批量规则、提前期、日历和低层码生成计划订单/采购建议。

MRP 不是一次 SQL SUM：

- 需求有独立/相关需求。
- 库存有冻结、已分配、QC 状态。
- 供应有可信度和日期。
- BOM 多层和版本。
- 时间桶和提前期。

## 7. 工单

工单至少包含：产品、数量、计划日期、BOM/工艺版本、状态和优先级。下达意味着允许现场执行，并可能冻结版本快照。

为何要快照：主数据后来改变，历史工单仍需按当时版本解释成本和质量。

## 8. 领料、退料、补料与反冲

- 领料：实际从仓库发到工单/线边。
- 退料：未用或不良材料退回。
- 补料：超出标准需求追加。
- 反冲：报工时按标准/实际规则自动扣料。

反冲效率高，但主数据或报工不准会把误差藏到库存。关键材料/批次追溯通常需要扫码实领，低值稳定材料可反冲。

## 9. 报工

报工记录：合格数、不良数、工时、设备、人员、开始/结束、材料批次。边界：

- 累计不能无控制超过工单数量。
- 重复提交要幂等。
- 跨班/跨日。
- 撤销报工需反向库存和成本。
- 离线终端要同步冲突策略。

## 10. 质量

- IQC：来料。
- IPQC：过程。
- FQC/OQC：完工/出货。

不合格处理：隔离、返工、让步接收、报废、退供应商。质量状态必须影响库存可分配性，不能只显示一个 tag。

## 11. 完工入库与发货

完工入库增加成品库存，关联工单/批次和成本。发货常经过：分配 → 波次/拣货 → 复核 → 包装 → 出库 → 承运。

强一致边界通常在单系统库存变动；ERP 订单状态、财务开票、客户通知跨系统可用事件和对账保证最终一致。

## 12. 批次追溯

正向：某原料批次进入哪些工单/成品/客户。

反向：某成品批次用了哪些原料/供应商/检验。

数据链：收货批次 → 库存流水 → 领料 → 工单/报工 → 成品批次 → 发货客户。任何一个环节只存产品不存批次，追溯链就断。

召回需要：受影响库存冻结、客户范围、已发数量、通知和处置记录。

## 13. 库存几本账

- 物理库存：现场实际。
- 账面库存：系统记录。
- 可用库存：物理减分配/冻结等。
- 在途库存：已发未收。
- 在制品 WIP：生产中未完工。
- 寄售/VMI：所有权和保管地分离。

账实不符原因：漏扫、重复提交、单位换算、撤销未反向、负库存、批次错、盘点冻结失败、接口重放。

## 14. 盘点

流程：创建范围 → 冻结/基准快照 → 初盘 → 复盘 → 差异审批 → 调整流水 → 完成。

不能只直接 UPDATE 库存为盘点数；应保留账面数、实盘数、差异、审批和调整流水。

## 15. FIFO 与 FEFO

- FIFO：先入先出。
- FEFO：先到期先出。

食品/化工更重 FEFO。分配还要过滤 QC、召回、冻结、所有权和客户要求。

## 16. OEE

```text
OEE = Availability × Performance × Quality
```

- Availability = 实际运行时间 / 计划生产时间。
- Performance = 理论节拍产量 / 实际运行时间或等价定义。
- Quality = 良品数 / 总产量。

必须先统一停机分类、计划停机、理想节拍和数据采集来源，否则 OEE 数字可被“定义”操纵。

## 17. 成本

- 材料：实际用量 × 单价。
- 人工/制造费用：工时/机时 × 费率或分摊。
- WIP：未完工成本。
- 完工转成品。
- 发货/销售结转销售成本。

标准成本便于计划和差异分析；实际成本更贴近真实但计算复杂且结算滞后。

## 18. 采购三单匹配

PO（订了什么） vs GR（收了什么） vs Invoice（供应商开了什么）。匹配数量、价格、税、币种、容差，异常挂起人工处理。

只按单号相等不够，还要按行、部分收货、退货、附加费和汇率。

## 19. 纸器/包装行业特点

- 原纸克重、纸种、幅宽。
- 楞型与段成率。
- 印版、刀模生命周期。
- 油墨配方和批次。
- 拼版/合板：一次生产多个产品。
- 换单、洗墨、损耗。
- 面积/重量/张数/令数等单位转换。
- FSC 等认证链。

讲行业特点要连接系统字段/规则，不只列名词。

## 20. 业务面答题方法

被问“设计报工模块”：

1. 角色和场景。
2. 输入/输出单据。
3. 状态机与不变量。
4. 库存/质量/成本影响。
5. 异常：重复、撤销、离线、超报。
6. 权限、审计、租户。
7. 监控和对账。
