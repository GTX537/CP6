# 11 · Day 2 实验、面试题与答案

# 一、SQL 手写题

## S1：LEFT JOIN

列出全部仓库及其正库存数量，没有库存显示 0。要求解释过滤条件为何放 ON。

## S2：不存在

找出 90 天内没有任何交易的库存产品，分别用 NOT EXISTS 和 LEFT JOIN 写。

## S3：每组最新

每个“租户+仓库+库位+产品+批次”取最新一条交易。时间相同用明确 tiebreaker。

## S4：Top N

每个产品取数量绝对值最大的三次交易，说明并列是否保留。

## S5：运行余额

按产品计算流水余额，并找第一次小于 0 的时刻。

## S6：条件聚合

按仓库统计可分配、QC 冻结、召回库存三类数量。

## S7：BOM

递归展开产品 BOM，防环并汇总底层同一材料总需求。

## S8：去重

找重复角色权限映射，保留最新一条。先 SELECT 预览，再给事务内 DELETE 方案和唯一索引。

## S9：原子扣减

写单条条件 UPDATE 防止可用库存变负，并写出如何判断“不存在”和“不足”。

## S10：稳定分页

写 OFFSET 分页和 keyset 下一页查询，比较适用场景。

# 二、数据库实验

## DB1：NULL 真值表

插入 NULL、空字符串、C001、C002 四行，分别运行 `<>`、`NOT IN`、`NOT EXISTS`，记录结果。

## DB2：执行计划

对日期列运行 `CAST(col AS date)=@day` 和半开范围，比较实际计划与 logical reads。

## DB3：覆盖索引

构造 key lookup 多次执行的查询，加 INCLUDE 后比较；再说明写成本。

## DB4：并发

开两个 SQL 会话复现 lost update 或阻塞；记录时间线、锁和最终值。

## DB5：恢复演练设计

写出 Full + Log 备份恢复到新库的步骤、RPO/RTO 验收和应用 smoke test。不要在未知环境执行破坏性恢复。

# 三、前端实验

## FE1：响应式

演示 reactive 解构丢响应性，分别用 `toRefs` 和直接属性访问修复。

## FE2：watch 竞态

模拟 A 请求慢、B 请求快，复现旧响应覆盖新结果；用 requestId 或 AbortController 修复。

## FE3：Pinia

为权限 store 增加 idle/loading/loaded/error 状态并写单测；不要求改业务仓库，可在临时实验中完成。

## FE4：axios refresh

用 mock 同时返回三个 401，验证只发一次 refresh，每个原请求最多重试一次。

## FE5：组件

给 StockQueryView 设计组件测试：筛选参数、负数样式、QC 成功/失败、权限加载慢、i18n 切换。

# 五、参考答案要点

1. FROM/JOIN→ON→WHERE→GROUP→HAVING→SELECT→DISTINCT→ORDER→分页。
2. ON 过滤匹配候选并保留左侧；WHERE 过滤最终结果，右表条件常把空匹配去掉。
3. NULL 比较产生 UNKNOWN，WHERE 不保留；子查询可含 NULL 时优先 NOT EXISTS 或加非空约束。
4. WHERE 分组前过滤行，HAVING 分组后过滤组。
5. GROUP BY 折叠行，窗口函数保留明细。
6. RowNumber 不并列；Rank 并列有空洞；DenseRank 并列无空洞。
7. 排序值相同会非确定，分页/取一条可能漂移。
8. 不保证；主要是语句内具名表达式。
9. path 检测、数据约束、MAXRECURSION、深度监控。
10. 聚集叶层数据行；非聚集叶层键/include/定位。
11. 从等值、范围、排序、覆盖、选择性、查询组合和写成本共同决定。
12. 不一定；读取大比例或小表时 scan 合理。
13. 查询需要列都在非聚集索引中，减少回表。
14. 实际行、估算差异、IO、警告、膨胀节点、等待一起看。
15. 参数分布不同导致同一缓存计划不适合所有值。
16. RU、RC、RR、Serializable；另说明版本隔离。
17. RCSI 通常语句级 Read Committed 版本，Snapshot 是事务级一致快照并需显式/配置。
18. deadlock graph→统一顺序→缩事务/补索引→有界重试。
19. 条件 update、RowVersion、悲观锁、分区串行，按冲突率选。
20. 同事务记录待发布事件；不消除重复，消费者仍幂等。
21. EF 管模型/写入/普通查询，Dapper 精确复杂 SQL；Dapper 要手工租户等横切。
22. 未验证文件、密钥、步骤、耗时和应用可用性。
23. 通常被擦除，不自动验证 JSON。
24. `||` 把 falsy 都后备，`??` 仅 null/undefined。
25. 都表示未来结果；运行时、调度和取消模型不同。
26. ref 通过 value/整体替换，reactive 是对象 Proxy；选择看状态形态与解构。
27. computed 派生纯状态，watch 执行副作用。
28. if 创建销毁，show 切 display。
29. 局部 props/emits，深层 provide，跨页面 Pinia，布局 slots。
30. 跨组件/跨页面长期共享，局部弹窗/表单留组件。
31. 不是，后端授权是安全边界。
32. httpOnly Cookie 自动携带；非安全方法注入 CSRF header。
33. 共享 refreshPromise，排除 auth 端点，每请求 `_retried` 一次。
34. 加载前暂留按钮是 UX 选择；后端必须 fail-closed，敏感本地数据另行隐藏。
35. 服务端分页/虚拟化、稳定 key、减少 slot 计算、浅响应大型对象、测量 bundle/渲染。
