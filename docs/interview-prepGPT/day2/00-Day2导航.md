## SQL 的学习规则

每道 SQL 都做四遍：

1. 先画输入表与目标结果。
2. 闭卷写。
3. 在 SQL Server 实际运行。
4. 解释 NULL、重复行、并列值和空集。

只写“正常数据”不算完成。

## 前端的学习规则

每个页面都从数据流读，而不是从模板上到下背：

```text
用户动作
→ 响应式状态
→ 事件处理器
→ API 层
→ HTTP 拦截器
→ 后端
→ 响应
→ 状态更新
→ 组件重渲染
```
