# 三天冲刺与十四天深学路线

## 1. 先选择路线

| 路线 | 适合谁 | 每天时间 | 目标 |
|---|---|---:|---|
| 三天冲刺 | 72 小时内面试，已有开发经验 | 6～9 小时 | 补关键缺口，形成可输出答案 |
| 十四天深学 | 技术点会用但基础不系统 | 2～4 小时 | 从原理、项目到模拟面试完成闭环 |
| 维护路线 | 已完成一轮，等待更多面试 | 每天 45 分钟 | 保持手写和口述手感 |

如果是新手，不建议把三天路线理解成“三天掌握全栈”。它只是风险排序。

## 2. 三天冲刺路线

### 第一天：后端主链

| 时段 | 内容 | 输出 |
|---|---|---|
| 09:00～10:00 | 类型、对象、泛型 | 5 个 60 秒答案 |
| 10:10～11:20 | 异步、取消、并发 | 改正 4 段坏代码 |
| 11:30～12:20 | LINQ、IQueryable | 手写动态查询与分组 |
| 14:00～15:30 | ASP.NET Core、DI、管道 | 画请求管道图 |
| 15:40～17:10 | EF Core、事务、多租户 | 画读写隔离图 |
| 19:30～20:30 | Day 1 实验 | 跑最小实验并保存输出 |
| 20:40～21:30 | 口述复盘 | 录一段“库存 API 全链路” |

最低保底主题：`async/await`、DI 生命周期、中间件顺序、`IQueryable`、变更追踪、事务、多租户边界。

### 第二天：数据库与前端主链

| 时段 | 内容 | 输出 |
|---|---|---|
| 09:00～10:30 | JOIN、聚合、窗口函数 | 闭卷写 8 道 SQL |
| 10:40～12:00 | 索引、执行计划、锁 | 分析一个慢查询 |
| 14:00～15:00 | JS/TS 迁移心智 | C# ↔ TS 对照卡 |
| 15:10～16:30 | Vue 响应式和组件 | 修复 3 个响应性问题 |
| 16:40～18:00 | Pinia、路由、axios、权限 | 画前端请求图 |
| 19:30～20:30 | Element Plus 页面 | 解释 `StockQueryView.vue` |
| 20:40～21:30 | 全栈闭环 | 录一段库存查询 3 分钟回答 |

最低保底主题：JOIN 条件位置、NULL、窗口函数、复合索引、隔离级别、`ref/reactive`、路由守卫、Cookie+CSRF、前后端权限边界。

### 第三天：业务与输出

| 时段 | 内容 | 输出 |
|---|---|---|
| 09:00～10:00 | 自我介绍与项目主线 | 30 秒、1 分钟、3 分钟三版录音 |
| 10:10～11:30 | 三个故障故事 | 每个 30 秒和 2 分钟版本 |

| 15:40～16:40 | 需求、估时、沟通 | 回答 8 个场景题 |
| 17:00～18:00 | HR 与反问 | 准备个性化答案 |
| 19:30～22:00 | 三轮模拟 | 录音、评分、只补最高风险错题 |

### 三天路线的停止规则

时间不足时按下面优先级删除：

```text
必须保留：项目主线、SQL 手写、异步、DI/中间件、EF/事务、Vue 响应式、三个 STAR
可压缩：语法大全、组件 API 清单、冷门 C# 特性
可暂缓：编译器实现细节、完整 CLR/JIT 深挖、罕见 SQL Server 管理功能
```

## 3. 十四天深学路线

### 第 1～4 天：C# 与计算模型

- 第 1 天：运行时、类型、内存、OOP。
- 第 2 天：泛型、集合、委托、异常、可空。
- 第 3 天：Task、状态机、取消、并发与限流。
- 第 4 天：LINQ、表达式树、`IEnumerable`/`IQueryable`。

每晚输出：5 个口述答案 + 1 个最小程序。

### 第 5～6 天：ASP.NET Core 与 EF Core

- 第 5 天：启动、DI、配置、控制器、管道、认证授权。
- 第 6 天：映射、跟踪、加载、迁移、事务、多租户和审计。

输出：请求管道图、实体状态图、多租户绕过面清单。

### 第 7～9 天：SQL Server

- 第 7 天：SELECT、JOIN、聚合、子查询、CTE。
- 第 8 天：窗口函数、数据修改、数据库建模。
- 第 9 天：索引、执行计划、锁、隔离、生产排障。

输出：累计 30 道闭卷 SQL；至少 1 份执行计划对比。

### 第 10～11 天：Vue 全链

- 第 10 天：JS/TS、响应式、模板、组件、生命周期。
- 第 11 天：Pinia、router、axios、Element Plus、测试与性能。

输出：解释一个真实页面；写一个小 composable 和测试。

### 第 12 天：制造业业务

把“报价 → 订单 → 计划 → 工单 → 领料 → 报工 → 质检 → 入库 → 发货 → 应收”画成一张图。每个节点标：输入单据、输出单据、库存/财务影响、异常分支。

### 第 13 天：项目叙事与行为题

准备：

- 1 条项目主线。
- 3 个技术决策。
- 3 个故障故事。
- 2 个冲突/沟通故事。
- 1 个失败故事。

所有内容必须区分个人贡献和团队贡献。

### 第 14 天：全真模拟和回炉

上午技术面，下午业务面，晚上 HR 面。只复习评分最低的三个能力块，不再从头通读全书。

## 4. 维护路线

每天 45 分钟：

1. 10 分钟：随机 2 道 SQL。
2. 10 分钟：随机 2 道后端题。
3. 10 分钟：随机 2 道前端题。
4. 10 分钟：一个 STAR 或项目取舍。
5. 5 分钟：更新错题本。

每周至少完成一次 60 分钟技术模拟。

## 5. 何时调整顺序

- 后端强、前端弱：Day 2 前端提前到第一天下午。
- SQL 手写容易卡：每天开场先做 SQL，不要集中一天突击。
- 讲项目容易散：先学 Day 3 的叙事结构，再回头学技术，以问题驱动补知识。
- 离面试不足 24 小时：停止新增知识，只做速查卡、错题和录音。
