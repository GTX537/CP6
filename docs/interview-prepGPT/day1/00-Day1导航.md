# Day 1 导航：C#、ASP.NET Core 与 EF Core

Day 1 的目标不是背完 C# 语法，而是建立一条可解释的后端执行链：

```text
C# 数据与对象
  → 泛型、委托、异常
  → Task 与异步 I/O
  → LINQ 与表达式树
  → ASP.NET Core 请求管道和 DI
  → EF Core 查询、跟踪、事务
  → SQL Server
```

## Day 1 最终验收

不看资料回答：

1. 值类型和引用类型到底复制了什么？
2. 为什么金额使用 `decimal`，它是否绝对不会溢出或舍入？
3. `IRepository<T>` 的约束给实现带来什么保证？
4. 异步为什么提高 Web 服务器吞吐，却不保证单次请求更快？
5. `IEnumerable` 与 `IQueryable` 的分界在哪里？
6. Scoped 服务为什么不能直接注入 Singleton？
7. 中间件顺序错了会出现什么可观测结果？
8. EF Core 跟踪实体的成本和价值是什么？
9. 多租户查询过滤器能防住什么，防不住什么？
10. 用三分钟讲完库存写入的权限、事务、并发和通知边界。
