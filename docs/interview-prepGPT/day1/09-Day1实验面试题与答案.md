## LAB 5：LINQ 执行边界

## LAB 6：DI 生命周期

## LAB 7：中间件洋葱

# 三、参考答案骨架

## 1～5：类型与泛型

1. 值类型变量包含值，引用类型变量包含对象引用；存储位置不是定义。
2. 默认按值；引用类型复制引用。`ref/out/in` 才改变传递方式。
3. 哈希集合先按哈希定位，再判等；相等对象若哈希不同会落到不同桶，破坏查找契约。
4. 有身份/可变生命周期用 class；小型不可变值用 struct；结构化数据载体/值语义用 record，仍要检查深层可变性。
5. 约束让泛型实现能调用特定成员，并阻止不满足契约的类型实例化。

## 6～9：集合、闭包与异常

6. 复杂度忽略常数、分配和缓存局部性；小数据、顺序遍历时 List 更简单且可能更快。
7. 捕获对象延长生命周期、共享可变变量竞争、捕获 scoped 服务进入长生命周期。
8. `throw;` 保留原堆栈，`throw ex;` 重置抛出位置。
9. 通常不是；它是编译器的可空契约元数据和流分析。

## 10～14：异步

10. 不等于。I/O await 可以在等待期间不占线程；Task.Run/并行计算才可能使用其他线程。
11. 释放等待线程让其服务其他请求，提高吞吐；状态机开销和下游耗时仍在，单请求未必更快。
12. 不可以并发执行操作。每个并发分支用独立 scope/DbContext，或保持顺序。
13. 用受管后台队列、持久作业/outbox 或消息队列；保证作用域、异常、重试和关机语义。
14. timeout 是期限策略，cancellation 是合作信号；超时通常通过取消实现，但底层未必真的停止。

## 15～17：LINQ

15. IEnumerable 传委托在本地枚举；IQueryable 保存表达式，由 provider 翻译到数据源。
16. 会提前执行，后续过滤/分页落到内存，拉取过量数据。
17. DTO 投影、合理 Include、显式批量加载、拆分查询；需要平衡往返和结果膨胀。

## 18～23：Web 与安全

18. transient 每次解析、scoped 每 scope、singleton 每宿主。
19. 生命周期不匹配，会跨请求共享非线程安全上下文、错误租户或已释放对象。
20. Authentication 建身份，Authorization 根据身份和资源决定是否允许。
21. 不保密，只做 Base64Url 编码；签名主要防篡改。
22. 浏览器自动发送 Cookie，攻击站点可诱导写请求；需要同源不可伪造的 CSRF 证明。
23. 401 重新认证/刷新；403 显示无权限，不应无限刷新。

## 24～30：EF Core

24. 不是，按 scope 串行使用。
25. 只读查询，后续不需变更跟踪时。
26. 关系数据库中单次 SaveChanges 通常事务化；外部系统不在其中。
27. 用并发 token/RowVersion 加到 UPDATE WHERE，影响 0 行时抛并发异常。
28. 不能；存在 IgnoreQueryFilters、Dapper、特殊实体、写入非空错误 TenantId 等绕过。
29. 它直接生成 SQL，不进入 ChangeTracker 和 SaveChanges override。
30. InMemory 不等同关系数据库，缺少真实 SQL 翻译、约束、事务、并发和排序/NULL 语义。
