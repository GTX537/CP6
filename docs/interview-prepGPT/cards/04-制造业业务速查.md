# 制造业业务速查

## 主线

`报价 → 订单 → 评审 → BOM/工艺 → MRP → 采购/计划 → 工单 → 领料 → 报工 → 质检 → 完工入库 → 发货 → 开票/收款 → 成本`

## 系统边界

- ERP：订单、采购、库存账、财务。
- APS：物料/产能计划优化。
- MES：工单执行、报工、设备、质量、WIP。
- WMS：库位、批次、入出、拣配、盘点。
- PLM：产品/BOM/图纸/工艺版本。

企业边界会重叠，关键是数据权威和接口。

## BOM/工艺

- 版本、生效日、替代料、损耗、单位、虚拟件、联副产品。
- 工艺：工序、工作中心、准备/加工时间、质检点、外协。
- 工单下达时常需版本快照。

## MRP

`净需求 = 毛需求 + 安全库存 - 可用库存 - 可信供应`

再考虑 BOM、多层、提前期、批量、日历、冻结、QC。

## 库存

- Physical、Allocated、Available、In-transit、WIP、VMI。
- FIFO 先入；FEFO 先到期。
- 账实差：漏/重扫、撤销、单位、批次、反冲、接口重放、并发、盘点。
- 盘点：范围/冻结/快照/初盘/复盘/审批/调整流水。

## 生产

- 领料真实批次；反冲高效但依赖主数据。
- 报工防重复/超报/离线/撤销。
- IQC/IPQC/OQC；不合格隔离/返工/让步/报废/退货。
- OEE = Availability × Performance × Quality，先统一定义。

## 追溯

`收货批次 → 库存流水 → 领料 → 工单/报工 → 成品批次 → 发货客户`

正向找受影响成品/客户；反向找原料/供应商。

## 财务采购

- 三单匹配：PO vs GR vs Invoice，容差/部分/退货/税汇率。
- 材料 + 人工/制造费 → WIP → 成品 → 销售成本。

## 纸器

原纸克重/幅宽、楞型、印版/刀模、油墨批次、拼版、换型/洗墨、损耗、单位换算、FSC。
