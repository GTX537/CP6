# 项目叙事与 STAR 速查

## 自我介绍

`身份 → 两项能力 → 一个项目证据 → 岗位匹配`

- 30 秒：一个钩子。
- 1 分钟：两个证据。
- 3 分钟：背景/范围/架构/职责/深点/结果。

## 项目卡

`业务问题 → 不变量 → 实现 → 我的决策 → 证据 → 限制 → 改进`

主打候选：

1. 库存事务与移库限制。
2. 多租户过滤/盖章/后台/绕过。
3. Cookie+CSRF+refresh。

## 技术决策

`问题/约束 → A/B → 选择 → 代价 → 验证 → 何时改选`

## STAR+

`影响 → 我的责任 → 证据/排除/修复 → 结果 → 防复发`

主打故事：磁盘满、CSRF、租户写入/审计盲区。只用自己亲历、可核对的。

## 真实性

- 已实现 / 进行中 / 设计完成分开。
- 我独立 / 我主导 / 我参与 / 团队完成分开。
- 数字有日期、命令、口径。
- 不隐藏：Move 非原子、写租户边界、outbox 缺口。

## 不会时

`诚实边界 → 已知原理 → 验证方法 → 类似经验`

## 反问

- 前三个月成功标准？
- 当前最痛生产问题？
- 发布/监控/事故机制？
- 需求如何接触现场？
- 技术债如何排期？
