# 五个垂直切片实战

这些项目不是“看代码示例”。每个项目从需求和验收开始，要求你在独立分支实现、写测试、制造失败、记录证据，再做一次自我代码评审。可以只在练习分支完成，不要未经项目评审直接合入正式代码。

1. [把库位移动改成单数据库原子操作](01-原子库位移动.md)
2. [写一个租户安全的库存库龄报表](02-租户安全库存库龄报表.md)
3. [实现 latest-only 的 Vue 查询状态机](03-Vue最新请求状态机.md)
4. [把 Kafka 日志消费改成可恢复处理](04-Kafka幂等与通知Outbox.md)
5. [从零设计扫码报工垂直切片](05-扫码报工垂直切片.md)

## 通用交付物

每个项目提交：

- 一页需求/不变量。
- 一张数据流或状态机。
- 实现 diff。
- 正常、失败、并发/重试测试。
- 运行命令和结果。
- 未解决风险。
- 两分钟面试口述。
