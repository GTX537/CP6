## 每章怎么验收

每个原理必须能从四个入口回答：

```text
定义入口：它是什么？
代码入口：这段代码会怎样？
故障入口：什么症状说明边界被踩？
取舍入口：为什么不总用另一种方案？
```

只会第一个入口，仍然属于背诵。
