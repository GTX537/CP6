# CP6 面试准备 · GPT 开发者版

这是一套从 **CP6 真实开发任务**出发的制造业全栈训练材料。它覆盖 C#、ASP.NET Core、EF Core、SQL Server、TypeScript、Vue、制造业务和面试表达，只覆盖原目录的 Day1～Day3 范围，**不包含 Day4**。

Fable 版只作为覆盖检查表：它提醒本版哪些知识不能漏，但它的正文、章节组织和话术没有复制进来。GPT 版采用自己的“项目螺旋”结构：先解决一件完整开发任务，在途中下钻原理，再制造故障、写测试，最后把证据变成面试表达。

这版不再用“文档数量”和“标题数量”冒充详细。详细意味着你能回答：

1. 用户遇到什么，数据从哪里走到哪里。
2. 为什么当前实现这样写，事务和安全边界在哪里。
3. 网络、数据库、并发、取消或消息在最坏时点失败会留下什么。
4. 用什么测试和运行输出证明判断，不靠“应该没问题”。
5. 哪些是当前事实、哪些是建议、哪些是你真实做过的贡献。

## GPT 版的项目螺旋

每个主题都按同一顺序学习：

```text
用户问题与验收
  ↓
追踪 CP6 真实调用链
  ↓
遇到阻塞再下钻原理
  ↓
先预测，再运行
  ↓
故意制造失败与并发
  ↓
写回归测试和自我评审
  ↓
把证据组织成面试回答
```

只阅读正文不算完成。每个主线至少留下一个正常输出、一个失败输出、一条回归测试和一段两分钟录音。

## 三天使用方式

### Day 1：后端纵向切片

完成库存查询、库存写入、租户安全三个工作簿。原理按需阅读 C#、异步、LINQ、ASP.NET Core、EF Core。当天必须跑一次后端测试并画读写两条链。

### Day 2：数据库与前端纵向切片

完成消息一致性、SQL 排障、Vue 竞态和测试训练。至少保存一份实际执行计划或 IO、一份可控 Promise 竞态测试、一份消息重复故障矩阵。

### Day 3：业务与表达

完成制造业务建模、选择一个垂直切片写方案，再做证据账本和三轮模拟。不能把读码分析说成生产亲历。

## 难度标记

| 标记 | 含义 | 学习要求 |
|---|---|---|
| `L1` | 必须会，常规面试直接问 | 能用自己的话答出并举 CP6 例子 |
| `L2` | 区分度题，决定回答深度 | 能说明原理、代价和适用边界 |
| `L3` | 深挖题，不要求全背 | 知道入口，答到边界时不编造 |
| `LAB` | 必做实验 | 必须产生代码、SQL、命令输出或录音 |
| `TRAP` | 高频陷阱 | 能解释错误答案为什么错 |
| `EVIDENCE` | 项目证据 | 回答时可指向真实文件、测试或运行结果 |

## 三条真实性规则

1. **不把计划当成果**：仓库里有设计文档不代表功能已经生产落地。讲项目时说明“已实现、正在实现、设计完成”的状态。
2. **不把团队成果全说成个人成果**：使用“我负责”“我主导”“我参与”“团队完成”四种准确动词。
3. **不背会漂移的数字**：控制器数、页面数、测试数用命令现场统计，或说“截至某次验证”。
