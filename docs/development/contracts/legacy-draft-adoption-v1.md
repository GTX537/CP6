# W318：旧草稿的当前来源映射与向前采用

原WP12-03/04余项；当前实现中，实际验证/采用以W318交付为准。W316兼容HTTP和W317准确原生重基前恢复不重复。

## 当前信任边界

旧Wf_FormDef/Version与原生FORM定义按当前源码有意分离，同名不能当版本关联，旧状态、回填发布人/时间也不是可信发布凭据。保留UNVERIFIED_LEGACY原历史标记。新增映射仅表示现在授权的披露/复制来源，不证明过去的发布、实际人或原流程。

当前具有定义全部范围、Schema读取及独立form-legacy-source动作的管理员，显式绑定准确旧版本记录到真实不可变原生发布版本；两者Schema按既有原生规范JSON值比较必须准确相同。客户端给准确旧版本、源修订、目标key/发布GUID、前驱映射版本、启用与依据，不能让服务器用当前head替代历史版本。映射当前CAS、撤销和原操作日志同事务；撤去新写能力仍可凭当前读权查询原结果/关闭迟到。

只信任已经交付的原生发布/字段/权限合同，不重新包装其资格。旧可变记录是实际外部信任边界；旧版本和草稿原生写者在共同IAM门内推进准确修订，Source发生ABA也使旧预览或映射失效。旧行仍保留，旧接口不能直接改写它们。

## 内容与新草稿

本人历史目录保持只读。映射未登记、已撤销、旧版本改变、源归属/租户不符、当前Native字段或FORM政策不允许时，明确拒绝内容披露或向前采用；不返回空数据伪装无内容。内容仅按映射的准确原生版本及当前字段权限投影；隐藏字段不泄路径/值。

向前采用由用户在准确源预览后另行确认，严格DTO只含来源/映射前驱和依据，不接客户端Data覆盖。创建新的本人原生草稿，保准确原生pin及旧数据无损语义、来源和原命令；不改写旧行、伪造历史发布或复制原流程身份。当前add/edit/query、FORM政策、源资格、FILE可用性及最终会话同事务核对。无法映射的FILE或不合法旧值必须阻断，不造假父引用、转换、截行或静默丢字段。

当前映射的授权时点与技术可恢复期限使用可信新记录时间/现有明确FORM政策；原历史无可信时区的时间仅展示原记录，不倒推法律保留起点。旧历史仍留存，本窗没有清除或转换既有环境历史。

效果、不可变来源关联、历史和原回执同事务。未知提交只查同一原命令，NOT_OBSERVED不授权换号盲重做；显式关闭阻止迟到效果。当前读权重新投影已发生的新草稿原结果；源后续改变不把既有复制事实改成未发生。
