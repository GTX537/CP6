# WP02-02：真实服务签发租户事务实施计划

> 执行技能：subagent-driven-development；唯一实现者wave12_issuance。按项目精简规则连续实施，一次任务级集中SPEC/QUALITY审查，修改部分定向复查。

**目标：** 真实`POST /connect/token`的client_credentials路径，使用真实Basic/受控注册、普通租户连接、真实Sys_Tenants有效性与持久ServiceToken，最终提交前守住当前资格；同库签发令牌可通过既有真实撤销链路撤销，无活跃租户替身。

**架构：** 复用Platform0.10.3 trusted executor/accessor和TenantConnectionManager、同事务EF guard；在版本明确的显式fresh-only profile中提供实际目录及签发/撤销所需对象和最小权限。Sys_Tenants仍是Main共享权威表，服务只获准查询自身有效性；不另造主账，不授予花名册或任意维护权限。

**技术：** .NET8、EF/Npgsql、PostgreSQL18、自有Kestrel HTTPS夹具。旧profile和既有实体/模型/历史迁移保持原语义；没有在线迁库或生产启用。

已核对的具体方案：新`service-token-v1` / `service-token-tenant-rls-v1`，新`CrmIdentity:ServiceTokenTenancy`独占issue+self-revoke，与旧配置同时启用拒绝。Sys_Tenants原baseline含13列、PK、唯一Code和6个容量约束，无FK/RowVersion依赖；专用无tenant入参的受控helper按session_user精确读Enable/ExpireDate并FOR SHARE到commit，锁获得后及最终fence重新取clock。安装不从storage mapping自动创建或启用租户；显式控制身份管理真实目录，夹具据实种入合成权威行。普通运行登录没有跨租户issuance INSERT或目录枚举权限。

## 连续实施步骤与完成要求

- [ ] **1. 固定有限对象与权限。** 从真实baseline派生Sys_Tenants及其实际依赖、ServiceToken和既有撤销四类效果。新profile明确版本、初装/恢复和配置选择；旧service-revocation-v1与erp-identity-messaging-v1语义/seal不变。保留Id/TenantId、原索引/精度/容量，不写虚假的完整EF历史。精确目录访问与租户行锁需要最小受控helper时，固定search_path/owner/参数/授权并纳入seal；runtime不得读其他租户或更改目录/DDL。未知布局、错误profile、目录/权限/角色漂移拒绝。
- [ ] **2. 接入真实签发来源与租约。** 从原始Basic重新验证和冻结的真实服务客户端/组织注册生成Service actor与签发专用purpose/version；拒绝伪造tenant/default tenant/旧source/过期注册，未经认证不得打开业务池。签发Enabled/scope/CrmEnabled条件不能复用成撤销资格；停用签发仍可合法自撤销。明确配置更新仍需所有实例停止接入、排空、安静更新、重启，无热更新承诺。
- [ ] **3. 完成目录—记录—提交链。** 在一个受管物理事务中读取自身真实租户有效性并保存真实ServiceToken，原RecordAsync逻辑可提取同事务内核复用；不得内部另开默认连接或独立提交。签名成功且数据库commit确认后才能返回token；签名/存储/取消/最终fence失败不得返回可用成功。最终核验资格、到期时间和租户状态，与并发停用UPDATE通过数据库锁序列化，不能用两次普通SELECT冒充fence。保持ExpireDate合法输入、null与严格到期边界。提交后丢响应如实记不确定结果；原签发无幂等键，不伪称重试同token。
- [ ] **4. 显式启用和完整链路验证。** 生产DI/实际controller在新配置下走可信租户签发，缺布局/映射/权限失败关闭，不回退默认连接；新profile支持同一实际令牌的真实撤销。隔离无关后台服务可以，但认证、目录、签名、store、安装和写入不可用替身。旧配置/旧profile继续原支持范围。
- [ ] **5. 集中验证与交付。** 正向A/B真实HTTPS签发→持久记录→撤销；无效Basic、不获准client/scope/organization、缺失/禁用/过期租户、最终到期/配置期限、跨tenant读写/伪造输入、池复用、并发停用、提交前回滚、提交后响应丢失、新profile初装/同请求恢复/漂移拒绝。针对实际行为合并场景，不为字段逐字或实现镜像增加测试。保留原失败、只复用未变化证据，CLI通过私有stdin；完成一份DELIVERY并提交准确允许路径。
