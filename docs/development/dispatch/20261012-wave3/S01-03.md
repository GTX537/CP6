## 实现与验收

- [ ] 按原生FIN-CREDIT signedDecimal/nonNegativeDecimal/positiveDecimal三个域分别解析和输出，使用BigInteger系数及scale。明确最终字段profile，不凭字段名称猜测；包内4个signed、33个nonnegative、5个positive字段指针均有绑定记录。
- [ ] 接受38位整数及30位整数+8位小数；拒绝39位整数、31+8、scale9、负零、尾部小数零、指数、前导零、加号和空白。signed允许负数，nonnegative允许0，positive不允许0。
- [ ] 精确比较、对齐scale及加减/累加；中间值任意精度，max38+1-1成功而最终max38+1拒绝；负中间量后正结果合法。不使用decimal/double/float中转，不舍入、截断或钳位。
- [ ] JSON标量必须是符合profile的字符串；必填标量拒绝null/number/boolean/object/array，nullable/optional由所在字段决定。以既有Wire处理重复键和转义等价键；原UTF8独立保存，不能用解码后字符串证明原字节。
- [ ] 25条固定向量逐ID/期望系数/scale执行；另加profile误用、未知profile、算术中间溢出、最终越界、不同scale、错误token和原字节测试。
