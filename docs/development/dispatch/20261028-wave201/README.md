## 必须实现与验证

- 关系绑定准确当前制造版本、完整配置、真实 MBOM 输入和 Routing 工序；按位置保留同产品多次输出，不按产品去重或按数组下标推工序。输出主产品须与原兼容主 PRODUCT 一致。
- 每个输入/输出的规格与原产品、工序、完整配置均准确核对；受控关系证据和无输入依据由真实 Owner 提供，客户端文字不升级为授权或已批准证据。缺输入/工序、异配置、孤立输出、无依据无输入须拒绝或保持明确未就绪状态。
- 保存原完整关系 bytes/长度、独立 schema domain 摘要、版本历史、操作结果及审计；同键异体冲突，同键丢响应恢复，关闭未知操作后不可迟到落地。准确读/差异/恢复核当前来源读权。
- 独立专业确认准确绑定原制造内容、全部关系/数量/规格证据、实际人与授权，禁止作者自确认；来源变化、证据撤回、配置漂移或撤权阻止新的使用。只由本轮实际实现的原生 Owner 给出 HoldExact，不伪跨库原子。
- 来源检查使用新关系的准确版本和完整原件；技术 Manifest 与关系摘要独立，修改关系/配置使旧检查失效。旧未变化原件和既有购买成品检查证据保持原范围，内部制造不得凭缺关系给肯定冻结资格。
- UI 可实际选择准确来源并读回，分开草稿、专业确认、当前性与冻结状态；只保存身份隔离的未知操作键，禁止自动换键提交。
