## 要完成什么

在实际 CP6.WebApi 进程观察已加载 Platform 程序集、包版本、来源与运行身份，与明确输入的期望清单比较；将事实、声明和 Unknown/不匹配分开。现 `/health/release` 主要回显配置及 migration，不能因此声明包实际加载或兼容已验证。诊断只读且按既有授权保护，输出不泄露私有路径、连接串和凭据。

保留 `/health/release` 现有 version/gitSha/apiImageDigest/webImageDigest/latestMigration 字段与 no-store；新增诊断用兼容扩展或单独受保护端点，不改变既有健康含义。配置注册与健康路由只在本轮登记的 Program 小范围修改。`OwnedModuleObserverV1` 复制 DLL 到独立 ALC 不足以证明 Main 已加载的实际程序集，测试必须运行真实 Main 宿主。

实现基于证据的回退判断：缺失或不匹配兼容证据时明确拒绝；只有两个明确实际制品及对应 PostgreSQL schema/驱动组合验证后，才记录该范围兼容。先交付可靠运行观测和拒绝路径，不为制造正向结果臆断 0.10.3→0.10.2 可回退。正式 0.10.3 当前资格只包含 ctx-binding-v1/ctx-v1 的 Http/Message/Background；OBS 类型存在不等于正式 OBS 资格。
