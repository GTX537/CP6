## 要完成什么

交付用户能在现有 CodeGen 页面使用的安全即时预览：输入受控实体/字段信息，生成可审阅文本及模板版本、输入摘要、输出清单，清楚标明未应用。沿用固定模板，不接收任意模板、不执行代码、不写磁盘、不隐式保存元数据、不占用业务号码。

现 CodeGenService 直接将 EntityName/Module/TableName/RoutePath/Label/ClrType 等输入插入模板；需在渲染前按用途校验名字、类型和重复字段，对自由文本按输出语言正确转义。限制输出为安全建议文件名，拒绝目录穿越、路径/模板/代码注入。模板和类型白名单依据已接受设计及当前真实模板选择，保留安全合法输入，不能为了测试任意缩小合同。稳定的 templateRef/inputDigest/outputs 能追溯输入与模板。

现即时 POST preview 返回 `{code:0,data:Dictionary<string,string>}`，前端期待 Record；新增元信息采用有版本响应/端点并显式接入页面，或保留兼容包装，不能直接破坏旧字典形状。持久 GET preview 也调用 Generate，相关校验失败应明确映射到兼容错误；原有认证及 `pub-codegen:view` 权限保留，不借预览增加保存权限。

## 写入边界与验证

允许路径见下表；Controller 仅预览动作/相关错误映射，不改 Tables/Save 的读写流程和授权。SeqService/采番、GenTable/GenColumn 实体、EF/数据库迁移、Program、全局项目依赖和共享状态不改。本轮不实现数据库持久化、文件应用/覆盖或业务编号事务，不为预览开启 Main 存储接线。

相关验证覆盖合法输入与原响应兼容、非法类型/重复或保留字、路径穿越/文本注入、相同输入与模板的稳定摘要、无持久副作用以及实际 API 权限。做受影响测试、前端类型检查及必要页面检查；不为普通 UI 文案写镜像测试，不要求全仓构建。无 PG 资源；需要临时 HTTP/页面检查时只启动自有实例，用操作系统分配的空闲端口并在结束关闭。
