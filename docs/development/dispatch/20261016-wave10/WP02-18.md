## 实际行为

summary、未出货、库存滞留三组各自维护请求状态。初始尚未取得数据时不显示业务零；只有成功且响应结构符合现有合同的 `0` 或空集合才能显示零/无数据。403 清除该组旧结果并显示无权；网络/服务异常或必需字段缺失显示不可用，不能用默认零/空数组冒充成功。

首次 summary 失败不应阻断另外两组加载和既有 SignalR 生命周期。每组记录请求代次，旧成功或旧失败晚到均不能覆盖新状态；卸载后不回写。保留三组独立刷新，避免重新引入操作日志与 widget 刷新循环。只丢弃响应就报告丢弃，不宣称网络请求已取消。对已有可以观察到的身份变化清理过期展示，但不能把客户端清理称为服务端租户隔离证明。

保留现有 API 合同、导航权限和页面布局。可新增本地状态 helper 和定向测试；复用已有文案、i18n 与页面组件，不改公共 `CpStatCard`、权限/认证 store、HTTP客户端或全局生成资产。若现有响应无法区分某种语义，明确显示不可判定/不可用，不能凭客户端猜授权。

## 验证与边界

定向覆盖首次加载不闪零、成功零、403清旧值、500/缺字段不伪零、某组失败不阻断其他组、晚响应不覆盖新成功/失败、卸载后不回写与分组刷新。运行相关前端测试、类型检查及必要页面检查，一次集中审查；不用为状态字段逐项堆静态断言。

DashboardController 当前仍是 legacy KPI/缓存路径。本轮不改变后端、不新增 scoped KPI API或菜单CAS、不推断权限版本或宣称租户/撤权验收完成。这些留在完整任务及其 WP02-03 前置中。后续若发现后端活动BUG，通过 COORD/GitHub Issues 处理，不在本分支夹带修复。
