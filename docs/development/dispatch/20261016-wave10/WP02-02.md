首租户安装共享结构和受保护目录；后续租户在精确验证已安装结构、版本、权限及既有映射后追加登记、租户 schema 与最小权限。现有安装器是 first-install-only，不能循环调用或用 `IF NOT EXISTS` 接管未知对象。允许在现有安装器中抽取可复用验证/追加逻辑，保持 OID+登录名映射、NOLOGIN helper、固定 search_path、目录锁序、RLS USING/WITH CHECK、全局唯一域及最小授权。schema 创建不能代替隔离与授权。

持久记录明确初始化操作身份、规范输入、数据库身份、profile/迁移版本、租户/登录映射及结果；凭据不进入指纹正文、日志或报告。同一操作同输入重试返回原结果，不重复建对象或放宽权限；不同输入冲突拒绝。并发首装/追加需有确定串行化边界。事务提交前中断可以重试；提交完成但响应丢失应通过持久结果恢复，不能把网络错误直接判成未执行。未知结构或不完整状态必须明确拒绝/恢复，不能随意标 Ready。检查结果只宣称此组合消息存储 profile 可用。

迁移/初始化身份与运行登录分离。命令显式选择目标，不从默认业务连接推断，不挂 WebApi 启动钩子；凭据通过安全的进程输入/配置引用提供，不能出现在命令行、输出或仓库。此轮执行只用新建自有测试集群，不操作任何现有业务库；实现工具不构成部署或迁移授权。

## 未包含的实际业务接线

Main 目前无生产可信 source verifier/binding authority；旧 TenantMiddleware 的默认租户不能提升成可信上下文。IdentitySnapshotWriter 写集还含 Snapshot、普通 Outbox、ServiceToken/浏览器令牌及授权表；ERP handler 仍访问 Core 业务表。直接把消息连接替换成新租户连接会破坏原子性或权限，因此本轮不做该切换。后续可优先限定 `/connect/service-revocations` 的真实自撤销写集，补准确 Core RLS、真实认证和同事务接入，不要求先迁完328张表。本轮不关闭原17 PGT或声明整项 DONE。
