## 设计与边界

采用独立 `Main Quality / QA-NCR-01` 的退货质量适配合同v1。它签发原RMA `QualityDecisionRef` 四态分区；RMA只读取和采用。原QA-NCR R5仍为设计稿，本轮不冒称完整NCR API已实现或旧资格记录已被批准。相比在WMS直接判断，独立Owner保留专业权限；相比继续记录静态缺失，实际实现质量写入和原结果恢复能直接推进目标。

每个实收行形成一个准确坐标的检验义务，保留实际原生入库、Stock流水、份额与数量。质量政策/检验证据由显式模拟配置提供，实际权限、四态完整无重叠分区、版本、独立签署、不可变事实与原命令由PostgreSQL代码执行。当前来源无冲正，VOID为空；来源冲正必须后续接入真实更正链，不用任意VOID减少数量。质量决定不移动库存或自动完成商业、财务、五种终端处置。
