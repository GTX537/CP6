# BUG-905 — 有效功能配置当前查询

W452-01；Issue [#905](https://github.com/GTX537/CP6/issues/905)；基线 `16e346664431272f83edf64c46106a141542a535`。本报告记录已实际执行的本地结果；最终远端采用、分支处置和 DEV-2 释放以对应 PR、远端 main 与 `manage.ps1 finish` 为准。

## 改动

原 `/api/v2/admin/wms-features` GET 在控制器检查缓存动作后直接查询 DbContext。现在由既有功能控制 Owner 的 `GetFeaturesAsync` 承担读取，复用实际签名会话、同 Context 当前 `wms-mobile:device-manage` 与认证父事务，先取得共同认证根，再对实际配置表取得 SHARE，完成读取及最终会话/取消检查后返回。

原查询表达式整体移入 `GetFeaturesCoreAsync`：同一租户与删除过滤、仓库排序、五个 DTO 字段和原 RowVersion Base64/空值表示全部保持。既有服务接口只增只读成员，控制器注入该服务，Program 现有工厂保持。原直接 PUT 的 410 主体和权限点保持，无默认授权、模型、迁移、包、缓存或工作流修改。

共享边界只增加内部固定的配置/申请表选择；既有申请入口使用默认 false，生成原相同表名、模式和授权/会话/事务/错误逻辑。集中审查以精确逆向比较确认旧路径原字节等价，未重复新增身份或依赖资格检查。
