- `POST /api/fin/cost/{workOrderNo}/settle` 以原 `fin-cost:settle` 在请求 Core 事务取得 Main 共同栅栏。成本单、WIP、FG、差异凭证、分录、期间与采番一并提交。原错误经整体回滚后返回。业务先提交保留三张原凭证，暂停或撤权先提交返回 401 或 403，写集保持。核对 Main 原权限版本、回执和出站状态，同号工单在第二个租户的读回保持。
- 原版七项实测中五项复现。暂停和撤权两种顺序未共同排序。模拟成本 87.96、标准 77.98，非末级 COGS 导致第三张凭证原 400 `E-FIN-104`，旧版保留两张凭证、六条分录、期间及 GL 采番。修复后按原错误整体回滚，修正科目后成功结转，三张凭证分项为 87.96、77.98、9.98。零值仅改成本单，成本归集实际返回 `FINANCE_OWNER_REQUIRED` 503，均验证原合同。
