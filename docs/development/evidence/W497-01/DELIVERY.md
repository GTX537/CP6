## 实测行为

合法模拟询盘经公开 HTTP 提交并转 Lead。具备当前签名权限的操作者请求导出，得到 HTTP 202 和状态 20。使用既有程序集内部测试访问入口给同一个 Worker 传入 1024 字节阈值。生产入口使用固定 10 MiB，上限没有新增宿主配置。测试请求使用合法宽字符内容，实际序列化后的字节数触发拒绝分支。

Worker 提交 20→90，返回一条拒绝。HTTP 读取返回同一 Job 的请求时间与完成时间，到期时间、制品 ID 和下载凭据均为空。文件下载返回 410。PostgreSQL 只保留原请求审计与一条版本 2 的 `privacy.export.reject`，分别绑定申请人和签名服务身份。拒绝时钟与终态及 HTTP 完成时间一致，制品表无行。

同键同 If-Match 重放恢复原 202 正文及 ETag。默认 Worker 再扫零条，库内仍只有一个 Job、一个请求效果和一条出站消息。
