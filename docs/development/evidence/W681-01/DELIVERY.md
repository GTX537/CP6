- 看板 WarehouseName 必须满足 `wms-warehouse:query`、WarehouseName 读取及 MasterWarehouses 的当前真实对象范围。只读取实际可见库存分组所需的仓码；缺少来源 query 或名称读取权时为 null，来源范围外、已删除或其他租户的名称不会披露。仓码、StockValue、SkuCount 沿原授权库存集合和金额合同保留。
- 客户分组名称同时满足本资源 CustomerName 与 `erp-business-partner:query`、BpName 读取、BusinessPartners 当前对象范围。隐藏或不可见名称时显示原客户码，数量、参考值、分组和排序不变；CustomerNameReadable 在客户分组时反映两端字段/动作交集，不代表每个来源对象可见。产品分组或自身名称隐藏时不额外读取客户来源。
- 仅明确的来源 `ACTION_FORBIDDEN` 用于可隐藏名称投影；来源不可用、注册域错误和最终权限故障继续失败，不能静默变成空名称成功。两类已取得的来源决定参与同一事务的最终复核；原生权限及仓库/客户表锁复用当前 Owner，不重复建锁或证明包装。
- 名称仍为业务码的显示关联，没有据此构造 UUID 身份、TradingEligibility、Finance 估值或计费资格。VMI 历史账单快照不受此当前主数据名称修复影响。保留非 PostgreSQL 历史分支，不新增 SQL Server 实现或验收。
