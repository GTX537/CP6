# W608-01 应付发票及付款的共同事务栅栏

2026-11-15 UTC。开发基线 `59f379a0a11fb47a71adec340e245ab0d2c1475b`，受测源码 `05b3ef627919f132d15df628f955db70afae736e`。隔离 PostgreSQL 18.6、实际签名 Main Kestrel、模拟会计和双租户数据。 [缺陷 #1125](https://github.com/GTX537/CP6/issues/1125) · [PGT-017 #1012](https://github.com/GTX537/CP6/issues/1012)

- 五条 HTTP 入口包括应付发票新增及过账、付款新增、撤销和核销。原动作在同一 Core PostgreSQL 事务获取 Main 栅栏。失败的凭证、差额冲销和核销使用原业务错误，并回滚采番、期间、发票、付款、凭证、分录和核销。新增的付款与发票表头和明细归已认证租户，实际存在的财务引用按当前租户核对。
- 原版实测未按共同栅栏排序、跨租户落单及错误后仍保留凭证或采番。晚失败覆盖已采番后非末级科目、第二条核销失败、主凭证不可冲销与差额凭证失败。候选保留合法可选引用、原收付金额精度和现有业务错误。采购调用使用其原业务上下文，继续独立验证接入范围。现金折扣撤销的原币回退是另一个源码观察，需独立复现和核对无损表示。
