## 问题和实现

装箱、拆箱、拆分、合并四个真实 HTTP 请求均复现：前置认证通过后，在租户暂停先提交的情况下仍返回 200，并修改 LPN 树、内容、序列号、事件或回执。原同操作号回放也在当前授权事务之外。

四个 PostgreSQL 命令现通过既有 `OperationsOwnerV1` 的 `wms-mobile:lpn-manage` 动作执行，复用共同认证根、当前 actor 和提交前授权检查。创建使用的包装提取为命令共用方法，核心业务逻辑与原事务复用方式不变，回放在 Owner 内执行。入口参数校验保持；事务内 ArgumentException 按已有业务 InvalidOperation 协议回滚并保持 HTTP 400。原 MobileTaskConflict/NotFound 协议保持；四个控制器动作采用已有 `OrderOwnerResult`，保留 Owner 的 401/403/503。没有新增数据库迁移或外部合同。
