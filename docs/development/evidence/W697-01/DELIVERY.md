## 业务行为

- 财务人员在本人账套提交成本政策和费率依据的不可变内容。复核人须独立于制订人，并具备该类版本的有效专业资格。发布时核对当前发布资格及原复核人的同一资格，实际取版使用已发布原件。
- 费率依据准确绑定已发布政策、工作中心及工序。采用半开有效区间，已定义结束日的前版可安排后继，后继沿用根身份并递增版本。每个前版只有一条可发布后继。零费率同时要求政策允许和专业复核过的明确零值理由。财务归集按账套会计日读取发布的费率，并保存绑定的政策和费率依据版本。
- 送审、复核、发布复用 D28 与 C28。发布行、供实际归集使用的政策或费率依据及命令回执在同一事务提交。回查同时核对当前账套、主数据权限和依据的实际工序、产品来源。历史回执保留执行当时的内容和状态。

## 本地验收

- Windows、.NET 8、PostgreSQL 18.6 的隔离数据库与签名 HTTP，业务数据为模拟。实际发布两代成本政策和两组费率依据，再发布工序费率并归集。相邻日期使用各自版本，原成本快照逐字保持，第二代批准的零制造费实际入归集。已批准的旧版跨期后拒绝新采用。
- 定向覆盖本人及账套、独立批准、复核资格撤销、未发布和超有效期、零值权限、跨账套和来源读权。发布事务故障后按同键重试，实际版本与回执共同提交。最终签名 HTTP 复测覆盖 W697 主数据发布及 W696 标准单据与 C28。W692 中心采用和 W690 现行用版复用首次通过证据。执行证据见 `acceptance.trx`、`delivery.trx`。[PostgreSQL 用例](../../../../CP6.Tests/Erp/ManufacturingCostSourcePostgreSqlTests.cs)
