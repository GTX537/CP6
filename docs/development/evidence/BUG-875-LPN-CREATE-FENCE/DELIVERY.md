## 问题和实现

实际复现了已通过 HTTP 前置检查的创建请求，在租户暂停先提交后仍返回 200，并新增完整 LPN、闭包、事件及回执。原创建回放也位于当前授权事务之外。

PostgreSQL 创建入口现使用已有 `OperationsOwnerV1` 的 `wms-mobile:lpn-manage` 动作，在共同认证根事务中执行原创建核心及回放，采用当前 actor，提交前校验授权。既有核心识别并复用 Owner 事务，不提前提交。业务参数校验仍在入口，事务内的业务参数错误按已有 InvalidOperation 业务错误协议回滚并保留原 HTTP 400 文本。控制器原通用 catch 现在放行 Owner 错误，由已有 `OrderOwnerResult` 保留 401/403/503。
