- 现有会计科目菜单接入 Vue 授权账套、准确提案正文、工作流动作、发布前后完整区间、旧科目及标准模板批次、历史修订和原操作。新增页也可直接走 `/fin/master/accounts`。旧服务与 API 中已登记版本账套的直接写入受当前 IAM 和 PostgreSQL 双层守卫。

- 发布在同一 PostgreSQL 事务核对当前来源门、账套门、原操作、对象头及完整候选时间线。发布、单次预览消费、状态、原回执、审计原件与本地通知 Outbox 同次提交。通知仅携准确账套、修订与 Root 的刷新事实。暂停决策保留当时的原时间线；后继发布保留暂停。后续恢复有绑定当前时间线的新决定，退休终态保留历史和编码。
- 上级和子图按候选区间断点核对，发布父链验证 32 层边界。暂停仍占角色，退休自账套业务日起截断未来占用。用途入口返回资格观察及原因，任何时点观察的 `isExecutionPermit` 均为 false。真实凭证、BP、AP/AR、红冲、原 UseReceipt 和通知投递接收方仍需各业务卡在原 Owner 实际验收。
