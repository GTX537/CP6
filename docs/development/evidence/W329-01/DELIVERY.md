## 实际验证

Windows、PostgreSQL 18.6、Npgsql 8.0.8、net8.0，使用本地 SDK 10.0.302 和模拟 A/B 租户。

- 新增 PostgreSQL 用例通过。真实原 journal 与原 Outbox 在同一普通 LOGIN 事务保存，提交前独立连接不可见，回滚后原命令、源引用和消息均消失。两租户同一操作 ID 分别产生原合同消息键，跨租户读取受限。
- 原事务以外的历史原命令尝试入队，在提交时由现有源证明拒绝。普通登录直接修改通知权威行或消息状态被拒绝。
- 既有原生 Worker 回归通过，覆盖旧入口的路由建立、空租户提示派送和持久化原命令读回。两项实际 PostgreSQL 用例合计 2 通过、0 跳过。
- Release 安装工具在自有 PostgreSQL 的独立模拟库实测缺 journal 授权拒绝、路由准备、安装回执、窄权限和重复拒绝。基线 `red.trx` 保留原入口缺租户锁权限的失败。 `green.trx`、`worker-regression.trx`、CLI 和停止证据在 `D:/CP6-local-test/CP6-72H-20261109/W329-01`。
- 集中审查覆盖同一事务、原锁顺序、RLS 和最小权限、现有延迟证明、原入口兼容和 CLI 回包。保留既有依赖告警。普通 Actions 为手动入口，R2 自动入口匹配版本标签。
