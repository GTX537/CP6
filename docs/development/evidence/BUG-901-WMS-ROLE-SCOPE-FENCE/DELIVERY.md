# BUG-901 — 仓库角色范围当前授权与整组替换

W450-01；Issue [#901](https://github.com/GTX537/CP6/issues/901)；基线 `ac73038fe9edc5d8041eab5fdd0bb014b9049bc0`。本报告记录已执行的本地验证；本任务最终远端采用、分支处置及 DEV-2 释放以对应 PR、远端 main 和 `manage.ps1 finish` 结果为准。

## 改动与业务边界

现存 `WmsRoleScopeService.Get/Replace` 使用既有 `pub-data-scope:query/edit`，通过同一个 CP6Context 的 IAM 父事务和实际签名会话，在共同认证根之后决定当前 actor、租户及动作。范围表查询使用 SHARE、替换使用 SHARE ROW EXCLUSIVE，随后对实际 `Sys_Roles`、仓库、库位表取得 SHARE 锁，按当前启用角色和未删除仓库/区域验证。末尾验证同一会话并传递取消；回滚清理跟踪状态，防止日志 SaveChanges 重刷未完成权限变更。未知提交明确返回错误，不盲目重试。

保留一参数构造器、非 PostgreSQL 既有路径、HTTP 原列表成功体、角色 1 全范围读取/不可修改、启用角色要求、规范化与去重、通配符、空集合清空以及 200 项上限。引用校验从逐项查询改为至多两次集中读取，再校验精确仓库/区域配对；不缩减合法输入。各项错误码保留；同时含多类非法项时先报告格式/通配符错误，错误先后次序不宣称与旧实现逐项查询完全相同。未新增权限点、默认授权、实体模型、迁移、包或工作流配置。
