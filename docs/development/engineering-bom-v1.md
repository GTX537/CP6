# BOM 工作稿与准确材料来源 v1

`Main.Plm.EngineeringBom.v1` 维护独立 EBOM/MBOM 身份、不可变版本及稳定结构位置。页面 `/plm/engineering-bom`，API `/api/engineering-bom/owner-v1`，权限资源 `plm-engineering-bom` 分别使用 `query/add/edit`；迁移登记菜单和动作，不授予角色权限。

## 结构与准确来源

创建时明确当前工程修订及准确根产品；同一 BOM 的根产品身份、修订身份、视图种类和创建人 UUID 不变。修订采用预期版本与 Etag，持久保存原因、操作者、父版本及全部原件。每个 Occurrence 有自己的 UUID、父位置、路径和同级顺序；相同材料出现在不同位置时不合并。移除、移动或修改一个位置不改写旧结构或旧工单。

材料来源可明确选择既有经营产品原版本，或工程产品原版本。两者保持不同 Owner，不按物料编号猜测等价，不要求先发布工程基线才允许读取基本经营材料。经营原件来自已有 ProductIdentity 捕获链，工程原件来自已有 EngineeringProduct；没有新增可写物料主账。经营身份本身不证明技术修订或生产资格。

数量及损耗为精确十进制字符串，整数和小数各支持 1024 位，保留原值而不经过浮点舍入。用量单位引用准确 UOM 版本；用量分母/基准、损耗基准和依据分别记录，不默认每单位根产品、不自动换算、不补系数 1。单位定义的存在和来源匹配不等于该材料用量或转换已经获批。

MBOM 可引用同一修订和准确产品的工艺版本，以及该版本内的具体工艺 Occurrence。工艺来源、场所一致性和位置存在性分别核对；未知位置保留缺项，不根据 ProcessCd 猜测。制造映射、替代批准、配置适用和冻结仍有明确后续责任。

## 草稿与完整性

重复位置 UUID、重复路径或同父位置同顺序、无效数值、伪造引用拒绝保存。未知材料/单位、循环或父位置缺失、祖先材料自包含、非正用量、损耗依据不足、单位精度冲突和待批替代可以保存为草稿，但明确返回对应位置的缺项。输出始终为 `DRAFT / DRAFT_ONLY`，没有可执行或已冻结状态。

工程修订的 EBOM/MBOM 组成选择种类匹配、同一修订/准确产品的当前 BOM。新采用重新检查真实来源；历史组成保留旧引用并报告变化。BOM 读取准确父修订原件而不递归展开组成，避免父子循环。材料使用位置查询按准确 Owner/UUID/版本/摘要匹配当前 BOM 原件，分别返回每个位置；不把未获权的结构纳入结果，也不宣称覆盖所有后续业务引用。

## ProductMaterial 原件适配

`POST legacy-preview` 接收准确且当前已确认的双 Owner 产品映射，读取该经营产品真实 `T_ProductMaterial` 原行；摘要包含准确映射、经营产品及有序原件。显式采用时，命令只携带映射与预览摘要，服务端在同一事务重新读取核对；原行已变化则拒绝。

原行全部保留。建议位置以真实行 UUID 定位，静态定额保留精确 UnitUsage；尺寸驱动行保持数量待解析，不补默认用量。MaterialCd/ItemCd/UsageUnit/ProcessCd 作为原文字段保留，不自行提升为准确材料、单位、工艺位置或替代许可。重新导入产生新版本，历史原件不会随旧数据更新而重写。

## 权限、事务与恢复

BOM 自身动作授权独立；部门范围继承不可变父修订的可信部门映射，创建人范围使用 UUID，全部查询保留 TenantId。读取历史、差异、使用位置和原操作都重新检查当前 BOM 及各实际来源权限。来源失权不通过旧摘要绕过。

在根 Main PostgreSQL 事务中保存当前头、不可变版本、原操作与审计，并重核最终授权；任一失败全部回滚。相同 OperationId/请求返回原结果，异体拒绝。`operations/{id}` 查询原结果，`operations/{id}/close` 关闭未提交键；结果未知时不换键重发，关闭后迟到写入被拒绝。

页面用浏览器锁协调同一租户/用户，只持久保存操作与对象 UUID。身份变化或当前权限拒绝清除业务内容，迟到响应不恢复旧身份资料；读取历史不覆盖未保存编辑。
