# 开发大任务评估

14项是业务工作包。WP01负责全局评估，WP14负责跨域验收协调，其余12项各自拥有目标；跨域合同可以有多个参与方，但一个Target只有一个归属。

规模L/XL是相对范围与风险，不是工期；置信度均为LOW。已有实现入口是复用候选，未代替逐目标语义核对和实际测试。

## WP01 现有实现与设计对照

**成果：** 形成125目标的实现差异、复用边界和开发批次。

**现有基础：** 已有固定代码对照及本轮源码入口盘点；逐目标符合性尚未确认。

**规模与置信度：** L / LOW；按目标数量、跨域依赖和一致性风险作初步规模判断；未估算人日，逐目标源码评估后修订。

**分批业务范围：**

- 固定三仓源码和包身份
- 逐目标核对接口/表/页面/测试
- 原验收清单和修订场景合并登记
- 选择首批业务切片

**进入条件：** 固定Main/CRM/Platform源码和已接受R1设计组合。

**完成条件：** 125目标均有固定源码差异结论、原验收清单、范围和批次决定。

**重点风险：** 旧实现与新合同不能直接等同；候选分支不能当主线能力；资料缺件保留影响边界。

**协作包：** 全局基线输入。这些是接口协作关系，不表示必须等待对方整包完成。

**目标归属：** 全局协调工作，不另占125目标名额。
