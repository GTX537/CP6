## 三、ProcessCostRate 工序费率（A2）— POST /api/mes/process-cost-rate/upsert

**前端**：`/mes/process-cost-rate`（`router/index.ts:85`）→ `ProcessCostRateView.vue`，`submit`（`:101-113`）→ `processCostRateApi.save`，`laborRate/overheadRate`(min 0)，`validFrom` required、`validTo` 可空=长期。api `processCostRateApi`（`processCost.ts:21-31`：`list`/`save`/`remove(id)`）。
**后端**：Controller `ProcessCostRateController`（`:19-25`，含 `[HttpGet("resolve")] Resolve(wgCd, onDate)` 按基准日解析单条有效费率）。Service `UpsertAsync`（`ProcessCostRateService.cs:27-62`）核心**区间重叠校验**：
```csharp
if (dto.LaborRate < 0m || dto.OverheadRate < 0m) throw new InvalidOperationException("E-A2-RATE-003: 费率不可为负");
if (dto.ValidTo is { } vt && vt < dto.ValidFrom) throw new InvalidOperationException("E-A2-RATE-004: 失效日早于生效日");
if (!await _db.WorkCenters.AnyAsync(x => x.WgCd == dto.WgCd && !x.IsDeleted))
    throw new InvalidOperationException("E-A2-WC-001: 工作中心不存在");
var newTo = dto.ValidTo ?? DateTime.MaxValue;
foreach (var s in siblings) {
    var sTo = s.ValidTo ?? DateTime.MaxValue;
    if (dto.ValidFrom <= sTo && s.ValidFrom <= newTo)
        throw new InvalidOperationException("E-A2-RATE-001: 费率生效区间重叠");
}
```
`ResolveAsync`（`:19-25`）取 `ValidFrom ≤ onDate ≤ (ValidTo ?? +∞)` 中 `ValidFrom` 最新一条——成本归集取费率入口。实体 `ProcessCostRate`(`T_ProcessCostRate`,`LaborRate/OverheadRate decimal(21,8)`,`ValidFrom/ValidTo?`)。

**⭐专讲（工时×费率成本计算 — 真实公式）**：费率主数据只在此维护；**金额计算在财务成本归集** `Fin/CostCollectService.cs`（注入 `IProcessCostRateService` 按基准日解析）。逐工序公式（`CostCollectService.cs:98-114`）：
```csharp
var stdMachine = (pp?.SetupHour ?? 0m) + calcQty * (pp?.CycleTime ?? 0m);   // 标准机时 = 段取 + 完工数×CT
var stdLabor   = stdMachine * (pp?.StandardCrewSize ?? 1m);                 // 标准人工工时 = 标准机时×标准人数
var rate = await _rateSvc.ResolveAsync(w.WgCd ?? "", baseDate);
var actMachine = w.ActualMachineHour ?? stdMachine;   // 缺实绩→回退标准
var actLabor   = w.ActualLaborHour   ?? stdLabor;
var laborActLine = Math.Round(actLabor   * rate.LaborRate,    2, ...);  // 人工实际 = 实人工工时×LaborRate
var ohActLine    = Math.Round(actMachine * rate.OverheadRate, 2, ...);  // 制费实际 = 实机时×OverheadRate
```
即 **人工=实绩人工工时×LaborRate；制造费=实绩机时×OverheadRate**；实绩缺失回退标准工时并打 `W-A2-COST-001` 警告。基准日 = `ActualEndDate ?? PlanStartDate ?? CreateDate`。
**错误码**：`E-A2-RATE-003/004`、`E-A2-WC-001`、`E-A2-RATE-001`；成本侧 `E-A2-RATE-002`(无费率)/`E-A2-COST-001`(无工序)。

## 四、PlanAchievement 達成率（ME 分析）— POST /api/mes/plan-achievement/summary

**后端**：Controller `Summary`（`PlanAchievementController.cs:23-28`）。Service `GetSummaryAsync`（`PlanAchievementService.cs:33-...`）：过滤 `!IsDeleted && Status!=Cancelled && ProductionQty>0`（`OnlyCompleted` 时只取 Completed/Inspected，否则 `Status>=Issued`）→ 内存按基准日 `refDate=(ActualEndDate ?? **⭐专讲（达成率口径②）**：
- **达成率 `AchievementRate = GoodQty/PlannedQty`**，`GoodQty=Σ CompletedQty`、`PlannedQty=Σ ProductionQty`。

- 全经 `Rate()`(四舍五入 4 位 AwayFromZero)。
**CSV 导出** `POST /export-csv`（`:30-35`，`File(...,"text/csv; charset=utf-8")`）→ `ExportCsvAsync`(复用汇总 + UTF-8 BOM + CSV 转义)。无业务错误码（纯报表）。

**⭐专讲（存储过程聚合 — 真实 SQL）**，定义在迁移 `Migrations/20260518115050_AddMesStoredProcedures.cs`：
- `usp_GetMesDashboardSummary`(`:44-86`)本日 KPI 单往返。
- `usp_GetMesDailyTrend @Days`(`:96-128`)用**递归 CTE 补全日期序列**再左连聚合（无产出日也出 0）：
```sql
;WITH Dates AS (
    SELECT @from AS d UNION ALL SELECT DATEADD(day,1,d) FROM Dates WHERE d < DATEADD(day,-1,@to)
),
Agg AS (
    SELECT CAST(CreateDate AS date) AS d, SUM(GoodQty) AS GoodQty, SUM(DefectQty) AS DefectQty
    FROM T_ProductionResult WHERE IsDeleted = 0 AND CreateDate >= @from AND CreateDate < @to
    GROUP BY CAST(CreateDate AS date)
)
SELECT CONVERT(varchar(10),D.d,23) AS [Date], ISNULL(A.GoodQty,0), ISNULL(A.DefectQty,0)
FROM Dates D LEFT JOIN Agg A ON D.d = A.d ORDER BY D.d OPTION (MAXRECURSION 366);
```
配 2 个覆盖索引（`IX_T_ProductionResult_CreateDate_IsDeleted` INCLUDE GoodQty/DefectQty/MachineCd、`IX_T_WorkOrder_ActualEndDate`），注释称比 EF 版快 30-60%。

## 关键发现
1. **「拖拽」非真拖拽**：CSS 绝对定位甘特，改期=点击 Bar→弹窗→PUT，服务端硬约束「仅未着手可改」。
2. **达成率两套口径**：PlanningBoard KPI `CompletionRate`=完了工程数/全工程数；PlanAchievement `AchievementRate`=Σ良品/Σ计划数量。
3. **工时×费率不在 MES 而在财务**：费率主数据维护在 `ProcessCostRateService`，金额计算在 `Fin/CostCollectService`（人工=实人工工时×LaborRate、制费=实机时×OverheadRate）。
4. **A2 错误码另一套** `E-A2-WC-001/003`/`E-A2-RATE-001/003/004`，PlanningBoard 用 `ME-MSG-003/041/042/043`。
5. **PlanAchievement 用 POST body**；**Dapper/SP 版前端未接入**（性能样板）。
