## Docker 故障与保留

原目录的旧套接字返回 Windows 1920。只读目录句柄检查表明父目录与 `docker-secrets-engine` 位于不同卷，句柄改名返回跨磁盘错误；把故障目录保留到同卷 Docker 目录后成功。另一旧 `dockerInference` 运行目录也完整改名保留。随后 Docker Engine 29.3.1 实际响应，原数据库容器恢复运行。没有修改 ACL、工厂重置、删卷、重建容器或改变重启策略；不声称已解释 Windows 1920 的全部底层原因。

原根服务按既有 restart 策略恢复；C02 三个 transport 容器仍停止。备份前后 51 个容器的 ID/镜像/配置/重启策略、挂载条目与状态保持一致。第一次按原始 Mounts 数组计算的摘要比较失败；诊断确认 Docker 返回顺序不稳定，重排当前完整条目可重现原摘要，未放宽条目内容比较，也未重新运行数据库验证。
