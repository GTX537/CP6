# 销售管理用户操作手册

> 适用对象：销售、营业助理、报价担当、受注担当、主数据维护人员  
> 系统名称：CP6 销售管理  
> 更新日期：2026-05-08  
> 说明：本文依据当前已开发完成的系统页面整理，适合作为培训讲义和用户日常操作参考。

---

## 1. 手册目的

本手册用于说明 CP6 销售管理模块的主要业务功能、操作路径、关键输入项、常见注意事项，以及推荐的业务演示顺序。

销售管理模块覆盖以下业务链路：

`客户/交易先维护 -> 报价计算 -> 正式报价 -> 产品主数据 -> 受注录入 -> 单价修正 -> FSC清单 -> 纸板单价导入 -> 版型/木型管理`

---

## 2. 登录与通用操作

### 2.1 登录

1. 打开系统登录页。
2. 输入用户名和密码。
3. 登录成功后，从左侧菜单进入“销售管理”模块。

### 2.2 菜单对应功能

| 编号 | 功能名称 | 用途 |
|---|---|---|
| PA010 | 报价计算单登记 | 新建报价计算基础数据 |
| PA020 | 报价计算单一览 | 查询报价计算单 |
| PA030 | 正式报价单登记 | 生成客户正式报价 |
| PA040 | 正式报价单一览 | 查询正式报价 |
| PA050 | 产品主数据登记 | 建立产品基础资料 |
| PA060 | 产品主数据一览 | 查询产品资料 |
| PA070 | 受注输入 | 建立订单 |
| PA080 | 受注一览 | 查询订单 |
| PA090 | 单价修正 | 批量修改订单单价并触发审批 |
| PA100 | FSC检查清单 | 生成 FSC 相关清单 |
| PA110 | 交易先主数据登记 | 维护客户/供应商等往来单位 |
| PA120 | 交易先主数据一览 | 查询往来单位 |
| PA130 | 纸板单价主数据 | Excel 导入/查看纸板单价 |
| PA140 | 版型/木型登记 | 维护版型、木型、Rev 版本 |
| PA150 | 版型/木型一览 | 查询并打印标签 |

### 2.3 通用操作模式

系统多数主档页面都支持以下操作模式：

| 操作模式 | 说明 |
|---|---|
| 新建/登记 | 新建一笔资料 |
| 编辑/修正 | 修改既有资料 |
| 复制/流用 | 基于旧资料快速复制新资料 |
| 参照/查看 | 只读查看 |
| 删除 | 逻辑删除 |
| 改定 | 仅版型/木型使用，建立新 Rev |

### 2.4 常见按钮含义

| 按钮 | 说明 |
|---|---|
| 读取/检索 | 按编号或条件载入数据 |
| 新建 | 清空画面，进入登记模式 |
| 上一步/下一步 | 用于步骤式页面切换 |
| 保存/登记 | 写入数据库 |
| 删除执行 | 删除当前数据 |
| 清空 | 清空检索条件或输入内容 |
| 导入 | 从已有主数据或 Excel 带入 |
| CSV输出 | 导出列表数据 |
| 发行 | 生成文件、标签或报表 |

### 2.5 通用注意事项

- 如果提示“数据已被其他用户更新”之类的并发消息，需要重新读取后再保存。
- 大多数登记页面都有必填检查，报错时先优先检查红色提示或必填字段。
- 列表页面检索无结果时，先放宽条件，再重新查询。

## 3. 推荐业务流程

### 3.1 标准销售流程

1. 维护交易先主数据（PA110）
2. 新建报价计算单（PA010）
3. 生成正式报价单（PA030）
4. 客户确认后建立产品主数据（PA050）
5. 建立订单/受注（PA070）
6. 如需改单价，进入单价修正（PA090）
7. 如涉及 FSC，生成 FSC 清单（PA100）

### 3.2 主数据维护流程

1. 维护交易先
2. 导入纸板单价
3. 维护产品主数据
4. 维护版型/木型

## 4. PA110 交易先主数据登记

### 4.1 功能说明

用于维护客户、供应商、请款对象、收款对象、付款对象等往来单位。  
系统根据勾选的属性标志，动态显示不同页签。

### 4.2 操作模式

- 事前登记
- 正式登记
- 编辑
- 删除
- 参照

### 4.3 新建步骤

1. 进入 `销售管理 -> 交易先主数据登记`。
2. 选择“事前登记”或“登记”。
3. 输入以下基础信息：
   - 交易先CD
   - 交易先名称
   - 拠点CD
4. 至少勾选 1 个属性标志，例如：
   - 客户
   - 应收
   - 请款
   - 收款
   - 交货先
   - 供应商
   - 应付
   - 付款计划管理
   - 付款
5. 根据勾选结果，补充对应页签内容。
6. 点击“登记”保存。

### 4.4 重点规则

- 9 个属性标志不能全为空。
- 编辑时，不允许任意变更已确定的属性标志。
- 删除通常仅管理员可执行。

## 5. PA010 / PA020 报价计算单

### 5.1 功能说明

报价计算单是正式报价前的内部计算基础。页面分 3 步：

1. 基本信息
2. 工程明细
3. 计算结果

### 5.2 新建步骤

1. 进入 `销售管理 -> 报价计算单登记`。
2. 保持在“新建”模式。
3. Step 1 填写基础资料：
   - 报价拠点
   - 担当者
   - 受注形态
   - 客户
   - 数量
   - 父子区分
   - 客户品名1
4. Step 2 录入工序信息：
   - 工程
   - 作业
   - 采购/加工单价
   - 比率等
5. Step 3 确认系统自动计算结果。
6. 点击“保存”。

### 5.3 查询与后续操作

在 PA020 可按编号、日期、客户等条件查询。  
查询到的数据可进入：

- 编辑
- 复制
- 查看
- 删除

### 5.4 注意事项

- Step 1 的关键字段未填写时无法进入后续保存。
- 工程或配比相关数据若不完整，会导致计算异常。

## 6. PA030 / PA040 正式报价单

### 6.1 功能说明

正式报价单面向客户输出，可把多个报价计算单组合成一张正式报价。页面主要包含以下内容：

- 抬头/案件信息
- 报价说明
- 关联报价计算单
- 打印明细
- 提交用计算说明
- 备注

### 6.2 新建步骤

1. 进入 `销售管理 -> 正式报价单登记`。
2. 选择“新建”。
3. 在抬头页签录入：
   - 拠点
   - 担当者
   - 客户CD
   - 项目编号
   - FSC相关信息（如适用）
4. 切换到“关联报价计算单”页签。
5. 勾选需要纳入本次报价的报价计算单。
6. 系统会自动带入报价明细。
7. 如需补充，可在“打印明细”页签手工追加明细行。
8. 检查总金额与备注。
9. 保存。

### 6.3 报价确认

正式报价支持“确认登记”和“确认取消”：

1. 载入报价单。
2. 点击“确认登记”。
3. 勾选要确认的报价计算单。
4. 再次执行确认。

确认后，报价进入已确认状态，通常不能再随意修改。

### 6.4 报价发行

点击“发行”后，可选择输出类型：

- 正式报价单
- 提交用计算单
- 计算说明

### 6.5 适用场景

- 客户报价提交
- 销售内部报价确认
- 作为后续产品主数据的来源

## 7. PA050 / PA060 产品主数据

### 7.1 功能说明

产品主数据是受注和生产管理的重要基础。页面分 5 步：

1. 目标/部材选择
2. 基本信息
3. 工程信息
4. 材料设定
5. 批量单价/其他

### 7.2 新建步骤

1. 进入 `销售管理 -> 产品主数据登记`。
2. Step 1 维护部材一览。
   - 可手工新增行
   - 也可从正式报价带入部材
3. Step 2 填写产品基本信息：
   - 客户CD
   - 客户品名
   - 父子区分
   - 套装比率
4. Step 3 维护工程信息。
5. Step 4 维护材料信息：
   - 工程CD
   - 材料CD
   - 材料区分
6. Step 5 维护批量价格信息。
7. 保存。

### 7.3 系统规则

- 新建时产品CD由系统自动编号。
- 未维护工程时，系统会给出确认提醒。
- 未维护批量价格时，也会给出确认提醒。
- 批量数量必须按升序录入。

### 7.4 常见用途

- 从报价转产品
- 为受注页面提供产品、工序、材料基础资料

## 8. PA070 / PA080 受注输入

### 8.1 功能说明

受注输入是订单建立页面，分 3 步：

1. 基本信息 + 明细
2. 明细扩展信息 + 备注
3. 工程信息 + 材料信息

### 8.2 新建步骤

1. 进入 `销售管理 -> 受注输入`。
2. 选择“登记”。
3. Step 1 填写订单头信息：
   - 受注区分
   - 客户CD
   - 受注日
   - 客先纳期
4. 新增至少 1 条明细。
5. 每条明细填写产品CD、数量、单价等。
6. 进入 Step 2，逐条查看和补充扩展信息、备注。
7. 进入 Step 3，确认工程与材料。
8. 保存。

### 8.3 查询方式

受注可通过以下方式读取：

- Web受注NO
- 手配NO1

### 8.4 重点规则

- 没有明细不能保存。
- 明细中的产品CD为必填。
- 保存前会做信用额度检查；如超额，系统会要求再次确认。

## 9. PA090 单价修正

### 9.1 功能说明

用于批量修改既有订单单价，并触发审批流程。

### 9.2 操作步骤

1. 进入 `销售管理 -> 单价修正`。
2. 输入检索条件：
   - 拠点
   - 客户范围
   - 受注日期范围
   - 手配NO
   - 产品CD
3. 点击“检索”。
4. 勾选需要调整的订单行。
5. 修改以下字段：
   - 个别单价（修改后）
   - 套装单价（修改后）
   - 特价标志
   - 单价变更理由
6. 点击“选中行更新”。

### 9.3 结果

成功后系统会返回：

- 更新件数
- 触发审批/WF 件数

### 9.4 注意事项

- 未选中行时不能提交。
- 建议先按客户或日期缩小范围再批量修改。

## 10. PA100 FSC 检查清单

### 10.1 功能说明

用于生成 FSC 对象报价的检查清单，并输出 Excel。

### 10.2 操作步骤

1. 进入 `销售管理 -> FSC检查清单`。
2. 输入检索条件：
   - 拠点
   - 担当者
   - 报价日期范围
   - 报价单号范围
   - 客户
   - 项目号
3. 选择状态：
   - 未发行
   - 已发行
4. 选择输出格式。
5. 点击“检索”。
6. 在结果中勾选需要发行的行。
7. 点击“发行”。

### 10.3 注意事项

- 拠点为必填。
- 输出格式为必选。
- 至少要选择“未发行”或“已发行”中的一个状态。

## 11. PA130 纸板单价主数据

### 11.1 功能说明

用于 Excel 批量导入纸板单价，或查看既有单价主数据。

### 11.2 登记模式

1. 进入 `销售管理 -> 纸板单价主数据`。
2. 选择“登记”。
3. 输入：
   - 基准日
   - 拠点
   - 取込区分
4. 点击“Excel选择”上传文件。
5. 系统自动执行：
   - 文件读取
   - 列数检查
   - 必填检查
   - 数据格式检查
   - 主数据存在性检查
   - 重复检查
6. 检查预览结果。
7. 勾选要更新的行。
8. 点击“更新”。

### 11.3 参照模式

1. 切换到“参照”。
2. 输入基准日、拠点，可追加客户和营业担当。
3. 点击“显示”。

### 11.4 注意事项

- Excel 模板列数必须符合系统要求。
- 有重复数据时，系统会要求确认是否覆盖。

## 12. PA140 / PA150 版型/木型管理

### 12.1 功能说明

用于管理印刷版型、木型等资料，并支持 Rev 版本改定。

### 12.2 操作模式

- 登记
- 改定
- 编辑
- 删除
- 参照

### 12.3 新建步骤

1. 进入 `销售管理 -> 版型/木型登记`。
2. 在登记模式下输入“决定报价NO”并点击“导入”。
3. 系统自动带入部分基础信息。
4. 维护以下内容：
   - 基本信息
   - 构成信息
   - 附带信息
   - 必要件
5. 保存。

### 12.4 改定步骤

1. 切换到“改定”模式。
2. 输入版型NO和 Rev 后读取。
3. 修改新的适用开始日和需要变更的内容。
4. 点击“登记”。
5. 系统自动生成新的 Rev，并调整旧 Rev 的结束日。

### 12.5 附加功能

- 查看历史版本
- 发行标签
- 查看版型发注书入口提示

## 13. 常见错误与处理建议

| 场景 | 可能原因 | 处理建议 |
|---|---|---|
| 保存失败，提示必填 | 缺少基础字段 | 先检查当前页和上一步必填项 |
| 检索无结果 | 条件过严 | 先清空部分条件再查 |
| 并发更新提示 | 其他用户已修改 | 重新读取最新数据再保存 |
| Excel 导入失败 | 模板列不对或主数据不存在 | 先核对模板和主数据 |
| FSC 无法发行 | 未选格式或未勾选行 | 先选格式，再选择目标数据 |
| 单价修正不能提交 | 未选中行 | 至少勾选 1 条待修正记录 |
