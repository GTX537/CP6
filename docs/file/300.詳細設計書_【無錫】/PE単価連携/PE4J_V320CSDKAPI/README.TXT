 このたびは、POWER EGG3.0 Version 3.2c Software Development Kit
（以下、SDKと記述します）をご購入頂き、誠にありがとうございます。

　この資料では、SDKの内容とインストール方法について説明します。

１．SDK CD-ROMの内容

 documentsフォルダ
　　アドオン開発マニュアル、テーブル設計書がPDF形式またはhtmlで格納されています。
　　また、apidocフォルダ以下にPOWER EGG3.0 Version 3.2cのAPIリファレンスが、
　　webserviceフォルダ以下にPOWER EGG3.0 Ver3.2cのWebサービスAPIのリファレンス
　　が、javadoc系形式で格納されています。

 sample_sourceフォルダ
　　アドオン開発マニュアルの付録に付いているサンプルアプリケーションのソース
　　コードが格納されています。

 LICENSESフォルダ
　　POWER EGGが利用するサードパーティソフトウェアのライセンス情報等が含まれる
　　フォルダです。
