20. Webデータベースの外部システム連携¶

Webデータベースの操作に応じて、アドオン処理を呼び出すことができます。 これにより以下のことが実現できるようになります。

  • データベースの設定では実現できない項目間の関連チェック

  • 外部システム（データベース）を利用した業務チェック

  • 外部システム（データベース）の同時更新

20.1. 事前準備¶

アドオン処理を呼び出すためには、データベースの登録メニューにある「外部連携設定」を設定する必要があります。

この画面では以下の項目を設定します（※詳細は「ユーザーズマニュアル」を確認してください）

  • 連携先URL：Webデータベースの操作後に呼び出すURL

  • HTTPヘッダ：HTTPヘッダに追加するパラメータ

  • 接続タイムアウト：接続が確立するまでのタイムアウト時間

  • 読込タイムアウト：接続後、データを取得するまでのタイムアウト時間

  • 連携タイミング：アドオン処理を呼び出すタイミング

20.2. アドオン処理の呼び出し（HTTPリクエスト）¶

Webデータベースのレコード操作後に設定したURLに対してPOSTリクエストを送信します。

20.2.1. リクエストヘッダ¶

ヘッダ名

内容

Host

「外部連携設定」で設定した連携先URLのサーバ名もしくはIPアドレス

Content-Type

application/json

注釈

「外部連携設定」でHTTPヘッダを設定している場合は付加されます

レコードの情報がリクエストボディに設定されます。

20.3. アドオン処理の結果の受け取り（HTTPレスポンス）¶

アドオンの処理結果をレスポンスボディで受け取り、処理の継続・中止を判断します。

20.3.1. レスポンスパラメータ¶

パラメータ名

設定する値

必須

説明

result

文字列

必須

処理結果を指定します。（S:正常終了,W:警告終了,E:エラー終了）

messages

文字列の配列

省略可

処理結果のメッセージを指定します。

20.3.2. レスポンス例¶

{
    "result": "E",
    "messages": [
        "受付日に未来日が入力されています。",
        "進捗区分が対応済の場合は対策部署を指定してください。"
    ]
}

20.4.5. 「record」パラメータ¶

  • システム標準項目

    「No」のみ設定されます。（他のフィールドは設定されません）

    • C(新規登録,参照登録) ：nullが設定

    • U(更新) ：更新対象のレコードNoが設定

  • ユーザ定義項目

    入力項目のみ設定されます。（入力項目以外は設定されません）

    • 画面入力 ：入力画面に配置されているフィールドが設定

    • CSV取込 ：タイトル行に指定されているフィールドが設定

    • Restful API ：リクエストボディに指定されているフィールドが設定

  • 明細行

    明細行に定義されているすべてのフィールドが設定されます。
