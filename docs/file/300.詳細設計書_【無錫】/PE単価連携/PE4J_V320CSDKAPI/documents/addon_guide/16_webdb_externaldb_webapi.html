21. Webデータベース外部DB参照のWebAPI連携¶

外部DB参照定義の設定において、JDBCによる接続に加えて、WebAPIによる接続が 可能となりました。その場合、以下の2種類のWebAPIを別途、実装する必要があります。

  • 外部DB参照定義取得RESTAPI

  • 外部DB参照検索RESTAPI

外部DB参照定義の設定に関する詳細は「ユーザーズマニュアル　データベース作成編」- 「2.7 外部DB参照定義」-「WEB API連携の外部DB参照定義を登録する」を参照ください。

21.1. 事前準備¶

WebAPI連携を利用時には、AES共通鍵による暗号化を行うために暗号化のキーを事前に設定する必要があります。 PE4J\PEWEB\properteis\poweregg.properteisに、以下の内容を追加します。 設定後、POWER EGGのサービスを再起動する必要があります。

【追加内容】
① 鍵

名前：WEBDB_AES_COMMON_KEY_SECRET 値　：32文字任意の文字列(半角英数字)を設定してください。

② 初期ベクトル(IV)

名前：WEBDB_AES_COMMON_KEY_IV 値　：16文字任意の文字列(半角英数字)を設定してください。

例）

WEBDB_AES_COMMON_KEY_SECRET=PowerEgg20200424Abcdefghijklmnop WEBDB_AES_COMMON_KEY_IV=AbcdEFGhijk01234

21.2. 外部DB参照定義取得RESTAPI¶

Webデータベースの外部DB参照定義項目でWebAPI連携の項目を作成する際、 連携先の定義を取得するために、設定したURLに対しGETリクエストを送信します。

21.2.1. HTTPメソッド¶

GET

21.2.2. URI¶

http(s)://(連携先URLのサーバ名もしくはIPアドレス) /api/dbreferenceDef

21.3. 外部DB参照検索RESTAPI¶

WebデータベースのWebAPI連携型の外部DB参照項目をユーザが入力する時に、 設定したURLに対しGETリクエストを送信します。

21.3.1. HTTPメソッド¶

GET

21.3.2. URI¶

http(s)://(連携先URLのサーバ名もしくはIPアドレス) /api/dbreferenceQuery

21.3.3. リクエストヘッダ¶

ヘッダ名

内容

Host

「外部連携設定」で設定した連携先URLのサーバ名もしくはIPアドレス

Content-Type

application/json

注釈

「外部連携設定」でHTTPヘッダを設定している場合は付加されます

21.3.4. リクエストパラメータ¶

パラメータ名

指定する値

必須

説明

code

文字列

modeに依存

コードを直接して検索する場合に指定します。

keyword

文字列

modeに依存

データ参照ウィンドウでキーワード検索したときに指定します。

mode

文字列

省略可

テスト接続用かを判断するパラメタです。（0:本番接続,1:テスト接続） ※省略時は0として扱います。

注釈

modeが0の場合、keyword、もしくは、codeのどちらかが必須で設定されます。 modeが1の場合、code、keywordは両方設定されません。

21.3.5. リクエストの例¶

  1. 外部DB参照検索条件

  • 検索対象のキーワードは「大石」

  • 本番接続での検索

  1. パラメータを HTTP のクエリ文字列で送信する場合

HTTPのクエリ文字列の例

keyword=%E5%A4%A7%E7%9F%B3&mode=0

＜URLエンコーディングする前＞

keyword=大石&mode=0

リクエストヘッダを含んだ例

GET /api/dbreferenceQuery?(HTTPのクエリ文字列) HTTP/1.1
Host: gaibu-system.poweregg.net
Content-Type: application/json
Add-Header: hogehoge
