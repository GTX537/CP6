18. REST 作業API¶

18.1. 優先度一覧取得(GET)¶

POWER EGGに登録されている作業の優先度の情報を全件取得します。 ここで取得した優先度区分を、作業登録時や作業更新時に利用します。

18.1.1. HTTPメソッド¶

GET

18.1.2. URI¶

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/todo/priorities.json

18.1.3. リクエストパラメタ¶

なし

18.1.4. レスポンス(JSON)¶

パラメータ名

データ型

必須

説明

priorities

JSON

必須

優先度情報の配列

prioritiesのJSON型

パラメータ名

データ型

必須

説明

priorityCode

文字列

必須

優先度区分

priorityName

文字列

必須

優先度名称

18.1.5. レスポンスの例¶

{
    "priorities": [
        {
            "priorityCode": "1",
            "priorityName": "通常"
        },
        {
            "priorityCode": "2",
            "priorityName": "優先"
        },
        {
            "priorityCode": "3",
            "priorityName": "緊急"
        }
    ]
}

18.2. 作業登録(POST)¶

作業を1件登録します。

18.2.1. HTTPメソッド¶

POST

18.2.2. URI¶

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/todo/todo.json

必須

必須

必須

Content-Type: application/json
