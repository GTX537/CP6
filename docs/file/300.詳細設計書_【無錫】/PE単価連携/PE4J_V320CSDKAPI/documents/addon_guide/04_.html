4. フレームワーク¶

4.1. POWER EGG3.0 Ver3.2cが採用している開発フレームワーク¶

本システムでは、基盤技術として、Java Enterprise Edition 7 (EJB 3.2, JPA 2.1, JSF 2.2, CDI 1.1)を採用しています。

4.2. データベースアクセス¶

データベースへのアクセスには、Java Persistance API 2.1を利用しています。 JPAプロバイダとしては、EclipseLinkを採用しています。

4.3. アプリケーションロジック¶

アプリケーションロジックは、CDIビーン、EJBステートレスセッションビーン （サービスロジック）として作成しています。

4.4. プレゼンテーション¶

プレゼンテーション層で利用するビューは Facelet(xhtml)で作成します。
