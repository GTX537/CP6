POWER EGG3.0 Ver3.2c SDK アドオン開発マニュアル¶

本書はPOWER EGG3.0 Ver3.2c上でアドオンアプリケーションを開発される方 を対象に、POWER EGGが提供している各種のAPIとその利用方法について説明 しています。

POWER EGG3.0 Ver3.2c上でアドオンアプリケーションを開発するためには、 Java言語、JavaServer Faces、Java Servlet API、Java Server Pages、 Enterprise Java BeansなどのJava EE7プログラミングに関する知識が 必要となりますが、本書ではそれらに関する知識は既に保有されているもの として記述しています。

本資料が、みなさまのシステム開発の一助になることを願っております。
