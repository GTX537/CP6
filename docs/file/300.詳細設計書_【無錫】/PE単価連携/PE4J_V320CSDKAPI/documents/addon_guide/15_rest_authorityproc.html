23. REST 処理権限API¶

23.1. 処理権限設定(POST)¶

処理に対する権限情報の設定を行います。

23.1.1. HTTPメソッド¶

POST

23.1.2. URI¶

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/security/authorityproc.json

23.1.5. リクエストの例¶

  • リクエストヘッダ

    POST /pe4j/api/rest/v1/security/authorityproc.json HTTP/1.1
Host: pe280demo.poweregg.net
X-API-Key: 23b2a870-6bd4-413c-a467-c4c83f6da1f0
Content-Type: application/json

  • リクエストボディ

    {
    "procGroupName": "申請画面アドオン",
    "procName": "異動届申請",
    "rbody": [
        {
            "corpId": "friend",
            "authUnit1": 0,
            "authLevel": 1
        },
        {
            "corpId": "friend",
            "authUnit1": 70,
            "authTarget1": "1190",
            "authUnit2": 80,
            "authTarget2": "9",
            "authLevel": 9
        }
    ]
}

23.1.6. レスポンスの例¶

  • 正常時

    {
    "inputCount": 5,
    "updateCount": 6
}

  • 異常時

    {
    "inputCount": 5,
    "updateCount": 6,
    "errorInfo": [
        {
            "code": " WSA00030SE ",
            "message": "パラメタに誤りがあります。（procGroupName=グループウェア（一般）、procName=スケジュール",
            "details": "会社情報が取得できません。（corpId=friend99）"
        }
    ]
}
