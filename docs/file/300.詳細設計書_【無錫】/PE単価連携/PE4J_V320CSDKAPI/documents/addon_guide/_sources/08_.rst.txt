========================================
アドオンシステムのPOWER EGGへの組み込み
========================================

この章では、アドオン開発したxhtml, EJBをPOWER EGG環境に
組み込む際の手順について説明します。


開発資産のWEBアプリケーションサーバへの配置
============================================

Earの再作成とデプロイ
-----------------------

アドオン開発したEJB, xhtmlなどは、POWER EGGのエンタープライズ
アプリケーションである、pe4j-ear.earに組み込む必要があります。

特に、EJBがある場合、アプリケーションサーバへのデプロイ操作が
必要になりますので、アドオンを組み込んだearファイルをアプリケーション
サーバに再デプロイしてください。

POWER EGGメニューへの組み込み
=================================

開発したアプリケーションをPOWER EGGのアクションメニューから
起動する場合は、POWER EGGのシステム管理メニューのマスタメンテ
プログラムを利用して「処理の登録」、「メニューの登録」を行います。

マスタメンテプログラムの使用方法については、
「POWER EGG V3.0管理者マニュアル」を参照してください。
