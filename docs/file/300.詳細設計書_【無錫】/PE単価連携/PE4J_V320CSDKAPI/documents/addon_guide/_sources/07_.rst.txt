==============================================
POWER EGG JSFコンポーネントの利用方法
==============================================

POWER EGG3.0では、日付や社員などのデータを入力・表示するときに
各プログラムで共通的に利用するための共通部品をJSFコンポーネントと
して提供しています。

この章では、それらの共通部品の利用方法について解説します。

POWER EGG JSFコンポーネントを利用する場合は、Facelet xhtmlのhtml宣言部で、

.. code-block :: html

 xmlns:p=http://www.poweregg.net/jsf/html


という記述を追加する必要があります。

日付入力(inputDate)
============================

日付の入力を行うための部品です。入力域の右側にカレンダーから日付を
選択するためのアイコンが描画され、カレンダーからの日付選択も行えます。

入力された日付は、java.util.Dateオブジェクトとして格納されます。

Dateオブジェクトの時間フィールドは常に”00:00:00,000”になります。

日付範囲入力(inputDateRange)
======================================

日付範囲の入力を行う部品です。年月(yyyy/mm)または年月日
(yyyy/mm/dd)のどちらかの入力モードを選択できます。

年月日入力モードの場合は、日付期間を選択するためのカレンダーアイコンが表示されます。

入力された日付は、fromDate, toDateの２つのDateオブジェクトをプロパティに持つ
net.poweregg.util.DateRangeオブジェクトとして格納されます。

格納されるDateの時刻は、開始日は"00:00:00"、終了日は"23:59:59"固定となります。

また、年月日入力モードの場合は、「最近１ヶ月」などの簡易入力モードの指定が可能です。

添付ファイル入力(inputAttachFile)
===============================================

添付ファイルを入力する機能を提供します。
選択されたファイルは、net.poweregg.ui.param.AttachFile
オブジェクトのリストとして格納されます。

.. image :: image/7-11.png

HTML5対応のブラウザを利用している場合は、HTML5対応のドラッグ
&ドロップによるファイル添付ウィンドウが開きます。

また、ドラッグ＆ドロップによるファイル添付はシステム設定で切替が可能であるので、
実行環境によってどの画面が開くかは異なります。

.. image :: image/7-11-1.png

ドラッグ&ドロップのファイル添付を利用しない設定の場合は、上記の画面となります。

ラベル描画(outputLabel)
===================================

<label>タグを生成します。for属性で指定されたコンポーネントの
label属性がnullの場合は、コンポーネントのlabel属性にラベルの
valueに設定されている値をセットします。

また、for属性で指定されたコンポーネントのrequired属性が
"true"の場合は、入力必須マークを自動描画します。

.. image:: image/7-13.png
