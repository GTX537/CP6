======================================================
ログインパスワード変更同期インターフェース
======================================================

POWER EGGのログインパスワードが変更された際、他システムのパスワードを
変更するためのプラグインモジュールを呼び出すためのインターフェースです。

このインターフェースは、ログインパスワード変更のみを対象とし、
ワークフローの承認パスワードの変更については対象外です。

プラグインモジュールの組み込みは、poweregg.propertiesに以下の定義を
追加することによって行います。

定義が存在しない場合はPOWER EGGのログインパスワード変更処理のみが実行されます。

このインターフェースを実装したプラグインは、POWER EGGシステムに付き１つのみ定義可能です。

【poweregg.properties設定】
キー	値
PASSWORD_SYNC_PLUGIN	ログインパスワード変更同期インターフェースを実装しているクラス名
このキーが定義されている場合に、以下の追加設定に応じてパスワード変更同期を行う。
PASSWORD_SYNC_ON_ADMIN	システム管理者によるパスワード変更時にログインパスワード変更同期を行うか行わないかを設定する。
“true” または “false”で指定する。デフォルト値は”false”
PASSWORD_SYNC_ON_USER	ユーザによるパスワード変更時にログインパスワード変更同期を行うか行わないかを設定する。
“true” または “false”で指定する。デフォルト値は”false”

インターフェースクラス
========================

パスワード変更インターフェースは、
net.poweregg.api.security.LoginPasswordSyncInterfaceです。
プラグインモジュールはこのクラスをインプリメントし、
changePasswordメソッドを実装する必要があります。

なお、プラグインモジュールは、パスワードの変更結果を
net.poweregg.api.security.LoginPasswordSyncResult
クラスとして返却する必要があります。

パスワード変更時の動作
=========================

POWER EGGでは、ログインパスワード変更操作が行われた際、
次の順序でログインパスワード変更同期処理を実行します。

パスワード文字列の妥当性チェックを行う（標準処理）

※ユーザによるパスワード変更操作が行われた場合のみ実施され、
社員の登録画面からのパスワード変更時、
MIUからのパスワード変更時は妥当性チェックは実施されません。

poweregg.propertiesの”PASSWORD_SYNC_PLUGIN”キーを検索し、
値が存在した場合は、設定されている値をクラス名として
Class.forNameメソッドを用いてクラスのインスタンスを作成し、
LoginPasswordSyncInterfaceにキャストします。

インスタンス生成に失敗した場合は「パスワード連携モジュール({0})の
インスタンス化に失敗しました」のメッセージを持つRuntimeExceptionをスローします。

作成したインスタンスが、LoginPasswordSyncInterfaceにキャストできない場合は、
「パスワード連携モジュールで指定されたクラス({0})がインターフェースを
実装していません。」のメッセージを持つRuntimeExceptionをスローします。

※メッセージ内の{0}はpoweregg.propertiesのPASSWORD_SYNC_PLUGINの値

パスワード変更同期実行判定（※１）を行い、同期実行の場合インスタンス化
したクラスのchangePasswordメソッドを呼び出します。

戻り値(LoginPasswordSyncResult)に応じて次の処理を行います。

- 戻り値がnullの場合、「パスワード連携モジュールの戻り値がnull」
  のメッセージを持つRuntimeExceptionをスローする。
- LoginPasswordSyncResult#getStatusCode()が -20 の場合はパスワード
  妥当性検証エラーとし、POWER EGGのパスワード変更は行わない。（※２）
- LoginPasswordSyncResult#getStatusCode()が -20 以外の場合は 
  #isRollback()の値を調べ、trueの場合はPOWER EGGのパスワード変更は行わず、
  ユーザ画面にエラーメッセージを表示する。#isRollBack()がfalseの場合は、
  POWER EGGのパスワード変更を行い、ユーザ画面に正常終了メッセージを表示する。（※２）


.. csv-table :: ※１ パスワード変更同期実行判定
    :header: 画面の操作, 説明
    :widths: 30,70

    "社員登録画面でログインパスワードを変更した","poweregg.propertiesの
    PASSWORD_SYNC_ON_ADMINがtrueの場合のみ同期実行する"
    "MIU社員インポートでログインパスワードを変更した","同期実行しない"
    "ユーザ画面からのログインパスワード変更
    （個人設定、パスワード期限切れ警告、パスワード期限切れ画面）","
    poweregg.propertiesのPASSWORD_SYNC_ON_USERがtrueの場合のみ同期実行する"

.. csv-table :: ※２ ユーザ画面に表示するエラーメッセージ
    :header: statusCode,エラーメッセージ
    :widths: 30,70

    -20,"パスワードに使用できない文字が含まれています。"
    -21かつisRollback=true,"外部システムの制約により、パスワード更新に失敗しました。{0}"
    -21かつisRollback=false,"外部システムのパスワード変更が失敗したため、
    POWER EGGのみログインパスワードを更新しました。{0}"
    "isRollback=true かつ
    上記以外のステータスコード","外部システムからの通知により、パスワード更新を行いませんでした。{0}"

{0}：プラグインモジュール側でLoginPasswordSyncResult#setExecMessage()により、エラー詳細内容を設定することにより表示されます
