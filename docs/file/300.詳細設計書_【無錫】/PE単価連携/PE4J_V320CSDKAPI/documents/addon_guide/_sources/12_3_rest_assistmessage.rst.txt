===============================
REST アシストメッセージAPI
===============================


アシストメッセージ登録(POST)
=================================================

アシストメッセージを1件登録します。


HTTPメソッド
---------------------------

POST

URI
----------------

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/portal/assistMessage.json


リクエストボディ(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    corpId,文字列,必須,メッセージの宛先社員の会社の外部会社コード。 
    empNumber1,文字列,必須,"メッセージの宛先社員の外部社員コード１"
    subEmpNumber1,文字列,必須,"メッセージの宛先社員の部下社員の外部社員コード１（不要な場合はempNumber1と同じものをセット）"
    message,文字列,必須,"メッセージ文字列"
    priority,文字列, , "重要度(""0001"":最高, ""0002"":高い, ""0003"":通常, ""0004"":低い, ""0005"":最低)
    省略した場合は通常が指定されたことになります。"
    processId,文字列, ,"任意のメッセージ作成元識別用文字列（先頭３文字SYSはシステム予約）"
    url,文字列, , "メッセージのリンク先のURL"
    messageType,文字列,必須,"アシストメッセージ連携区分の登録で登録した区分番号を指定"
    businessClass,文字列,,"アシストメッセージ分類の登録で登録した区分番号を設定"


レスポンス(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,データ型,必須,説明
    :widths: 15,15,15,55

    messageId,数値,必須,登録したメッセージのメッセージID

リクエストの例
-------------------------------

- リクエストヘッダ :: 

    POST /pe4j/api/rest/v1/portal/assistMessage.json HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1
    Content-Type: application/json

- リクエストボディ ::

    {
        "corpId": "friend00",
        "empNumber1": "10025",
        "subEmpNumber1": "10141",
        "message": "〇〇株式会社の未回収が100,000,000円あります",
        "priority": "0003",
        "processId": "ABC1001",
        "url": "http://extsystem/referdata?id=12345",
        "messageType": "11",
        "businessClass": "0004"
    }


レスポンスの例
---------------------------

登録したアシストメッセージの管理番号が返却されます。 ::

    {
        "messageId": 3421568
    }

アシストメッセージ削除(DELETE)
=================================================

登録済みのアシストメッセージを削除します。
メッセージIDを指定して1件だけ削除するか、メッセージ登録時に指定したprocessId
のメッセージをすべて削除するかのどちらかで利用できます。


HTTPメソッド
---------------------------

DELETE

URI
----------------

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/portal/assistMessage.json


クエリパラメータ
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    messageId,数値, ,メッセージIDで削除する場合に対象のIDを指定します。
    processId,文字列, ,"作成元識別で削除する場合作成元識別用文字列を指定"

レスポンス
----------------------------------

なし

リクエストの例
-------------------------------

- HTTPのクエリ文字列の例 ::

    messageId=10001

- リクエストヘッダを含んだ例 :: 

    DELETE /pe4j/api/rest/v1/portal/assistMessage.json?(HTTPのクエリ文字列) HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1

  ※Content-Typeヘッダは不要です。
