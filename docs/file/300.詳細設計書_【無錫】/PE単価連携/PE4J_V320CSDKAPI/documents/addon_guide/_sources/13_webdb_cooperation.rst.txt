==================================
Webデータベースの外部システム連携
==================================

Webデータベースの操作に応じて、アドオン処理を呼び出すことができます。
これにより以下のことが実現できるようになります。

* データベースの設定では実現できない項目間の関連チェック
* 外部システム（データベース）を利用した業務チェック
* 外部システム（データベース）の同時更新

事前準備
==========

アドオン処理を呼び出すためには、データベースの登録メニューにある「外部連携設定」を設定する必要があります。

この画面では以下の項目を設定します（※詳細は「ユーザーズマニュアル」を確認してください）

* 連携先URL：Webデータベースの操作後に呼び出すURL
* HTTPヘッダ：HTTPヘッダに追加するパラメータ
* 接続タイムアウト：接続が確立するまでのタイムアウト時間
* 読込タイムアウト：接続後、データを取得するまでのタイムアウト時間
* 連携タイミング：アドオン処理を呼び出すタイミング

アドオン処理の呼び出し（HTTPリクエスト）
===========================================

Webデータベースのレコード操作後に設定したURLに対してPOSTリクエストを送信します。

リクエストヘッダ
-------------------

.. csv-table :: 
    :header: ヘッダ名,内容
    :widths: 40,60

    Host,「外部連携設定」で設定した連携先URLのサーバ名もしくはIPアドレス
    Content-Type, "application/json"

.. note ::

    「外部連携設定」でHTTPヘッダを設定している場合は付加されます

リクエストパラメータ
---------------------

レコードの情報がリクエストボディに設定されます。

.. csv-table :: 
    :header: パラメータ名, 設定する値, 必須, 説明
    :widths: 20, 20, 15, 40

    system, 数値, 必須, "システム区分（0:WebDB,1:汎用申請,2:CRM）"
    database, 文字列, 必須, "データベース名（(親フォルダ名)/(フォルダ名)/(データベース名)）"
    screen, 文字列, 任意, "表示編集画面名"
    event, 文字列, 必須, "処理タイミング（C:入力チェック,U:レコード更新,S:スタンプ更新）"
    process, 文字列, 必須, "CRUD（C:登録,U:更新,D:削除）"
    stamp, 文字列, 任意, "押下したスタンプの文字列"
    record, Object, 必須, "レコード情報
    ※各フィールドの形式はWebデータベースのRestful API（レコード取得）のレスポンスデータと同じです。"
    loginUser, Object, 必須, "ログインユーザ情報（ユーザID,社員名）"


リクエスト例
---------------------------

リクエストヘッダの例

.. code :: 

    POST /api/rest/v1/addon.json HTTP/1.1
    Host: gaibu-system.poweregg.net
    Content-Type: application/json
    Add-Header: hogehoge

アドオン処理の結果の受け取り（HTTPレスポンス）
===============================================

アドオンの処理結果をレスポンスボディで受け取り、処理の継続・中止を判断します。

レスポンスパラメータ
-------------------------------

.. csv-table :: 
    :header: パラメータ名, 設定する値, 必須, 説明
    :widths: 20, 20, 15, 40

    result, 文字列, 必須, "処理結果を指定します。（S:正常終了,W:警告終了,E:エラー終了）"
    messages, 文字列の配列, 省略可, "処理結果のメッセージを指定します。"


レスポンス例
------------------------

.. code ::

    {
        "result": "E",
        "messages": [
            "受付日に未来日が入力されています。",
            "進捗区分が対応済の場合は対策部署を指定してください。"
        ]
    }

リクエストパラメータ
--------------------

レコードの情報がリクエストボディに設定されます。

.. csv-table ::
    :header: パラメータ名, 設定する値, 必須, 説明
    :widths: 20, 20, 15, 40

    system,数値,必須,"'0'(WebDB) or '1'(汎用申請) or '2'(CRM)が設定されます"
    database,文字列,必須,"データベース名が設定されます"
    screen,文字列,任意,"表示編集画面名が設定されます
    ※Webデータベース、CRMデータベースのCSV取込、Restful API実行時はnullが編集されます"
    event,文字列,必須,"'C'(入力チェック)が設定されます"
    process,文字列,必須,"'C'(登録) or 'U'(更新)が設定されます"
    stamp,文字列,任意,"nullが設定されます"
    record,Object,必須,"レコード情報が設定されます"
    loginUser,Object,必須,"ログインユーザ情報が設定されます（ユーザID,社員名）"


「record」パラメータ
-------------------------------

* システム標準項目

    「No」のみ設定されます。（他のフィールドは設定されません）

    - C(新規登録,参照登録)	：nullが設定
    - U(更新)			：更新対象のレコードNoが設定

* ユーザ定義項目

    入力項目のみ設定されます。（入力項目以外は設定されません）

    - 画面入力			：入力画面に配置されているフィールドが設定
    - CSV取込			：タイトル行に指定されているフィールドが設定
    - Restful API		：リクエストボディに指定されているフィールドが設定

* 明細行

    明細行に定義されているすべてのフィールドが設定されます。
