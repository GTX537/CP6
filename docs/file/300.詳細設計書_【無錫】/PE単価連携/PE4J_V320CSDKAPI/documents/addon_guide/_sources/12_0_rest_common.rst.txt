===============================
REST API 共通
===============================

POWER EGG2.0ではAPIをJavaネイティブまたはSOAP Webサービスとして提供していました

Ver.2.8以降からはAPIをより容易に利用できるように、Restful Webサービスとして利用できるようになっています。

REST API（共通仕様）
==============================

プロトコル
------------------------

HTTP または HTTPS

フォーマット
------------------------
JSON

文字コード
------------------------
UTF-8

エスケープ文字
------------------------
「\\」を使用します。

日付フォーマット
------------------------
日付、時刻、日時、日時分フィールドのデータを扱う場合、
それぞれ以下のフォーマットの文字列で指定する必要があります。

.. csv-table :: 
    :header: "フィールドタイプ","フォーマット","説明"
    :widths: 10,30,40

    "日付","YYYY-MM-DD","UTCに変換されません。"
    "時刻","HH:MM","UTCに変換されません。"
    "日時","YYYY-MM-DDTHH:MM±HH:MM
    or YYYY-MM-DDTHH:MMZ","「YYYY-MM-DD」と「HH:MM」の間の「T」は固定値です。
    「Z」はUTCを表します。
    
    日本時間（JST）の2016年2月5日14時00分は次のように表せます。 
    
    例）「2016-02-05T14:00+09:00」または「2016-02-05T05:00Z」"
    "日時分","YYYY-MM-DDTHH:MM:SS±HH:MM
    or YYYY-MM-DDTHH:MM:SSZ",""


ユーザ認証
------------------------

APIを実行するリクエストには、認証キーをリクエストヘッダに追加する必要があります。
認証キーは「Webサービス認証キー発行」画面で発行します。
※詳細については「管理者マニュアル」をご確認ください

リクエストヘッダ
------------------------

送信するリクエストには以下のリクエストヘッダを指定します。

.. csv-table :: 
    :header: ヘッダ名,内容
    :widths: 20,40

    Host,"POWER EGGサーバ名もしくはIPアドレス"
    Content-Type,"""application/json""
    ※リクエストボディにJSON文字列を格納する場合のみ指定します。"
    X-API-Key,"「Webサービス認証キー発行」画面で発行したAPIキー"


例）リクエストヘッダ ::

    Host: pe280demo.poweregg.net
    Content-Type: application/json
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1


レスポンス
------------------------
HTTPステータスコードが「200」「201」であれば正常終了、それ以外はエラー終了です。

正常終了のHTTPステータスコード

.. csv-table :: 
    :header: ステータスコード,HTTPメソッド,内容
    :widths: 40,30,40

    200(OK),GET / PUT / DELETE,リクエストが成功した
    201(Created),POST,リソース作成リクエストが成功した

異常終了のHTTPステータスコード

.. csv-table :: 
    :header: ステータスコード,種別,例
    :widths: 40,30,40

    400(BAD REQUEST),バリデーションエラー,"- リクエストヘッダのチェック
    - リクエストボディのチェック
    - 入力データ（入力、桁数等）のチェック"
    401(UNAUTHORIZED),認証エラー,- 認証キーでの認証チェック
    403(FORBIDDEN),権限チェックエラー,"- 認証キーでの権限チェック
    - POWER EGGのライセンスチェック"
    409(CONFLICT),重複エラー,- キー項目の重複チェック
    500(INTERNAL SERVER ERROR),その他,- システムエラー

エラー時には下記情報を含むJSONデータをレスポンスとして受け取ります。

.. csv-table :: 
    :header: Key,Value
    :widths: 20,40

    code,エラーコードです。問い合わせの際に利用します。
    message,エラーメッセージが表示されます。
    details,エラーの詳細メッセージが表示されます。

例）エラーレスポンス ::

    {
        "code": "WSA01213SE",
        "message": "フィールド値を正しく指定してください。",
        "details": [
            "社員名を必ず入力してください。",
            "住所は半角200文字以内で入力してください。"
        ]
    }


DELETEメソッドの呼び出しに関する注意事項
------------------------------------------

アプリケーションサーバーによって、DELETEメソッドではbodyでのパラメタ指定は行えない
場合があります。(Interstage等）

この場合は、bodyでのパラメタ渡しでなく、クエリ文字列でパラメタを渡すようにしてください。


ファイルアップロード（POST）
=======================================

ファイルを添付するためにファイルをアップロードするAPIです。

- アップロードされたファイルのファイルキーを利用して、ファイルを添付できます。
- 一度にアップロードできるファイルは一つです。


HTTPメソッド
-------------------------
POST


URI
-------------------------
http(s)://(POWER EGGサーバ)/pe4j/api/rest/v1/com/file.json


リクエスト形式
-------------------------
- リクエストは multipart/form-data 形式で送信します。 

  ※詳細は RFC1867、RFC2388 を参照してください。

- ファイル名は Content-Disposition 内のfilenameで指定して下さい。 

  ※日本語ファイル名の場合は UTF8 でエンコードした内容を指定して下さい。


リクエストの例
-------------------------
ファイル内容が「test」の test.txt ファイルを送信した場合::

    POST /pe4j/api/rest/v1/com/file.json HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1
    Content-Type: multipart/form-data; boundary=---------------------------bee48a285354
    Content-Length: 188
    
    -----------------------------bee48a285354
    Content-Disposition: form-data; name="file"; filename="test.txt"
    Content-Type: text/plain
     
    test
     
    -----------------------------bee48a285354--


レスポンスの例
---------------------------
アップロードされたファイルのファイルキーが返されます。 :: 

    {
        "fileKey": "74b2a870-6bd4-413c-a467-c4c83f6da1f0"
    }

※添付ファイルを登録する場合はこのファイルキーを使用します。


ファイルダウンロード（GET）
=============================
添付ファイルをダウンロードする API です。


HTTPメソッド
-------------------------
GET


URI
----------------
- パラメータを HTTP のクエリ文字列で送信する場合

  http(s)://(POWER EGGサーバ)/pe4j/api/rest/v1/com/q/file.json

- パラメータを JSON形式で送信する場合

  http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/com/file.json

  .. note ::

   GETでのリクエストボディの指定をサポートしていないクライアントでは使用できません


リクエストパラメータ
-----------------------
ダウンロードするファイルを特定するファイルキーを指定します。

.. csv-table :: 
    :header: パラメータ名, 指定する値, 必須, 説明
    :widths: 30,30,10,30

    fileKey,文字列,必須, ダウンロードするファイルのファイルキーを指定します。（添付ファイルが登録されているデータを検索したときに返却されます）

※ファイルのアップロード時にレスポンスで返却されるファイルキーとは異なるため注意してください。


リクエストの例
---------------------------
1. パラメータを HTTP のクエリ文字列で送信する場合

- HTTPのクエリ文字列の例 ::

    fileKey=Od/bdrkdy3ZfD4NaYGHGxQJXeyXzYZRxhDp+LU+CFDmpP5FI2bx7Y4MqOO8bTQ3p

- リクエストヘッダを含んだ例 :: 

    GET /pe4j/api/rest/v1/com/q/file.json?(HTTPのクエリ文字列) HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1

  ※Content-Typeヘッダは不要です。

2. パラメータを JSON形式で送信する場合

- リクエストヘッダの例 :: 

    GET /pe4j/api/rest/v1/com/file.json HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1
    Content-Type: application/json

  ※Content-Type に application/json を指定して下さい。 
  指定しない場合は JSON が解釈できないため、実行時エラーとなります。

- リクエストボディの例 ::

    {
        "fileKey": "Od/bdrkdy3ZfD4NaYGHGxQJXeyXzYZRxhDp+LU+CFDmpP5FI2bx7Y4MqOO8bTQ3p"
    }


レスポンスの形式
------------------------------
Content-TypeにMIMEタイプ、Content-Disposition 内のfilenameにファイル名が入り、
レスポンスボディにファイルの内容がセットされます。
