=====================================
REST WebデータベースAPI
=====================================


Webデータベース：レコードの取得（GET）
===============================================
レコードをクエリで条件を指定して取得できます。

- 一度に取得できるレコードは 100件までです。（100件以上取得する場合は
  レコードの取得範囲を変えて複数回実行してください）
- ソート順に指定できるフィールドはフィールド設定で「ソート対象」を指定できるフィールドです。
- 検索条件の指定方法、検索条件に指定できるフィールド、論理演算子、比較演算子は絞り込み条件と同じです。

.. image :: image/12-1.png

以降、①は「ブロック毎の論理演算子」、②は「フィールド毎の論理演算子」と記述します。


HTTPメソッド
-------------------------

GET


URI
--------------------

1. パラメータを HTTP のクエリ文字列で送信する場合

  http(s)://(POWER EGGサーバ)/pe4j/api/rest/v1/xdb/q/records.json

2. パラメータを JSON形式で送信する場合

  http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/xdb/records.json

  .. note :: 
  
    GETでのリクエストボディの指定をサポートしていないクライアントでは使用できません


リクエストパラメータ
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    system,数値,省略可,"システム区分を指定します。（0:WebDB,1:汎用申請,2:CRM）
    ※省略時は0が指定されます。"
    database,文字列,必須,データベース名を指定します。（(親フォルダ名)/(フォルダ名)/(データベース名)）
    query,JSON形式の配列,省略可,"レスポンスに含めるレコードの条件を指定するクエリ文字列を指定します。
    ※省略時は全レコードが対象になります。"
    order,JSON形式の配列,省略可,"レコードの並び順を指定します。
    ※省略時はNoの昇順でソートされます。"
    limit,数値,省略可,"指定した数だけ、レコードを返却します。
    ※省略時は100が指定されます。"
    offset,数値,省略可,"指定した数だけ、出力するレコードをスキップします。
    ※省略時は0が指定されます。"


「query」パラメータ
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,10,60

    blockConj,文字列,省略可,"ブロック毎の論理演算子を指定します。（""and"",""or""）
    ※省略時は""and""が指定されます。"
    itemConj,文字列,省略可,"フィールド毎の論理演算子を指定します。（""and"",""or""）
    ※省略時は""and""が指定されます。"
    items,Object,必須,検索条件を指定します・


「items」パラメータ
-----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,10,60

    field,文字列,必須,検索条件に指定するフィールド名を指定します。
    opr,文字列,必須,"比較演算子を指定します。

    .. csv-table :: 
        :header: 比較演算子,説明
        :widths: 20,40

        =,同じ
        !=,異なる
        ^,始まる
        ~,含む
        !~,含まない
        >,より大きい
        <,より小さい
        >=,以上
        <=,以下
        n,未入力
        !n,入力済
        ~=,配下（部門選択で利用）
        c=,企業が同じ（お客様選択で利用）
        b=,部門が同じ（お客様選択で利用）
        e=,担当者が同じ（お客様選択で利用）
        true,チェック済（フラグで利用）
        false,未チェック （フラグで利用）
    "
    code,"真偽値","省略可","検索条件にDB参照、DB参照コード入力、
    WebDB参照、WebDB参照コード入力を使用する場合に指定します。
    （true:コードで比較,false:名称で比較）
    ※省略時はfalseが指定されます。"
    value,文字列,省略可,"検索する文字列を指定します。
    oprによって、必須/任意が切り替わります

    .. csv-table :: 
        :header: フィールド,指定方法
        :widths: 20,40

        日付、申請日、決裁日,""YYYY-MM-DD形式で指定
        例）2015-02-05""
        年月,""YYYY-MM形式で指定
        例）2015-02""
        時刻,""HH:MM形式で指定
        例）10:00""
        日付時刻、""日付時刻計算,YYYY-MM-DDTHH:MM±HH:MM形式で指定
        例）2015-02-05T10:30+09:00""
        登録日時、""最終更新日時,YYYY-MM-DDTHH:MM:SS±HH:MM形式で指定
        例）2015-02-05T10:30:15+09:00""
        会社選択,""外部会社コードを指定
        例）friend00""
        部門選択、申請部門,""(外部会社コード):(外部部門コード1)形式で指定
        例）friend00:eigyo""
        社員選択、複数社員選択,""(外部会社コード):(外部社員コード1)形式で指定
        例）friend00:ooishi""
        商品選択,""(外部会社コード):(商品コード)形式で指定
        例）friend00:poweregg""
        お客様選択、顧客リレーション,""(企業ID):(部署ID):(担当者ID)形式で指定
        例）1:2:3""
        登録者、最終更新者、申請者、決裁者,""ユーザIDを指定
        例）ooishi""
        それ以外,文字列を指定
    "


「order」パラメータ
--------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,10,60

    field,文字列,必須,ソート条件するフィールド名を指定します。
    desc,真偽値,省略可,"並び順を指定します。（true:降順,false:昇順）
    ※省略時はfalseが指定されます。"


リクエストの例
----------------------------

1. レコード取得条件

  - 対象のデータベースは「ﾌﾟﾛｾｽ管理型/クレーム管理」

  - 並び順は「No」の「降順」

  - レコードの取得範囲は「50」件目から「100」件

  - 検索条件は以下のとおり

  .. image :: image/12-2.png


2. パラメータを HTTP のクエリ文字列で送信する場合

  HTTPのクエリ文字列の例 ::

    system=0&database=%EF%BE%8C%EF%BE%9F%EF%BE%9B%EF%BD%BE%EF%BD%BD%E7%AE%A1%E7%90%86%E5%9E%8B%2F%E3%82%AF%E3%83%AC%E3%83%BC%E3%83%A0%E7%AE%A1%E7%90%86DB&query=%5B%7B%22itemConj%22%3A%22and%22%2C%22items%22%3A%5B%7B%22field%22%3A%22%E5%8F%97%E4%BB%98%E8%80%85%22%2C%22opr%22%3A%22%3D%22%2C%22value%22%3A%22friend00%3Aooki%22%7D%2C%7B%22field%22%3A%22%E9%80%B2%E6%8D%97%E5%8C%BA%E5%88%86%22%2C%22opr%22%3A%22%21%3D%22%2C%22value%22%3A%22%E3%82%AF%E3%83%AC%E3%83%BC%E3%83%A0%E5%AF%BE%E5%BF%9C%E6%B8%88%22%7D%5D%7D%2C%7B%22blockConj%22%3A%22and%22%2C%22itemConj%22%3A%22or%22%2C%22items%22%3A%5B%7B%22field%22%3A%22%E5%AF%BE%E5%BF%9C%E9%83%A8%E7%BD%B2%22%2C%22opr%22%3A%22%3D%22%2C%22value%22%3A%22friend00%3Aeigyo%22%7D%2C%7B%22field%22%3A%22%E5%AF%BE%E5%BF%9C%E9%83%A8%E7%BD%B2%22%2C%22opr%22%3A%22n%22%7D%5D%7D%5D&order=%5B%7B%22field%22%3A%22No%22%2C%E2%80%9Ddesc%E2%80%9D%3Atrue%7D%5D&limit=100&offset=50

  ＜URLエンコーディングする前＞ ::

    system=0&database=ﾌﾟﾛｾｽ管理型/クレーム管理DB&query=[{"itemConj":"and","items":[{"field":"受付者","opr":"=","value":"friend00:ooki"},{"field":"進捗区分","opr":"!=","value":"クレーム対応済"}]},{"blockConj":"and","itemConj":"or","items":[{"field":"対応部署","opr":"=","value":"friend00:eigyo"},{"field":"対応部署","opr":"n"}]}]&order=[{"field":"No",”desc”:true}]&limit=100&offset=50

  リクエストヘッダを含んだ例 ::

    GET /pe4j/api/rest/v1/xdb/q/records.json?(HTTPのクエリ文字列) HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1

  ※Content-Typeヘッダは不要です。

3. パラメータを JSON形式で送信する場合

  リクエストヘッダの例 ::
  
    GET /pe4j/api/rest/v1/xdb/records.json HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1
    Content-Type: application/json

    ※Content-Type に application/json を指定して下さい。 
    指定しない場合は JSON が解釈できないため、実行時エラーとなります。

  リクエストボディの例

Webデータベース：レコードの登録（POST）
=================================================

1件のレコードを登録できます。


HTTPメソッド
---------------------------

POST


URI
----------------

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/xdb/record.json


リクエストパラメータ
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    system,数値,省略可,"システム区分を指定します。（0:WebDB,2:CRM）
    ※省略時は0が指定されます。"
    database,文字列,必須,"データベース名を指定します。（(親フォルダ名)/(フォルダ名)/(データベース名)）"
    notification,"真偽値","省略可","通知の有無を指定します。
    （true:通知する,false:通知しない）
    ※省略時はfalseが指定されます。"
    notifyfollow,真偽値,省略可,"フォロー通知の有無を指定します。
    （true:通知する,false:通知しない）
    ※省略時はfalseが指定されます。"
    external,真偽値,省略可,"外部連携（アドオン呼び出し）の有無を指定します。
    （true:実行する,false:実行しない）
    ※省略時はtrueが指定されます。"
    record,Object,必須,"レコードの情報（フィールド名とフィールドの値）をオブジェクトで指定します。
    ※フィールド値の仕様についてはフィールドの形式により異なります。 詳細については、後述「フィールド形式」をご確認ください。
    ※明細行（details）は省略可能です。
    "

リクエストボディの構造

.. code-block :: javascript

    {
        "system": (システム区分),
        "database": "(データベース名)",
        "notification": (通知の有無),
        "notifyfollow": (フォロー通知の有無),
        "external": (外部連携の有無),
        "record": {
            "(フィールド名)": {
                "value": "(フィールド値)"
            },
            "details": [
                {
                    "(明細行フィールド名)": {
                        "value": "(フィールド値)"
                    }
                }
            ]
        }
    }

リクエストの例
-------------------------------
1. レコード登録条件

 - 対象のデータベースは「プロセス管理型/クレーム管理」
 - 通知の有無は「通知する」
 - フォロー通知の有無は「通知しない」
 - 外部連携の有無は「実行しない」
 - 登録するフィールドは以下のとおり

    レコード

    .. csv-table :: 
        :header: フィールド名,フィールド型,値
        :widths: 30,30,40

        登録日時,(システム標準項目),2015-01-15T19:21:14+09:00
        登録者,(システム標準項目),大石 学(ooishi)
        最終更新日時,(システム標準項目),2015-01-15T19:21:14+09:00
        最終更新者,(システム標準項目),大石 学(ooishi)
        受付日時,日付時刻選択,2015-01-10T10:00+09:00
        受付者,社員選択,"フレンド商事(friend00)
        システム室(system)"
        梨田 義男(nakanishi)
        進捗区分,ラジオボタン,クレーム対応済

    .. csv-table ::

  .. note ::

Webデータベース：レコードの更新（PUT）
=================================================

1件のレコードを更新できます。


HTTPメソッド
---------------------------
PUT


URI
----------------------------
http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/xdb/record.json


リクエストパラメータ
----------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    system,数値,省略可,"システム区分を指定します。（0:WebDB,2:CRM）
    ※省略時は0が指定されます。"
    database,文字列,必須,データベース名を指定します。（(親フォルダ名)/(フォルダ名)/(データベース名)）
    notification,真偽値,省略可,"通知の有無を指定します。（true:通知する,false:通知しない）
    ※省略時はfalseが指定されます。"
    notifyfollow,真偽値,省略可,"フォロー通知の有無を指定します。（true:通知する,false:通知しない）
    ※省略時はfalseが指定されます。"
    external,真偽値,省略可,"外部連携（アドオン呼び出し）の有無を指定します。（true:実行する,false:実行しない）
    ※省略時はtrueが指定されます。"
    No,数値,必須,レコードNoを指定します。
    record,Object,必須,"レコードの情報（フィールド名とフィールドの値）をオブジェクトで指定します。
    ※フィールド値の仕様についてはフィールドの形式により異なります。 詳細については、後述「フィールド形式」をご確認ください。
    ※明細行（details）は省略可能です。
    ※明細行は全置換されます。（差分で更新できません）
    "

リクエストボディの構造 ::

    {
        "system": (システム区分),
        "database": "(データベース名)",
        "notification": (通知の有無),
        "notifyfollow": (フォロー通知の有無),
        "external": (外部連携の有無),
        "No": (レコードNo),
        "record": {
            "(フィールド名)": {
                "value": "(フィールド値)"
            },
            "details": [
                {
                    "(明細行フィールド名)": {
                        "value": "(フィールド値)"
                    }
                }
            ]
        }
    }

リクエストの例
---------------------------

1. レコード更新条件

  - 対象のデータベースは「ﾌﾟﾛｾｽ管理型/クレーム管理」
  - 通知の有無は「通知する」
  - フォロー通知の有無は「通知しない」
  - 外部連携の有無は「実行しない」
  - 更新するレコードNoは「1」
  - 更新するフィールドは以下のとおり

    .. csv-table :: 
        :header: フィールド名,フィールド型,値
        :widths: 30,30,40

        最終更新日時,(システム標準項目),2015-01-20T10:05:14+09:00
        最終更新者,(システム標準項目),中西 義男(nakanishi)
        進捗区分,ラジオボタン,対策検討依頼済

2. リクエストヘッダの例 ::

    PUT /pe4j/api/rest/v1/xdb/record.json HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1
    Content-Type: application/json

  .. note :: 

    Content-Type に application/json を指定して下さい。 
    指定しない場合は JSON が解釈できないため、実行時エラーとなります。

3. リクエストボディの例

  .. code-block :: json

    {
        "system": 0,
        "database": "ﾌﾟﾛｾｽ管理型/クレーム管理DB",
        "notification": true,
        "notifyfollow": false,
        "external": false,
        "No": 1,
        "record": {
            "最終更新日時": {
                "value": "2015-01-20T10:05:14+09:00"
            },
            "最終更新者": {
                "value": {
                    "code": "nakanishi"
                }
            },
            "進捗区分": {
                "value": "対策検討依頼済"
            }
        }
    }

Webデータベース：フィールド定義の取得（GET）
===============================================
指定されたシステム区分、データベース名のデータベースに登録されている
フィールド定義を一覧で取得できます。




HTTPメソッド
-------------------------

GET


URI
--------------------

  http(s)://(POWER EGGサーバ)/pe4j/api/rest/v1/xdb/q/fields.json


リクエストパラメータ
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    system,数値,必須,"システム区分を指定します。（0:WebDB,1:汎用申請,2:CRM）"
    database,文字列,必須,データベース名を指定します。（(親フォルダ名)/(フォルダ名)/(データベース名)）

リクエストの例
----------------------------

1. レコード取得条件

  - 対象のデータベースは「ﾌﾟﾛｾｽ管理型/クレーム管理」

2. パラメータを HTTP のクエリ文字列で送信する場合

  HTTPのクエリ文字列の例 ::

    system=0&database=%EF%BE%8C%EF%BE%9F%EF%BE%9B%EF%BD%BE%EF%BD%BD%E7%AE%A1%E7%90%86%E5%9E%8B%2F%E3%82%AF%E3%83%AC%E3%83%BC%E3%83%A0%E7%AE%A1%E7%90%86DB

  ＜URLエンコーディングする前＞ ::

    system=0&database=ﾌﾟﾛｾｽ管理型/クレーム管理DB

  リクエストヘッダを含んだ例 ::

    GET /pe4j/api/rest/v1/xdb/q/fields.json?(HTTPのクエリ文字列) HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1

  ※Content-Typeヘッダは不要です。



レスポンス(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,データ型,必須,説明
    :widths: 15,15,15,55

    id,数値,,"フィールドID"
    fieldName,数値,,"フィールド名"
    fieldType,日付,,"フィールド型"
    itemClass,日付,,"項目種別 (0：システム項目、1：ユーザ定義項目)"
    required,日付,,"必須フラグ (0：必須ではない、1：必須)"




レスポンスの例
---------------------------

レコードのリストが JSON 配列で返されます。 


.. code-block :: json

    {
        "fields": [
            {
                "id": 7283,
                "fieldName": "品目番号",
                "fieldType": 1,
                "itemClass": 1,
                "required": 0
            },
            {
                "id": 7284,
                "fieldName": "番号",
                "fieldType": 2,
                "itemClass": 1,
                "required": 0
            },
            {
                "id": 7285,
                "fieldName": "必須項目", 
                "fieldType": 1,
                "itemClass": 1,
                "required": 1
            }
        ]
    }



Webデータベース：レコード件数の取得（GET）
===============================================
指定されたデータベースIDのデータベースに登録されている
条件に合致するレコードの件数を取得できます。




HTTPメソッド
-------------------------

GET


URI
--------------------

  http(s)://(POWER EGGサーバ)/pe4j/api/rest/v1/xdb/q/recordcount.json


リクエストパラメータ
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    corpId,文字列,必須,"レコード件数を取得する対象のデータベースが配置されている会社の外部会社コードを指定します。"
    empCode,文字列,必須,"外部社員コード１を指定します。"
    p1,数値,必須,"データベースIDを指定します。"
    p2,数値,必須,"一覧表示画面定義IDを指定します。"
    p3,数値,必須,"絞り込み条件IDを指定します。"
    p4,文字列,省略可,"フィールド定義のID$フィールドの値$比較演算子コード(ConditionType 0～99) を指定します。
    比較演算子コードの詳細は「WebDBのフィールド毎の利用可能な比較演算子コード」を参照してください。複数の条件を指定する場合は|で繋げます。すべてAND条件となります。(OR条件は指定不可）"

.. note ::

    データベースID、一覧表示画面定義ID、絞り込み条件IDは、レコード一覧画面の「この情報のURL」から確認が可能です。
    
    例）/XDB/XDB0102l.jsf?p1=101134&p2=1334&p3=1174
    
    - データベースID⇒p1=101134
    
    - 一覧表示画面定義ID⇒p2=1306
    
    - 絞り込み条件ID⇒p3=1174

リクエストの例
----------------------------

1. 件数取得条件

  - 対象のデータベースはデータベースID=123456
  - 一覧表示画面定義は一覧表示画面定義ID=1431
  - 絞り込み条件は絞り込み条件ID=1001
  - フィールド条件はフィールド定義ID=249（形式：数値）、フィールドの値=1000

2. パラメータを HTTP のクエリ文字列で送信する場合

  HTTPのクエリ文字列の例 ::

    corpId=friend00&empCode=ooishi&p1=123456&p2=1431&p3=1001&p4=249%241000%241

  ＜URLエンコーディングする前＞ ::

    corpId=friend00&empCode=ooishi&p1=123456&p2=1431&p3=1001&p4=249$1000$1

  リクエストヘッダを含んだ例 ::

    GET /pe4j/api/rest/v1/xdb/q/recordcount.json?(HTTPのクエリ文字列) HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1

  ※Content-Typeヘッダは不要です。
