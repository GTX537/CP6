  ドラッグ＆ドロップのファイル添付ウィンドウが開くようになりました。


V2.7からV2.8の変更点
=============================

- 【V2.7以降】net.poweregg.engine.customer.IPost#getPostの非互換（V1互換API）

  管理単位を追加したことにともない、IPost.getPostを実行すると
  「RuntimeException: UnitId can’t be null.」が発生します。

  ＜対応方法＞
  
  CT2_SFA_TRANSFERテーブルに以下のレコードを追加してください

    - 管理会社ID（ManageCorpID）= 0000000000
    - 管理単位ID（UnitID） = 1
    
- 【V2.7以降】net,poweregg.api.todo.TodoAPI#resistの非互換

    内容欄の書式をテキストエリアからリッチテキストに変更したことにともない、
    改行コードが「\\r\\n」から「<br/>」になりました。

    これにより、V2.7以降、内容に改行コードが含まれている場合は改行されなくなります

    ＜対応方法＞

    改行コードを「<br/>」に置換後、APIを呼び出すように変更してください

- net.poweregg.utils.DateUtils#fomratDateYMDの変更

  第2引数及び第3引数に“”を指定した場合に戻り値のフォーマットが変更されました

  - Ver2.4~Ver2.7の場合：yyyy/MM/dd(E)

  - Ver2.8の場合： yyyyMMdd


- RESTful WebサービスAPIを追加

- Webデータベースの外部連携処理を追加
