===============================
REST 組織情報API
===============================


社員情報取得(GET)
=================================================

引数で指定した社員の情報を1件取得します。


HTTPメソッド
---------------------------

GET

URI
----------------

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/organization/employee.json


リクエストパラメータ
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    baseDate,日付,必須,組織の発令日を決定するための基準日です。この日付時点の組織図が対象となります。
    corpCode,文字列,必須,"基準日時点で社員が所属する会社の外部会社コードを指定します。"
    empCode1,文字列,"省略可","基準日時点でのcorpCodeの会社での外部社員コード１を指定します。"
    empCode2,文字列,"省略可","基準日時点でのcorpCodeの会社での外部社員コード２を指定します。"

.. note ::

    empCode1、empCode2のどちらか、または両方を指定する必要があります

レスポンス(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,データ型,必須,説明
    :widths: 15,15,15,55

    userid,文字列,必須,ログインユーザID
    empName, 文字列, 必須, 社員名
    nameFurigana, 文字列, , 社員名ふりがな
    mailAddress, 文字列, ,メールアドレス
    mobilePhoneNo, 文字列, ,携帯電話番号
    mobileMailAddress, 文字列, , 携帯メールアドレス（非公開に設定されてる場合はnull）
    retireDate, 日付, , 退職日
    expireDate, 日付, , ID有効期限
    belongToDepts, JSON, 必須, 所属情報の配列（パラメタで指定された会社以外の所属は含まない）

所属情報（belongToDepts）のJSON型

.. csv-table ::
    :header: パラメータ名,データ型,必須,説明
    :widths: 15,15,15,55

    announceDate,日付,必須,基準日時点での発令日
    deptCode1, 文字列, , 外部部門コード１
    deptCode2, 文字列, , 外部部門コード２
    deptName, 文字列, 必須, 部門名
    empCode1, 文字列, , 外部社員コード１
    empCode2, 文字列, , 外部社員コード２
    titleCode, 文字列, , 外部役職コード
    titleName, 文字列, , 役職名
    deliberationOrder, 数値, , 承認順位
    isMainBelong, 真偽型, 必須, "true:主所属 false:兼務"

リクエストの例
-------------------------------

- "friend00"という外部会社コードの会社で外部社員コード１が"114403"の社員の情報を取得する

- HTTPのクエリ文字列の例 ::

    baseDate=2018-06-16&corpCode=friend00&empCode1=114403

- リクエストヘッダを含んだ例 :: 

    GET /pe4j/api/rest/v1/organization/employee.json?(HTTPのクエリ文字列) HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1

  ※Content-Typeヘッダは不要です。

部門情報取得(GET)
=================================================

引数で指定した部門の情報を1件取得します。


HTTPメソッド
---------------------------

GET

URI
----------------

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/organization/department.json


リクエストパラメータ
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    baseDate,日付,必須,組織の発令日を決定するための基準日です。この日付時点の組織図が対象となります。
    corpCode,文字列,必須,"基準日時点での部門が存在する会社の外部会社コードを指定します。"
    deptCode1,文字列,省略可,基準日時点でのcorpCodeの会社での外部部門コード１
    deptCode2,文字列,省略可,基準日時点でのcorpCodeの会社での外部部門コード２
    lowerDept,真偽値, ,"true：配下部門を取得する false：自部門のみ取得する（省略値）"

.. note ::

    deptCode1、deptCode2のどちらか、または両方を指定する必要があります

レスポンス(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,データ型,必須,説明
    :widths: 15,15,15,55

    announceDate,日付,必須,基準日時点での発令日
    dept, JSON, 必須, 自部門の部門情報
    lowerDepts, JSON, , "配下部門情報の配列。再帰的に末端の部門まで取得される。配下部門を取得しない場合、存在しない場合は空の配列。"


部門情報（dept、lowerDepts）のJSON型

.. csv-table ::
    :header: パラメータ名,データ型,必須,説明
    :widths: 15,15,15,55

    deptId,数値,必須,部門ID
    aboveDeptId, 数値, , "上位部門の部門ID。上位部門が存在しない場合はnull"
    deptCode1, 文字列, , 外部部門コード１
    deptCode2, 文字列, , 外部部門コード２
    deptName, 文字列, 必須, 部門名称
    deptShortName, 文字列, 必須, 部門略称
    deptKana, 文字列, ,部門フリガナ
    address, 文字列, ,住所
    tel, 文字列, ,電話番号
    fax, 文字列, ,FAX番号
    location,文字列, ,地区名
    deptLevel,数値,必須,組織階層レベル
    deptClass,文字列,必須,"“1”:通常部門 “2”:申請部門"
    decide,真偽値,必須,"true:自部門での決裁可 false:自部門での決裁不可（上位委譲）"

リクエストの例
-------------------------------

- "friend00"という外部会社コードの会社で外部部門コード１が"300"の部門の情報を配下部門を含んで取得する

- HTTPのクエリ文字列の例 ::

    baseDate=2018-06-16&corpCode=friend00&deptCode1=300&lowerDept=true

- リクエストヘッダを含んだ例 :: 

    GET /pe4j/api/rest/v1/organization/department.json?(HTTPのクエリ文字列) HTTP/1.1
    Host: pe280demo.poweregg.net
    X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1

  ※Content-Typeヘッダは不要です。

社員情報登録更新(PUT)
=================================================

社員の情報(更新キーはユーザID)を登録・更新します。

登録、更新を行う社員をリクエストボディに設定してください。

HTTPメソッド
---------------------------

PUT

URI
----------------

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/organization/employee.json


リクエストボディ(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    rbody,JSON,必須,社員情報の配列

rbodyで指定するJSON型

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    userId,文字列,必須,ユーザID
    empName,文字列,(※1)(※2),氏名
    empNameKana,文字列,(※1)(※2),フリガナ
    loginPass,文字列,(※2),ログインパスワード
    appPass,文字列,(※2),承認パスワード
    mailAdr,文字列,,メールアドレス
    popServer,文字列,,メールサーバー
    popUser,文字列,,メールアカウント
    mailPass,文字列,(※2),メールパスワード
    mPhoneno,文字列,,携帯番号
    mMailAdr,文字列,,携帯電話メールアドレス
    adrOpenClass,文字列,,携帯電話メールアドレス公開区分(1:公開する 0:公開しない)
    extno,文字列,,内線番号
    expire,日付,,ID有効期限
    retireDate,日付,,退職日
    remark1,文字列,,メモ1
    remark2,文字列,,メモ2
    remark3,文字列,,メモ3
    passExpire,日付,,パスワード失効日
    ls01,文字列,,ライセンス01(1:使用する 0:使用しない)
    ls02,文字列,,ライセンス02(1:使用する 0:使用しない)
    ls03,文字列,,ライセンス03(1:使用する 0:使用しない)
    ls04,文字列,,ライセンス04(1:使用する 0:使用しない)
    ls05,文字列,,ライセンス05(1:使用する 0:使用しない)
    ls06,文字列,,ライセンス06(1:使用する 0:使用しない)
    ls07,文字列,,ライセンス07(1:使用する 0:使用しない)
    ls08,文字列,,ライセンス08(1:使用する 0:使用しない)
    ls09,文字列,,ライセンス09(1:使用する 0:使用しない)
    ls10,文字列,,ライセンス10(1:使用する 0:使用しない)

| ※1：登録時は必須。
| ※2：更新時にパラメタの指定があった場合は必須。


レスポンス(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,データ型,必須,説明
    :widths: 15,15,15,55

    beforeCount,数値,必須,更新前件数(退職済、ID有効期限を過ぎているデータを含む)
    inputCount,数値,必須,ボディの件数
    registCount,数値,必須,登録件数
    updateCount,数値,必須,更新件数
    afterCount,数値,必須,更新後件数(退職済、ID有効期限を過ぎているデータを含む)
    errorInfo,JSON,,エラー情報

errorInfoで指定するJSON型

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    code,文字列,必須,コード
    message,文字列,必須,メッセージ
    details,文字列,必須,詳細

リクエストの例
-------------------------------

1. リクエストヘッダ :: 

    POST /pe4j/api/rest/v1/organization/employee.json HTTP/1.1
    Host: pe280demo.poweregg.net

地区情報登録更新(PUT)
=================================================

地区の情報(更新キーは外部地区コード)を登録・更新します。

有効なすべての地区情報の一覧をリクエストボディに設定してください。

更新前に有効となっており、リクエストボディに存在しない地区は無効扱いとなります。


HTTPメソッド
---------------------------

PUT

URI
----------------

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/organization/location.json


リクエストボディ(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    rbody,JSON,必須,地区情報の配列

rbodyで指定するJSON型

.. csv-table ::
    :header: パラメータ名,指定する値,必須,説明
    :widths: 15,15,15,55

    fLocationCode,文字列,必須,外部地区コード
    locationName,文字列,(※1)(※2),地区名称

| ※1：登録時は必須。
| ※2：更新時にパラメタの指定があった場合は必須。


レスポンス(JSON)
----------------------------------

.. csv-table ::
    :header: パラメータ名,データ型,必須,説明
    :widths: 15,15,15,55

    beforeCount,数値,必須,更新前件数(無効データも含む)
    inputCount,数値,必須,ボディの件数
    registCount,数値,必須,登録件数
    updateCount,数値,必須,更新件数
    afterCount,数値,必須,更新後件数(無効データも含む)
    errorInfo,JSON,,エラー情報

errorInfoで指定するJSON型

.. csv-table ::

    details,文字列,必須,詳細

リクエストの例

組織図連携
=================================================

| 発令予定の組織図（部門階層、社員所属、審議者）情報を登録します。
| 組織図情報については、以下の流れで順に処理を呼び出す必要があります。
| 
|   Step1：予定組織図の作成
|     →会社、発令日をパラメタとして、現行組織図をコピーして予定組織図を仮データを作成します。
| 
|   Step2：部門情報登録更新
|     →部門情報をを予定組織図の仮データに更新します。
|       更新を行う場合は更新対象の部門のみではなく、すべての部門情報をリクエストボディにセットする必要があります
| 
|   Step3：社員所属情報登録更新
|     →社員の所属情報を予定組織図の仮データに更新します。
|       更新を行う場合は異動対象社員のすべての所属情報（兼務を含む）をリクエストボディにセットする必要があります
| 
|   Step4：審議者情報登録更新
|     →部門の審議者情報を予定組織図の仮データに更新します。
|       更新を行う場合は更新対象部門のすべての審議者情報をリクエストボディにセットする必要があります
| 
|   Step9：予定組織図の作成完了
|     →予定組織図の仮データを予定組織図情報として更新します。
| 
| Step2～Step4にてエラーが発生した場合には「StepZ：予定組織図の破棄」を呼び出し、予定組織図の仮データを破棄してください。
