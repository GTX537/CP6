==========================
開発に必要な環境
==========================

POWER EGG3.0 SDKを利用してアドオンアプリケーションを開発するには、
次の環境が必要になります。

- JDK8 update121以上、JavaEE 7に対応した開発環境

POWER EGG3.0 Ver3.2cは、JDK8、Java EE 7を利用して開発されています。
アドオンアプリケーションを開発するには、これらのJava APIに対応した
開発環境が必要になります。

開発の効率を上げるためにも、統合開発環境ソフトウェアを使用すること
を推奨します。
これらのAPIに対応している統合開発環境ソフトウェアとしては以下の
ものがあります。

Eclipse IDE for Java EE Developers

開発ツール上でPOWER EGG3.0の開発環境を構築する手順については、付録を参照してください。


- Java EE 7に対応したアプリケーションサーバ

開発したアプリケーションを実行するために、Java EE 7に対応した
アプリケーションサーバが必要です。

※運用環境と同じサーバを準備することを推奨します。

- Payara Server 4.1.2.181

- Interstage Application Server V11 + JavaEE 7個別修正

- POWER EGG3.0 SDK

APIの仕様やテーブルレイアウトを参照するためにPOWER EGG3.0 SDKで
提供されるAPIドキュメントが必要です。

- POWER EGG3.0が動作する環境
