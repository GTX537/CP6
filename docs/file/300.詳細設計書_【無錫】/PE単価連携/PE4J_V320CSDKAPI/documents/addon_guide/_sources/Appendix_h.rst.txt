申請処理のシーケンス
========================

申請入力から申請確認まで
---------------------------

.. uml ::

    participant 申請入力画面 as applyxhtml
    note over applyxhtml
        例)購入申請
    end note
    participant 申請アプリケーションBean as AppBean
    participant 申請アプリサービスBean as AppServiceBean
    participant DataflowHelperBean as DataflowHelper
    note over DataflowHelper
        申請アプリケーションはDataflowHelperコンポーネントを
        @Injectアノテーションで生成する
    end note
    AppBean -> DataflowHelper : @Inject
    applyxhtml -> AppBean : [確認]ボタン
    note over DataflowHelper
        申請入力の[確認]ボタンが押されたとき、申請アプリケーション
        はDataflowHelperに申請に必要な情報をセットし、
        prepareApplyメソッドを呼び出して、申請受付番号を取得する.
    end note
    AppBean -> DataflowHelper : 様式コードをセット
    AppBean -> DataflowHelper : 申請者情報,申請日をセット
    AppBean -> DataflowHelper : ルート判定条件をセット
    AppBean -> DataflowHelper : 申請本文XMLをセット
    AppBean -> DataflowHelper : XSLファイル名をセット
    note over DataflowHelper
        申請本文XMLをHTMLに変換するためのXSLファイルのファイル
        名をセットする.
        ここでセットするXSLファイルは、クラスパスの"/XSLT"ディレクトリ
        に存在しなければならないので、あらかじめ配置しておくこと.
        XSLはhtml全体でなく本文部分の要素のみを生成するものを作成.
    end note
    AppBean -> DataflowHelper : 以前の申請受付番号をセット
    AppBean -> DataflowHelper : ルート変更できるかをセット
    note over DataflowHelper
        申請確認画面からルート変更する
        ことができるかどうかをセットする.
    end note
    AppBean -> DataflowHelper : prepareApply
    DataflowHelper -> DataflowHelper : ルート情報・起案内容HTML生成
    AppBean <- DataflowHelper : 申請受付番号
    applyxhtml <- AppBean : 申請確認画面に遷移
    
申請確認から申請まで
------------------------

.. uml ::

    participant 申請確認画面 as confirmxhtml
    participant 申請アプリケーションBean as AppBean
    participant 申請アプリサービスBean as AppServiceBean
    participant DataflowHelperBean as DataflowHelper
    participant ルート変更画面 as routechangexhtml
    AppBean -> DataflowHelper : @Inject
    confirmxhtml -> DataflowHelper : 起案内容・ルート情報取得
    confirmxhtml <- DataflowHelper : 起案内容HTML・ルート情報
    note over confirmxhtml
        申請確認画面にincludeされた
        ワークフロー画面部品は
        DataflowHelperから申請本文、
        ルート情報を取得して表示する.
    end note
    confirmxhtml -> DataflowHelper : [ルート変更]ボタン
    DataflowHelper -> routechangexhtml : ルート変更画面に遷移
    note over routechangexhtml
        ルート変更画面はデータフロー
        ヘルパーと会話し、ルート情報
        の編集を行う.
    end note
    DataflowHelper <- routechangexhtml : ルート追加・変更操作
    DataflowHelper <- routechangexhtml : [確定]ボタン
    confirmxhtml <- DataflowHelper : 申請確認画面に戻る
    confirmxhtml -> AppBean : [申請]ボタン
    AppBean -> AppServiceBean : 入力データを保存
    AppBean -> DataflowHelper : 申請を確定する(commitApply)
    DataflowHelper -> DataflowHelper : 申請データをDBに保存し\nワークフローを開始
    AppBean -> DataflowHelper : ヘルパーの状態をリセットする
    note over AppBean
        申請エラーが無ければ、ヘルパー
        をリセットする
    end note
    DataflowHelper -> DataflowHelper : 内部のデータを破棄する
    note over DataflowHelper
        リセット命令が呼び出されたら、申請パラメタ、
        ルート情報などの内部データを破棄し、
        コンポーネントを初期化する
    end note
    AppBean --> confirmxhtml : 一覧画面に遷移する
    
申請内容表示処理のシーケンス
===============================

.. uml ::

    participant 画面 as display
    participant 申請アプリケーションBean as AppBean
    participant 申請アプリサービスBean as AppServiceBean
    participant DataflowHelperBean as DataflowHelper
    AppBean -> DataflowHelper : @Inject
    display -> AppBean : [件名]リンククリック
    AppBean -> AppServiceBean : データを読み込む
    AppBean <- AppServiceBean : 読み込んだデータ
    AppBean -> DataflowHelper : loadApplicationForm(申請受付番号)
    note over DataflowHelper
        引数で指定された申請受付番号の
        詳細表示画面 申請データ、
        承認状況を読み込む
    end note
    AppBean -> display : 「詳細表示」画面に遷移
    note over display
        詳細表示画面は、申請データ
        表示用部品をincludeし、
        案件を画面に表示する
    end note
    display -> DataflowHelper : 取下げ、コメント追加等
    note over display
        申請データ表示用部品はDataflowHelperと
        会話し、[取下]や[コメント追加]、
        [ルート変更]などの機能を提供する.
    end note
    display -> AppBean : [前]、[次]リンククリック
    AppBean -> AppServiceBean : データを読み込む
    AppBean <- AppServiceBean : 読み込んだデータ
    AppBean -> DataflowHelper : loadApplicationForm(申請受付番号)
    AppBean -> display : 再表示


取下げ処理のシーケンス
========================

.. uml ::

    participant 詳細表示画面 as display
    participant 案件表示画面部品 as partshtml
    participant 削除取下確認 as confirmdisplay
    participant 申請アプリケーションBean as AppBean
    participant DataflowHelperBean as DataflowHelper
    AppBean -> DataflowHelper : @Inject
    AppBean -> DataflowHelper : 取下確認時に表示する\nメッセージをセット
    note over DataflowHelper
        案件表示画面部品で「取下げ」ボタンが押された時に
        取下げ確認画面に表示するためのメッセージ文字列
        を設定する.
        設定しない場合は、エンジン固定のメッセージになる
    end note
    display -> partshtml : <ui:include>
    partshtml -> DataflowHelper : [取下]ボタン
    DataflowHelper -> DataflowHelper : パスワードチェック
    note over DataflowHelper
        DataflowHelperは入力されたパスワードが
        正しいかチェックし、取下げできる場合は、
        "confirmWithdraw"の文字列を返す.
        パスワードが正しくない場合は、
        facesMessageに、パスワードエラー
        メッセージをセットして、nullを戻す.
    end note
    display <- DataflowHelper : "confirmWidhdraw"
    note over display
        申請アプリケーションのページフロー定義
        で、詳細表示画面に"confirmWithdraw"
        で取下げ確認画面に遷移する記述を
        行う.
    end note
    display -> confirmdisplay : 削除取下確認画面に遷移
    confirmdisplay -> AppBean : [取下]ボタン
    AppBean -> DataflowHelper : widhdraw()
    DataflowHelper -> DataflowHelper : 取下更新
    AppBean -> confirmdisplay : 一覧画面に遷移
