=====================================
アドオン開発における規約
=====================================

この章では、アドオン開発時における各種規約について説明します。

命名規約
=================

Javaクラス名(CDIコンポーネント、JSF Managed Bean、EJB等)
-----------------------------------------------------------------------

アドオン開発においてJavaのクラスを開発する場合は、以下の方法でクラス名を付けるようにしてください。
・パッケージ名として自社ドメイン名を逆順にしたものを頭に付ける
・クラス名は英大文字で開始する

（例）ドメイン名が hoge.co.jp の場合
パッケージ名
jp.co.hoge.xxxxxx
クラス名
UAP0101

CDI Bean
------------------------------

アドオン開発においてCDI Beanを開発する場合は、先頭が”U”で始まる名称を付けてください。


WEBコンテンツ（XHTML、GIF等）格納ディレクトリ
--------------------------------------------------------

アドオンアプリケーションで利用するXHTMLやGIFファイルなどは、
POWER EGG3.0のWebrootのUAPフォルダ以下に格納してください。
なお、POWER EGGインストール時に作成されるディレクトリ、
ファイルは追加・変更・削除を行わないでください。


テーブル、ビュー
-------------------------------

アドオンアプリケーションに使用するテーブル、ビュー等データベース
オブジェクトをPOWER EGG3.0と同じスキーマに作成する場合は、
必ず先頭を"U"から始まる名前としてください。（例：UGYOUSEKI_T）


文字コードセット
------------------------------

POWER EGG3.0では、データベースの文字セットやJavaプログラム、
xhtmlの文字コードセットとして、utf-8を前提としています。
アドオンシステムでも、ソースコードはutf-8のコードで記述してください。

コーディング規約
==========================

HTMLに関する規約
----------------------------

(1)使用するバージョン
HTMLのバージョンは、html5(xhtml)とします。

(2)必ず指定する記述

①ドキュメントヘッダ

■通常のドキュメント

.. code-block:: html

    <!DOCTYPE html>
 

XMLに関する規約
---------------------------

(1)使用するバージョン
XMLのバージョンは、1.0とします。

XSLに関する規約
----------------------------

(1)使用するバージョン
XML, XSLのバージョンは、1.0とします。
