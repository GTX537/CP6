=======================
フレームワーク
=======================

POWER EGG3.0 Ver3.2cが採用している開発フレームワーク
=======================================================

本システムでは、基盤技術として、Java Enterprise Edition 7 
(EJB 3.2, JPA 2.1, JSF 2.2, CDI 1.1)を採用しています。

データベースアクセス
===============================

データベースへのアクセスには、Java Persistance API 2.1を利用しています。
JPAプロバイダとしては、EclipseLinkを採用しています。

アプリケーションロジック
=====================================

アプリケーションロジックは、CDIビーン、EJBステートレスセッションビーン
（サービスロジック）として作成しています。

プレゼンテーション
==============================

プレゼンテーション層で利用するビューは Facelet(xhtml)で作成します。
