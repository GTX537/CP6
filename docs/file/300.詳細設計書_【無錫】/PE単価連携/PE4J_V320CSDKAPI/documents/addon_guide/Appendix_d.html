28. 付録D,サンプルアプリケーション¶

28.1. サンプルアプリケーションの説明¶

このサンプルアプリケーションでは、社員の給与振込口座申請を題材としています。

28.1.1. 画面イメージ¶

①申請画面

②承認時画面

28.1.2. 機能の概要¶

  • 給与振込口座の申請を行うことができます。

  • 既に口座が登録されていれば、その口座の情報を初期値として表示します。

  • 振込先銀行の選択は、銀行選択部品で行います。

  • 申請した内容は、ワークフローエンジンを通して決裁されます。

  • 申請が決裁された時点で、申請した口座を本人の振込口座としてデータベースを更新します。

（１）ワークフロー関連

・申請様式として"9001"番を使用します。

・申請時の条件区分値は"1"を使用します。

28.2. SDKサンプルプロジェクトのビルド¶

28.2.1. SDKサンプルプロジェクトのEclipseへの取り込み¶

  1. Eclipseで「ファイル」-「インポート」を実行します。

  2. 既存プロジェクトをワークスペースへを選択します。

  3. アーカイブ・ファイルの選択で"sdksample.zip"を選択します。

  4. インポートしたプロジェクトディレクトリ配下にpe4j-earディレクトリを作成し、 pe4j-ear.earをjarコマンドで展開します。

    pe4j-ear> jar xvf pe4j-ear.ear

  5. インポートしたプロジェクトディレクトリ配下に pe4j-webappディレクトリを作成し、 pe4j-ear/pe4j-webapp.warをjarコマンドやzip展開ツールで展開します

  6. インポートしたプロジェクトディレクトリ配下に pe4j-engineディレクトリを作成し、 pe4j-ear/pe4j-engine.jarをjarコマンドやzip展開ツールで展開します

  7. インポートしたプロジェクトディレクトリ配下にpe4j-jpa-mainディレクトリを作成し、 pe4j-ear/lib/pe4j-jpa-main.jarをjarコマンドやzip展開ツールで展開します

  8. プロジェクトをリフレッシュします。

注釈

展開元ファイル(.ear,.jar,.war)は展開後削除してください。

28.2.2. SDKサンプルプロジェクトのビルド¶

  1. persistence.xmlの編集

    アドオンで作成したエンティティを有効にするため、pe4j-jpa-main/META-INF/ persistence.xmlにアドオンエンティティが格納されているjarファイルを登録します。

    <!-- sdksample -->
<jar-file>empAccount-entity.jar</jar-file>

  2. application.xmlの編集

    アドオンのEJBを有効にするため、pe4j-ear/META-INF/application.xmlにアドオン のejb-jarを登録します。

    <module>
    <ejb>empAccount-ejb.jar</ejb>
</module>

  3. web.xmlの編集

    アドオンで作成したJSFのナビゲーション定義を参照するため、 pe4j-webapp/WEB-INF/web.xmlのjavax.faces.CONFIG_FILES定義にアドオン開発 したナビゲーション定義ファイルを追加します。

    <context-param>
    <param-name>javax.faces.CONFIG_FILES</param-name>
    <param-value>/WEB-INF/faces-config.xml,
        ...
        ...
        /WEB-INF/navigations/UAP01Bean.xml
    </param-value>
</context-param>

    注釈

    既存の定義を削除するとPOWER EGGが正しく動作しなくなります。 アドオンの定義を追加するだけにしてください。

  4. pe4j-earのビルド

    build.xmlのallターゲットを実行し、アドオンが組み込まれたpe4j-earを生成します。 実行後、プロジェクトディレクトリの配下にpe4j-ear.earが作成されます。

  5. pe4j-earの配備

    生成されたpe4j-earをGlassFishにデプロイします。 配備の方法については、「付録B. アドオン開発環境の作成」 を参照してください。

28.2.3. 配備後の設定¶

  1. アドオン用テーブルの作成

    POWER EGGのデータベースにアドオン用のテーブルを作成します。

    SQLがsdksample/sqlフォルダに格納されているので、PSQLコマンド等 で実行し、テーブルを作成してください。

  2. 申請様式の登録

    サンプル申請用の申請様式を登録します。

    • 様式コード：9100

    • 様式名称：給与振込口座申請

    • ルート判定条件：区分値

    • ルートタイプ：申請

    • 採番ルール：標準採番ルール

    注釈

    「http://ホスト名:ポート/pe4j/」から管理者ユーザにてログインを行って操作してください。

    デモキットのデータを利用している場合、「ユーザID:ooishi / パスワード:123」でログインできます。

    注釈

    「申請様式の登録」～「申請種別の登録」は「システム設定 > 汎用申請の設定」配下のメニューから設定できます。

  3. 登録した様式に対して、「決裁」事後処理を登録します

    • 実行時のタイミング：決裁

    • 処理種別：Java

    • 処理名：sample.empaccount.UAP01AfterFlow

    • 実行区分：実行する

  4. 申請種別の登録

    登録した様式に対して申請種別を登録します

    • 種別名：給与振込口座申請

    • 区分：1

  5. システム管理の「処理の登録」を利用して処理を登録します

    • 処理名：給与振込口座申請

    • URLの前に"/pe4j"を付けるにチェック

    • URL：UAP/UAP0101e.jsf

    注釈

    「処理の登録」および「メニューの登録」は「システム設定 > システム共通 > メニューの設定」から設定できます。

  6. システム管理のメニューの登録を利用して、登録した処理をメニューに割り当 てます。

    注釈

    登録したメニューは再度ログインすることで利用可能となります。
