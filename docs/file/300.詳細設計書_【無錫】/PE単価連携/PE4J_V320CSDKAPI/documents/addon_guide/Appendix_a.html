25. 付録A 過去のバージョンからの変更点¶

25.1. V2.0からV2.0.1の変更点¶

  • Webサービスが利用可能になりました。

25.2. V2.0SR1からV2.1の変更点¶

  • dataTableSelectOneRadioを追加

  • inputTimeRangeを追加

25.3. V2.1からV2.2の変更点¶

  • inputAttachFileの画面をV2.2で追加されたアップロードアプレットに置き換え

25.4. V2.2からV2.3の変更点¶

  • palenControllerの引数を追加

  • inputTimeを追加

  • URL型事後処理の記述を追加

  • POWER EGG2.0ワークフローWebサービスを追加

25.5. V2.3からV2.4の変更点¶

  • 変更点はありません。

25.6. V2.4からV2.5の変更点¶

  • カレンダーイベント関連APIを追加

  • ログインパスワード同期インターフェースを追加

25.7. V2.5からV2.6の変更点¶

  • inputDateRangeにuseUnlimitedパラメタを追加

  • inputTextでは改行のみの入力は未入力として判定するように変更されました。

  • カレンダーAPIの戻り値であるDateDtoのgetDayメソッドの戻り値の型が intからIntegerに変更されました。（V2.3より）

25.8. V2.6からV2.7の変更点¶

  • Oracle Application Serverのサポートは終了しました。

  • ファイル添付部品では、HTML5対応ブラウザを利用している場合は、 Javaアプレットによるドラッグ＆ドロップで無く、HTML5の ドラッグ＆ドロップのファイル添付ウィンドウが開くようになりました。

25.9. V2.7からV2.8の変更点¶

  • 【V2.7以降】net.poweregg.engine.customer.IPost#getPostの非互換（V1互換API）

    管理単位を追加したことにともない、IPost.getPostを実行すると 「RuntimeException: UnitId can’t be null.」が発生します。

    ＜対応方法＞

    CT2_SFA_TRANSFERテーブルに以下のレコードを追加してください

    • 管理会社ID（ManageCorpID）= 0000000000

    • 管理単位ID（UnitID） = 1

  • 【V2.7以降】net,poweregg.api.todo.TodoAPI#resistの非互換

    内容欄の書式をテキストエリアからリッチテキストに変更したことにともない、 改行コードが「\r\n」から「<br/>」になりました。

    これにより、V2.7以降、内容に改行コードが含まれている場合は改行されなくなります

    ＜対応方法＞

    改行コードを「<br/>」に置換後、APIを呼び出すように変更してください

  • net.poweregg.utils.DateUtils#fomratDateYMDの変更

    第2引数及び第3引数に“”を指定した場合に戻り値のフォーマットが変更されました

    • Ver2.4~Ver2.7の場合：yyyy/MM/dd(E)

    • Ver2.8の場合： yyyyMMdd

  • RESTful WebサービスAPIを追加

  • Webデータベースの外部連携処理を追加

25.10. V2.8からV2.8cの変更点¶

  • 開発・実行に必要なJDKのバージョンがJDK5からJDK6に変更になりました。

25.11. V2.8cからV2.10cの変更点¶

  • 開発・実行に必要なJDKのバージョンがJDK6からJDK8に変更になりました。

  • 開発フレームワークがJavaEE7に変更になりました。

25.12. V2.10cからV2.11cの変更点¶

  • ワークフローのURL事後処理のパラメタが追加されました。

25.13. V2.11cからV3.0の変更点¶

  • REST APIの種類が追加されました。

    • 組織

    • アシストメッセージ

    • スケジュール

    • 社内メール

    • 作業

    • ワークフロー

  • Payara Serverのバージョンが4.1.1.163から4.1.2.181に変更されました。

  • 対応するSymfowareのバージョンとしてV12.3が追加されました。

25.14. V3.0cからV3.1の変更点¶

  • APIの追加・変更はありません

25.15. V3.1cからV3.2cの変更点¶

  • REST API呼び出し時にサーバー側で内部エラーが発生したときに返却される "WSA99999SE" のメッセージの detailsに、サーバーのスタックトレースはセットしないように変更されました。(脆弱性対応)

  • 社内メール送信のREST-APIにBCCを指定するためのパラメタが追加されました。

  • ワークフローのREST-APIに強制否認・差戻しを追加しました。

  • HTTP DELETEメソッドでの呼び出しに関する注意事項を記載しました。

  • RESTのワークフロー申請APIでxslFileNameを指定しない場合、スマートフォンの承認画面でもcontentXmlに 指定したxhtmlが表示され、承認できるようになりました。

  • 組織図連携のREST-APIを追加しました。

  • スケジュール取得のREST-APIを追加しました。

  • ワークフローのREST-APIにPDF申請を追加しました。

  • WebDBのフィールド定義取得、レコード件数取得のREST-APIを追加しました。

  • 処理権限変更のREST-APIを追加しました。

  • アドオン開発環境の作成で利用するEclipseのバージョンを4.7に変更しました。

  • Webデータベース外部参照のWebAPI連携を追加しました。
