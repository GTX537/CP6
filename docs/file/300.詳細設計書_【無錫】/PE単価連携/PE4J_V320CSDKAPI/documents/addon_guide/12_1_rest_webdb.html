13. REST WebデータベースAPI¶

13.1. Webデータベース：レコードの取得（GET）¶

レコードをクエリで条件を指定して取得できます。

  • 一度に取得できるレコードは 100件までです。（100件以上取得する場合は レコードの取得範囲を変えて複数回実行してください）

  • ソート順に指定できるフィールドはフィールド設定で「ソート対象」を指定できるフィールドです。

  • 検索条件の指定方法、検索条件に指定できるフィールド、論理演算子、比較演算子は絞り込み条件と同じです。

以降、①は「ブロック毎の論理演算子」、②は「フィールド毎の論理演算子」と記述します。

13.1.1. HTTPメソッド¶

GET

13.1.2. URI¶

  1. パラメータを HTTP のクエリ文字列で送信する場合

http(s)://(POWER EGGサーバ)/pe4j/api/rest/v1/xdb/q/records.json

  1. パラメータを JSON形式で送信する場合

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/xdb/records.json

注釈

GETでのリクエストボディの指定をサポートしていないクライアントでは使用できません

13.2. Webデータベース：レコードの登録（POST）¶

1件のレコードを登録できます。

13.2.1. HTTPメソッド¶

POST

13.2.2. URI¶

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/xdb/record.json

13.2.3. リクエストパラメータ¶

パラメータ名

指定する値

必須

説明

system

数値

省略可

システム区分を指定します。（0:WebDB,2:CRM） ※省略時は0が指定されます。

database

文字列

必須

データベース名を指定します。（(親フォルダ名)/(フォルダ名)/(データベース名)）

notification

真偽値

省略可

通知の有無を指定します。 （true:通知する,false:通知しない） ※省略時はfalseが指定されます。

notifyfollow

真偽値

省略可

フォロー通知の有無を指定します。 （true:通知する,false:通知しない） ※省略時はfalseが指定されます。

external

真偽値

省略可

外部連携（アドオン呼び出し）の有無を指定します。 （true:実行する,false:実行しない） ※省略時はtrueが指定されます。

record

Object

必須

レコードの情報（フィールド名とフィールドの値）をオブジェクトで指定します。 ※フィールド値の仕様についてはフィールドの形式により異なります。 詳細については、後述「フィールド形式」をご確認ください。 ※明細行（details）は省略可能です。

リクエストボディの構造

{
    "system": (システム区分),
    "database": "(データベース名)",
    "notification": (通知の有無),
    "notifyfollow": (フォロー通知の有無),
    "external": (外部連携の有無),
    "record": {
        "(フィールド名)": {
            "value": "(フィールド値)"
        },
        "details": [
            {
                "(明細行フィールド名)": {
                    "value": "(フィールド値)"
                }
            }
        ]
    }
}

  1. レコード登録条件

  • 対象のデータベースは「プロセス管理型/クレーム管理」

  • 通知の有無は「通知する」

  • フォロー通知の有無は「通知しない」

  • 外部連携の有無は「実行しない」

  • 登録するフィールドは以下のとおり

    レコード

    フィールド名

    フィールド型
