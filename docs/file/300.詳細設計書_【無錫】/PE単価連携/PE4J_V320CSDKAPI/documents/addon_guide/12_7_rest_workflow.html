19. REST ワークフローAPI¶

19.1. 申請(POST)¶

ワークフロー文書の申請を行います。

19.1.1. HTTPメソッド¶

POST

19.1.2. URI¶

http(s)://(POWER EGGサーバ) /pe4j/api/rest/v1/workflow/apply.json

19.1.3. リクエストボディ(JSON)¶

パラメータ名

指定する値

必須

説明

appRecpNo

数値

申請受付番号。再申請の場合にのみ指定します。新規申請の場合はセットしないでください。

corpId

文字列

必須

申請者の外部会社コード

deptCode

文字列

必須

申請者の外部部門コード１

empCode

文字列

必須

申請者の外部社員コード１

appliedDate

日付

必須

申請日

baseForm

文字列

必須

申請様式コード

condition1

文字列

必須

条件区分値１。 申請様式のルート判定条件が「区分値」の場合は区分値を設定します。 申請様式のルート判定条件が「条件値」の場合は条件値を設定します。 申請様式のルート判定条件が「区分値＋条件値」の場合は条件値を設定します。

condition2

文字列

条件区分値２。 申請様式のルート判定条件が「区分値＋条件値」の場合は区分値を設定します。

priority

文字列

"0001"...通常（省略値）、"0002"...緊急

title

文字列

必須

件名

contentXml

文字列

必須

申請内容本文(xmlまたはxhtml) xhtmlを渡す場合、head,bodyなどのタグは含まないdiv要素内のxhtmlをセットしてください。

xslFileName

文字列

起案内容を表示する際のXSLTで利用するXSLファイル名 （ファイルはあらかじめPEWEB\appLib\XSLフォルダに格納しておく必要があります。 ※POWER EGG Open CloudではXSLフォルダにファイルを追加できないので、このパラメタは利用できません） このパラメタが未指定の場合はcontentXmlで指定した内容がそのまま起案内容として表示されます。 スマートフォンでもcontentXmlで指定した内容がそのまま表示されますので、スマートフォンでも 起案内容が期待通り表示できるかご確認ください。

attachments

JSON

ファイルアップロードAPIでアップロードした添付ファイルのfileKeyの配列。

relativeurls

JSON

関連情報URL(relativeurlの配列)

proxyCorpId

文字列

代理申請の場合、代理申請者の外部会社コードをセット

proxyDeptCode

文字列

代理申請の場合、代理申請者の外部部門コード1をセット

proxyEmpCode

文字列

代理申請の場合、代理申請者の外部社員コード1をセット

routeModified

真偽値

ルート変更を行う場合はtrue、省略値はfalse。trueを指定した場合 「保留」状態で申請されるのでユーザは画面から保留状態の申請を開き、ルート設定後に申請を行う必要があります。

autoRouting

真偽値

ワークフロールートを設定から自動生成するかどうかを指定する。 デフォルトはtrue。falseを指定した場合はルート生成は行われないので、 addUsersToHead, addUsersToEnd等でルートを指定する必要があります。

addUsersToHead

JSON

生成されたルートの先頭に追加する承認者をセットします。

addUsersToEnd

JSON

生成されたルートの後ろに追加する承認者をセットします。

addUsersToRoute

JSON

指定された位置に挿入する承認者をセットします。

relativeurlsで指定するJSON型

パラメータ名

指定する値

必須

説明

relationUrl

文字列

必須

関連情報のURL

urlComment

文字列

関連情報URLコメント

addUsersToHead, addUsersToEnd, addUsersToRouteで指定するJSON型

パラメータ名

指定する値

必須

説明

authority

文字列

必須

ルート上の権限（”0001”:審議、”0002”:回覧、”0004”:同報）

corpId

文字列

必須

追加ユーザの外部会社コード

deptCode

文字列

必須

追加ユーザの所属部門の外部部門コード1

empCode

文字列

必須

追加ユーザの外部社員コード1

approvalOrder

数値

追加ユーザの承認順序。addUsersToRouteの場合のみ指定します。

19.1.4. レスポンス(JSON)¶

申請案件の管理番号(appRecpNo)が返却されます。

パラメータ名

データ型

必須

説明

appRecpNo

数値

必須

申請受付番号

historyNo

数値

必須

履歴番号

19.1.5. リクエストの例¶

  • リクエストヘッダ

    POST /pe4j/api/rest/v1/workflow/apply.json HTTP/1.1
Host: pe280demo.poweregg.net
X-API-Key: 7706d1ce-01a0-463b-a162-d389cec21eb1
Content-Type: application/json

  • リクエストボディ

    {
    "corpId": "friend",
    "deptCode": "eigyo",
    "empCode": "ooishi1",
    "appliedDate": "2017-06-15",
    "baseForm": "A001",
    "condition1": "1",
    "title": "テスト申請",
    "contentXml": "<doc>申請内容</doc>",
    "attachments": [
        {
            "fileKey": "afksjslkdfja-ksjflaj-skdjfalk"
        }
    ]
}

19.1.6. レスポンスの例¶

{
    "appRecpNo": 1001,
    "historyNo": 1
}
