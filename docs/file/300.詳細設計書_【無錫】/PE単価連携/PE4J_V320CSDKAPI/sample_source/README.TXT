１．はじめに

　この説明書では、POWER EGG3.0 アドオン開発マニュアルに記載されている
サンプルアプリケーションについて、インストール方法を中心に説明します。


２．導入手順

 (1)開発者マニュアル 付録Cの記述に従ってサンプルプロジェクトをビルドし、
    アプリケーションサーバーに配備します。

 (2)下記の申請様式を登録します。

     様式コード：9100
     ルート判定条件：区分値
     ルートタイプ：申請

 (3)登録した様式に対して、「決裁」事後処理を登録します。
     実行タイミング：決裁
     処理種別：Java
     クラス名：sample.empaccount.UAP01AfterFlow
     実行区分：実行する

 (4)登録した様式に対して、申請種別を登録します。

     申請種別名称：<任意>
     区分値：1

 (5)提供されているSQL文を実行して、テーブルの作成を行います。

 (6)[システム設定]-[システム共通]-[処理の登録]を利用して、処理を登録します。
   
   処理名：給与振込口座申請
   URL：(URLの前に"/pe4j/"をつける：チェック) UAP/UAP0101e.jsf

 (7)[システム設定]-[システム共通]-[メニューの登録]を利用して、
   登録した処理をメニューに割り当てます。
