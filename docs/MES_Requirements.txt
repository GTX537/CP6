第1章  MES模块总体架构与业务定位
1.1  功能目的
MES模块（MSBBME系列）是CP6系统在ERP销售管理（PA系列）基础上向制造执行层的延伸。ERP负责“卖什么”和“卖给谁”，MES负责“怎么做”和“做得怎么样”。本模块为独立MES原型，先不与mcframe7集成，后续可通过数据库视图或API对接。
1.2  业务流程定位
【ERP 販売管理（既存PA系列）】
  PA010 見積計算書入力 → PA020 一覧 → PA030 御見積書登録
       ↓ 見積確定
  PA050 製品マスタ登録（工程・材料・単価）
       ↓
  PA070 受注入力 → PA080 受注一覧
       ↓ 受注確定
════════════════════════════════════════
【MES 製造執行（新規 ME系列）】
  ME010 生産計画ボード（排程可視化）
       ↓
  ME020 製造指図入力 ← 从PA070受注自動生成 or 手動作成
  ME030 製造指図一覧照会
       ↓ 指図発行
  ME040 製造実績入力（各工程の開始/完了/数量報告）
  ME050 製造実績一覧照会
       ↓ 工程完了
  ME060 品質検査入力
  ME070 品質検査一覧照会
  ME080 不良品管理
       ↓
  ME090 MESダッシュボード（全体可視化）

第2章  MSBBME010 — 生産計画ボード
2.1  功能概述
生産計画ボードは、受注済みの製造指図を工程×時間軸のガントチャートで可視化し、手動で生産順序の調整（ドラッグ＆ドロップ）を行う画面。PA050で定義された生産並び順（製造順優先項目1～8）を初期配置の基準とする。

バー選択時：指図NO/製品名/得意先/納期/進捗率/残数量

6.3  合否自動判定ロジック
IF 上限値 IS NOT NULL AND 下限値 IS NOT NULL THEN
    IF 計測値 >= 下限値 AND 計測値 <= 上限値 THEN 合格
    ELSE 不合格
ELSE IF 規格値 IS NOT NULL THEN
    IF 計測値 = 規格値 THEN 合格 ELSE 不合格
ELSE 手動判定
総合合否 = 全項目が合格 → 合格 / 1項目でも不合格 → 不合格

12.2  PA050仕掛チェック拡張SQL
-- Level MES: MES指図発行済みチェック
SELECT wo.WORK_ORDER_NO
FROM T_WorkOrder wo
WHERE wo.PRODUCT_CD = :productCd
  AND wo.STATUS IN (2, 3, 5)  -- 発行済/着手中/中断中
  AND wo.DEL_FLG = 0
-- → レコードが存在する場合：
--   「MES製造指図が発行済みのため変更できません。」
