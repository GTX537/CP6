## 分层关系（自底向上）

```
CP6.Entity（一）          领域模型 + DTO，全栈数据契约
   ▲
CP6.Core（二~五）         Services 业务逻辑 + EFDbContext/Auth/Utilities/Migrations
   ▲
CP6.WebApi（六~七）        Controllers 暴露 REST + 启动/中间件/SignalR/后台 Worker/种子
   ▲
cp6.web（八~九）          Vue3 前端：views 页面 + api/stores/router/components/i18n
   ─
CP6.Tests（十）           覆盖以上各层的自动化测试
```

本盘点已对每一册做**实文件 ↔ 清单**集合比对（`comm` 双向 diff），确认无遗漏、无失效条目：
