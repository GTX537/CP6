# Space P2.5 货场分析 + 控制塔大屏设计

日期：2026-07-07
状态：用户已拍板（ABC=出入库流水自动算；利用率热力/存储分布/SignalR 推送照总纲；大屏纳入本包）。细 plan 开工令时出。
依据：总纲 Spec §9/§18.3（P2.5 规格已定义）+ 2026-07-07「对标菜鸟」路线第一二步（实时化+控制塔）+ `space3d-gap-analysis-2026-07` 波5 票据池 P2.5 项。

## 1. 目标

把 Space 从"查询式快照"升级为"活的仓库 + 看得出问题的决策层"——对标菜鸟观感差距的两个核心（实时性、控制塔）在本包closing。四个可视化能力 + 一个大屏形态，全部读侧，不动发布闭环。

## 2. 子域 A：库容利用率热力（总纲 §9.7）

- 口径：利用率 = 当前库存量 / 容量；容量取数优先 WMS Bin Capacity、缺省回落 Space Location.Capacity（CapacityUom 必须一致才参与，混单位记 W-SPACE 告警不计入）。
- 聚合三级：库位（着色渐变）→ 货架（均值+超容计数角标）→ 库区（侧栏排行）。
- Viewer 增加模式切换：结构 / 库存状态（P2 已有五态）/ **利用率热力** / **存储类型** / **ABC**——一个模式枚举统一管理，互斥切换。
- 后端：`GET /api/space/floor/{id}/utilization`（复用 IWmsStockQuery 批量查询 + 可见区裁剪口径与 P2 stock-overlay 相同）。

## 3. 子域 B：存储类型分布（总纲 §9.8）

- Zone 类型（Storage/Picking/Receiving/Shipping/Inspection/Return/Frozen/Passage）着色图层 + 侧栏统计（各类型库位数/占比）。
- 纯 Space 侧数据，零 WMS 依赖——本包最轻的子域。

## 4. 子域 C：动销 ABC 分布（拍板：流水自动算）

- 数据源：按时间窗（默认 90 天，可配）聚合 WMS `StockTransaction` 出库行 → 按物料出库量（或频次，口径可切）排序 → 累计占比 80/15/5 划 A/B/C（阈值可配，租户级设置）。
- 展示：①物料 ABC 命中的库位着色（A 红系/B 琥珀/C 灰，与语义色系统区分）②分析侧栏：「A 类物料距出货口平均距离」——用 P5 已有的通行成本/路径能力算距离，直接回答"高频物料是否放对了地方"（总纲 §9.6 的题眼）。
- 计算落地：后台定时任务（每日一算，复用现有 Worker 模式）落 `Space_AbcSnapshot` 结果表；Viewer 读快照不实时算。物料无流水 → 默认 C。

## 5. 子域 D：SignalR 实时着色

- WMS 库存变动（StockMovementService 提交处）→ 经 `ISpaceNotifier`（波4 已建的接口注入模式）→ SpaceHub 推送 `{warehouseCd, locationCode, binStatus}` 增量 → Viewer 订阅后就地重着色（不重拉全楼层）。
- 节流：同库位 2s 合并；楼层不在当前视图则忽略。断线降级回拉取式（P2 现状），不影响浏览。
- **注意**：这是 WMS 侧一行接线 + Space 前端订阅，不是新基建——SpaceHub/事件页自动刷新在波4 已通。

## 6. 子域 E：控制塔大屏

- 新路由 `/space/control-tower/:siteId`（standalone 全屏，照 P1 规范显式登记豁免——大屏挂电视无导航）。
- 布局：左 3D Viewer（自动轮播楼层，可锁定）+ 右侧栏三段：**KPI**（库容利用率/空满比/异常库位数/今日出入库笔数）、**告警流**（发布死信/超容/停用异常/W-SPACE 族——复用事件监视页数据源 + SignalR 推送）、**ABC/热力模式快捷切换**。
- 视觉：**固定深色单主题**（大屏场景的刻意选择）；复用 viewer 深色科幻现状风格，本包不做 Cp* 统一（那是 UI 翻新 SPACE 11 页的事，不混）。
- 权限：`space_viewer:tower` 独立权限点（大屏常用共享账号，单独授权）。

## 7. 横切与错误码

- 全按 `docs/00-横切接线规范.md`；菜单种子（利用率/ABC 入口挂 Viewer 模式无新菜单，大屏登记豁免清单）。
- 错误码：接通总纲已定义未实现的 **W-SPACE-701**（库存叠加查询失败）/ **W-SPACE-702**（未知库位状态），新增 **W-SPACE-703** 容量单位不一致未计入 / **W-SPACE-704** ABC 快照过期（超过 48h 未算）。
- 测试：利用率聚合口径（容量回落/混单位剔除）、ABC 划带（边界 80/95%）、SignalR 增量幂等（重复推送不闪烁——前端测试）、大屏 KPI 查询。
