## 一、上游已锁基线（不翻案，仅引用）

总纲 `docs/space/README.md` 已锁 5 个架构决策，本设计完全继承：

1. **混合分权**：Space 管几何/布局真相，WMS 管库存/业务真相，**库位编码做 join key**。Space 不写库存数量，WMS 不画 3D。
2. **可配置编码引擎**：Space 生成库位编码、发布给 WMS 消费；支持存量客户编码采纳/对账。
3. **v1 = 完整版**：编辑器 + 编码引擎 + 实时库存叠加 + 高级可视化。
4. **多租户 SaaS**：全表 `TenantId`，沿用 CP6 体系。
5. **自底向上分阶段** P1 空间建模底座 → P2 实时数据叠加 → P3 高级可视化。

继承自更早基线：独立 `Space` 命名空间；编辑器 = 模板化生成为主 + 受控自由布局为辅，不做完整自由绘制；CAD 导入推迟二/三期；前端 Three.js；首批客户 = 仓库/WMS 客户。

落点：`CP6.Entity/DomainModels/Space`、`CP6.Core/Services/Space`、`cp6.web/src/views/space`，前端 3D 封装独立 `space-viewer` 层。

## 二、本次分析新锁的增量决策

### 2.1 总纲分叉决策（D1–D5，2026-06-12 brainstorming 拍定）

这 5 条是总纲之外、写细分规格必须先定的落地分叉：

| # | 决策点 | 定论 | 理由 |
|---|---|---|---|
| **D1** | 编辑器交互范式 | **2D 俯视平面图建模** + 3D 只读预览/叠加。受控自由布局（拖拽/旋转/打点/框选）全部在 2D 平面图里做；3D 视口专做浏览 + 库存叠加 + 高级可视化。 | 菜鸟 / SAP EWM 主流做法，2D 对齐精确、风险低；3D 那条线不被编辑交互拖累。 |
| **D2** | 渲染规模基线 | 单仓 **~1 万库位**为 v1 硬基线。一开始就上 **InstancedMesh 实例化 + 视锥剔除 + 拾取**，不走"先朴素后重构"。LOD / 分块按需加载 / Web Worker 留 P3 遇超大客户再加。 | 覆盖绝大多数真实仓库；技术成熟；避免重构弯路。 |
| **D3** | 3D 几何表现来源 | **纯参数化盒体**（程序化几何，零美术素材）。货架 = 模板参数（列×层×深、间距、尺寸）程序化生成。设备模型（叉车/AGV）留 P3 设备联动再增量引入。 | 与"模板化生成 + 编码引擎"同一套参数驱动；InstancedMesh 最顺；彻底免掉素材管线 / 租户素材隔离的二期复杂度。 |
| **D4** | 库位编码身份与重排安全 | 内部恒用 **GUID 稳定主键**；**草稿期编码可反复重排**，**"发布"是冻结闸门**——过闸即冻结，之后只能"新增库位补新码 / 停用库位（保留历史）"，绝不重排已发布编码。**冻结对象是编码与身份，不含几何**：已发布货架/库位的几何（位置/朝向/尺寸）**永远可编辑**（支持仓库改造、货架挪位），挪动时其下库位的缓存绝对坐标自动重算，但 `LocationId` 与编码不变。**纯几何编辑（挪货架/改朝向/改尺寸）不触发 `LocationPublished`**——载荷本就不含几何（见 3.2），WMS 无须同步，故几何永远可动而 join key 不漂移；只有库位增/删/停用、编码变更才发事件。存量客户采纳 = 把现有 WMS 编码导入为"已发布·已冻结"。 | 建模自由度（草稿期）与对外契约稳定（join key 永不漂移）两头都保住；同时现实里货架挪位常见，几何必须可动。 |
| **D5** | 实时库存叠加刷新 | `IWmsStockQuery` 定为"**按库位编码列表批量只读查询**"。**默认按需快照**（打开即查 + 手动刷新）**+ 可选自动刷新间隔**（监控大屏场景）。**不引入 WMS 推送**（SignalR 订阅会让 Space 变 WMS 事件订阅者，破坏已锁的单向依赖）。自动刷新间隔设**下限默认 10s**，单次批量上限按场景可见库位裁剪（配合 06 章视锥/分区，只查可见区库位，避免每轮全仓 1 万次 join）。 | A + 可选轮询都基于同步只读查询，不碰 WMS 推送、不破坏"契约在 Space 侧、单向依赖"。 |

### 2.2 精度补充决策（D6–D8，2026-06-12 评审新增）

写细分规格时发现的跨章节接缝，补锁如下：

| # | 决策点 | 定论 | 理由 |
|---|---|---|---|
| **D6** | 库位停用与库存冲突 | 停用是 Space 侧几何软淘汰，但库存真相在 WMS。规则：**停用前置校验**——经 `IWmsStockQuery` 查得该库位 **0 库存**方可停用；若有库存则拒绝并提示，或降级为"禁止新上架"标记、由 WMS 清空后再停用。停用后保留 WMS 历史。停用为软标记，存在 check→停用 的 **TOCTOU 窗口**（校验后 WMS 刚好上货），WMS 侧消费停用事件时**再次校验库存**兜底。 | 守混合分权：Space 不能单方面制造孤儿库存。 |
| **D7** | 采纳态反向建模 | 存量采纳导入的编码为"已发布·已冻结、**无几何**"。编辑器需支持**反向建模模式**：先摆货架几何，再把格口**绑定到已存在的冻结编码**（而非生成新码）。与"模板生成新码"是并列的两种建模入口。绑定差异（场景有几何无码 / 有码无几何 / 编码冲突）须可视化并支持人工校正。 | 采纳客户的几何要后补，建模方向与新建相反，是独立编辑流程。 |
| **D8** | 物料定位搜索 | 独立功能，非点选捎带。**按库位编码定位 = 纯 Space（P1，06 章）**；**按物料/批次/容器定位 = 经 `IWmsStockQuery` 查命中库位（P2，07 章）**。统一 UX：搜索框 → 命中高亮 → 相机飞行定位 → 多结果列表逐个跳；支持模糊与扫码。 | 头号商用卖点，须独立认领，且跨 P1/P2 两阶段。 |

## 三、技术默认约定（写进 00 / 04 章的硬约束）

需求分析中以合理默认直接定下、用户已认可的技术约定：

### 3.1 坐标系与几何（→ 00 章）
- **每 Floor 一个局部坐标系**，原点取楼层参考角 `(0,0)`；单位 **毫米 (mm)**，整数友好。
- **Z 轴向上**（建筑/仓库惯例：X/Y 为地面、Z 为高度）。`space-viewer` 内部适配 Three.js 的 Y-up，**数据模型不迁就渲染库**。
- **层级跳过 Building**：v1 单建筑，`Site → Floor` 直连；多建筑园区留垂直扩展，届时 `Floor` 改挂 `Building`。00 章须显式声明此简化，避免多建筑客户 Floor 编号撞号。
- **旋转只存绕 Z 的偏航角 `RotationZ`（度）**——货架在 2D 平面图里只做平面旋转，不需四元数。受控自由旋转允许任意角度，`RotationZ` 存**浮点**；模板生成默认 0/90/180/270。
- **Rack `z` 常态为 0**（落地）；夹层走独立 Floor，故 v1 `z` 恒 0，字段保留以备 P3。
- 几何存储：
  - `Space_Zone` = 平面多边形顶点数组（JSON，floor 平面坐标）。
  - `Space_Aisle` = **区域多边形（巷道地面）+ 中心线折线/路径节点（JSON）**。中心线供 08 章拣货路径消费。**Aisle 是 Rack 的可选结构父级**：有巷道时 Rack 挂 Aisle、Aisle 进入发布层级路径（见 3.2）；**无巷道库区（收货区/平铺区）跳过 Aisle**，Rack 直接挂 Zone。故 Aisle 是条件父级，而非必经或仅派生分组。
  - `Space_Rack` = 位置 `(x,y,z)` + `RotationZ` + 模板参数（列×层×深 / 间距 / 尺寸）。**`ZoneId` 必填（Zone 恒为父级），`AisleId` 可选（仅有巷道时挂）**。
  - `Space_Location` = 在货架内的 `(列,层,深)` 索引 → 坐标可推导，另**缓存一份绝对坐标**供拾取 / 叠加 join。**缓存随货架几何变更（移动/旋转/改尺寸）自动重算**（对应 D4：几何可动、编码不变）。

### 3.2 发布给 WMS 的载荷边界（→ 04 章）
- `LocationPublished` 载荷 = 稳定 `LocationId`(GUID) + 库位编码 + 层级路径（Site/Floor/Zone/**[Aisle 可选]**/Rack 各级编码——**无巷道库区跳过 Aisle 段，路径为变长**）+ 库位属性（列/层/深索引、尺寸、承重/容量——若建模）。
- **不含 3D 几何 / 坐标**——几何真相留 Space，WMS 不画 3D（严守混合分权）。
- upsert 按 `LocationId` **幂等**，带**递增版本号**（版本号**按 `LocationId` 维度递增**，WMS 可逐库位检测陈旧更新）。
- **发布粒度**：事件**支持批量**——一次发布一个 Zone/Rack 的成批库位，载荷为库位数组，避免逐条事件风暴；WMS 侧按数组幂等消费。
- 库位生命周期 = **已发布 / 停用**（停用 = 软淘汰，保留 WMS 历史，对应 D4 冻结语义 + D6 停用前置校验：停用须先经 `IWmsStockQuery` 确认 0 库存）。
