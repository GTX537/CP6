# CP6 WMS Space 3D 空间数字底座需求规格说明书

版本：v0.1 草案  
模块：CP6 Space 空间数字底座  
适用系统：CP6 · WMS / Space / PUB / Integration  
技术栈：.NET 8 + EF Core + SQL Server / Vue3 + TypeScript + Konva.js + Three.js  
定位：Space 是独立顶级模块，与 WMS 平级，不是 WMS 内的轻量 3D 页面。

---

## 1. 背景与目标

### 1.1 背景

当前 CP6 已具备 WMS、ERP、MES、OA、PUB 等业务模块能力，但传统 WMS 对仓库空间的表达通常停留在二维表格、库位编码和库存明细层面，缺少统一的空间数字底座，导致以下问题：

1. 仓库、库区、巷道、货架、库位之间的空间关系不够直观。
2. 库位编码、货架布局、容量属性、库存状态之间缺少统一表达。
3. 入库上架、波次拣货、补货、移库、盘点等业务难以直接结合空间位置进行分析。
4. WMS 有库存真相，但缺少空间几何真相；3D 可视化如果直接依赖 WMS 库存表，会导致边界混乱。
5. 多客户部署时，库位编码规则、仓库布局、货架模板差异大，需要可配置、可复制的空间建模能力。

因此，需要建设 CP6 Space 3D 空间数字底座，用于承载仓库空间建模、库位编码、3D 浏览、库存叠加、作业路径和热图展示等能力。

### 1.2 建设目标

Space 3D 的目标不是单纯做一个“3D 仓库页面”，而是建立一套可复用、可配置、可发布给 WMS 的空间数字底座。

核心目标：

1. 建立仓库空间主数据模型：Site / Floor / Zone / Aisle / Rack / Location。
2. 支持通过模板化方式快速生成货架和库位。
3. 支持受控自由布局：拖拽、旋转、捕捉、碰撞提示。
4. 支持可配置库位编码引擎，生成可发布给 WMS 的库位编码。
5. 支持将库位目录发布给 WMS，并由 WMS 建立或关联库位。
6. 支持 3D 浏览、库位搜索、点击详情、楼层切换。
7. 支持从 WMS 只读查询库存状态并叠加到 3D 场景。
8. 支持后续扩展拣货路径动画、作业热图、设备设施占位。
9. 支持多租户、权限、审计、事件、错误码和验收闭环。

## 2. 对标产品分析

### 2.1 菜鸟空间 3D 可视化能力拆解

对标方向不是照搬页面，而是抽象其产品能力。可拆为以下几类：

| 能力 | 说明 | 本系统处理方式 |
|---|---|---|
| 空间建模 | 仓库、库区、货架、库位建模 | P1 必做 |
| 地图编辑器 | 支持拖拽、批量生成、布局调整 | P1 必做 |
| 库位编码 | 支持批量编码、规则化编码 | P1 必做 |
| 3D 可视化 | 展示仓库、货架、库位、状态 | P1 必做 |
| 库存叠加 | 展示空、满、锁定、在拣等状态 | P2 必做 |
| 货场分析 | 库存分布、SKU 分布、库容利用率 | P2 / P2.5 |
| 作业可视化 | 拣货路径、作业热图 | P3 |
| 设备联动 | AGV、输送线、设备点位 | v1 仅占位，P3+ |
| 人员定位 | 人员分布、人员轨迹 | 不做 |

### 2.2 本系统实现边界

本系统采用“Space 与 WMS 混合分权”的设计：

| 领域 | 真相源 | 说明 |
|---|---|---|
| 空间几何 | Space | 仓库、楼层、库区、巷道、货架、库位坐标 |
| 库位编码 | Space | Space 生成，发布给 WMS |
| 库位目录 | Space → WMS | WMS 消费 Space 发布的库位目录 |
| 库存数量 | WMS | Space 不写库存 |
| 库存状态 | WMS | Space 只读查询后叠加显示 |
| 作业单据 | WMS | Space 只读消费任务结果 |
| 3D 展示 | Space | 基于 Space 几何和 WMS 数据叠加 |

关键原则：

1. Space 不持有库存业务真相。
2. WMS 不持有空间几何真相。
3. Space 通过发布契约向 WMS 输出库位目录。
4. Space 通过只读查询契约向 WMS 获取库存状态。
5. 多仓场景下 join key 使用 `WarehouseCd + LocationCode`。
6. 发布后库位编码冻结，几何可以继续调整。

### 2.3 MVP 与非目标范围

#### MVP 范围

P1 MVP 必须完成：

1. 空间数据模型。
2. 2D 建模编辑器。
3. 模板化生成货架和库位。
4. 受控自由布局。
5. 可配置库位编码。
6. 发布库位目录到 WMS。
7. 3D 结构浏览。
8. 按库位编码定位。
9. 多租户、权限、菜单、DI 接入。

#### 非目标范围

以下内容不进入 MVP：

| 能力 | 结论 |
|---|---|
| 人员实时定位 | 不做 |
| 人员轨迹回放 | 不做 |
| 人员分布热力图 | 不做 |
| 人员排班 / 调度 | 不做 |
| CAD 自动解析 | P3+ |
| 完整自由绘制 | P3+ |
| 真实 IoT 设备实时联动 | P3+ |
| AGV 实时调度 | 不做或 P3+ |
| WMS 库存写入 | 不做 |
| WMS 库存事务处理 | 不做 |
| 高精度数字孪生仿真 | 不做 |

## 3. 产品定位

### 3.1 Space 3D 不是页面，而是空间数字底座

Space 3D 不是一个单独的 3D 页面，而是一套独立的空间数字底座，包含：

1. 空间对象模型。
2. 空间坐标体系。
3. 货架和库位几何。
4. 库位编码规则。
5. 库位发布契约。
6. 3D 可视化内核。
7. WMS 库存叠加契约。
8. 作业路径和热图展示能力。
9. 多租户、权限、审计和运维能力。

Space 作为 CP6 的独立顶级模块，与 WMS 平级。WMS 使用 Space 发布的库位目录，但不直接管理空间几何。

### 3.2 与 WMS 入库 / 出库 / 波次 / 盘点的关系

Space 与 WMS 的关系如下：

| WMS 业务 | Space 提供能力 |
|---|---|
| 入库上架 | 提供库位目录、库位状态、容量属性、3D 定位 |
| 出库拣货 | 提供库位定位、路径展示、库位高亮 |
| 波次拣货 | 提供波次涉及库位的 3D 高亮和路径动画 |
| 补货 | 展示来源库位和目标库位空间关系 |
| 移库 | 校验目标库位是否可用、是否冻结、是否存在库存冲突 |
| 盘点 | 按库区、货架、巷道、楼层形成盘点范围 |
| 库存查询 | 通过 3D 场景展示库存所在库位 |
| 异常处理 | 展示超容、冻结、同步失败、路径不连通等异常 |

## 4. 业务角色

### 4.1 仓库管理员

职责：

1. 创建和维护仓库空间结构。
2. 配置库区、货架、库位。
3. 设置库位类型、容量、状态。
4. 维护编码规则。
5. 执行库位发布。
6. 处理空间异常和发布异常。

典型操作：

1. 新建仓库楼层。
2. 批量生成货架。
3. 批量生成库位编码。
4. 发布库位到 WMS。
5. 停用库位。
6. 查看 3D 空间结构。

### 4.2 库管员

职责：

1. 查看库位状态。
2. 查看库存分布。
3. 查询 SKU 所在库位。
4. 辅助上架、移库、盘点。
5. 查看异常库位。

典型操作：

1. 输入库位编码定位。
2. 点击库位查看库存。
3. 按库区筛选库存。
4. 查看空库位、满库位、冻结库位。

### 4.3 拣货员

职责：

1. 查看拣货任务涉及库位。
2. 辅助确认拣货路径。
3. 查看波次库位高亮。
4. 查看拣货库位详情。

说明：

本系统不做人实时定位，也不记录拣货员轨迹。拣货路径动画基于 WMS 波次任务中的库位序列和 Space 巷道中心线生成，不代表真实人员移动轨迹。

### 4.4 运营主管

职责：

1. 查看仓库空间利用情况。
2. 查看库存分布和作业热图。
3. 查看异常和告警。
4. 分析库区使用效率。
5. 评估仓库布局合理性。

典型操作：

1. 查看库存热力。
2. 查看库容利用率。
3. 查看作业频次热图。
4. 查看异常库位列表。

### 4.5 系统调度逻辑

职责：

1. 为 WMS 提供库位目录。
2. 支持 WMS 上架、拣货、盘点等业务调用。
3. 支持 Space 与 WMS 的事件和查询契约。
4. 保证发布、同步、停用、库存叠加的幂等和一致性。

## 5. 空间对象模型

### 5.1 Warehouse / Site

仓库或站点，是 Space 的顶层空间对象。

关键字段：

| 字段 | 说明 |
|---|---|
| Id | 主键 |
| TenantId | 租户 |
| SiteCode | 仓库 / 站点编码 |
| SiteName | 名称 |
| WarehouseCd | 对应 WMS 仓库编码 |
| Status | 状态 |
| Remark | 备注 |

规则：

1. 同租户下 `SiteCode` 唯一。
2. `SiteCode` 与 WMS `WarehouseCd` 需要建立映射。
3. Space 发布库位到 WMS 时必须带 `WarehouseCd`。

### 5.2 Zone

库区，表示一个仓库楼层内的逻辑区域。

常见类型：

| 类型 | 说明 |
|---|---|
| Storage | 存储区 |
| Picking | 拣选区 |
| Receiving | 收货区 |
| Shipping | 发货区 |
| Inspection | 质检区 |
| Return | 退货区 |
| Frozen | 冻结区 |
| Passage | 通道区 |

规则：

1. Zone 必须属于某个 Floor。
2. Zone 可以有多边形几何。
3. Rack 必须归属某个 Zone。
4. Zone 删除时，如果存在已发布库位，应阻断删除。

### 5.3 Aisle

巷道，表示货架之间的通行路径。

关键能力：

1. 可选对象，不是所有库区都必须有 Aisle。
2. 支持中心线 Centerline。
3. P3 拣货路径动画使用 Aisle 中心线计算路径。
4. 无巷道库区可跳过 Aisle 段，编码引擎需要支持变长路径。

### 5.4 Rack

货架，是承载库位的核心几何对象。

关键字段：

| 字段 | 说明 |
|---|---|
| RackCode | 货架编码 |
| ZoneId | 所属库区 |
| AisleId | 所属巷道，可空 |
| TemplateId | 货架模板 |
| X / Y / Z | 坐标 |
| RotationZ | 平面旋转角 |
| Cols | 列数 |
| Levels | 层数 |
| DepthCount | 深度数 |
| Status | 状态 |

规则：

1. Rack 通过模板批量生成。
2. Rack 可在 2D 编辑器中拖拽和旋转。
3. Rack 几何变化后，Location 绝对坐标由服务端重算。
4. 已发布库位的编码不因 Rack 几何移动而变化。

### 5.5 Bay

Bay 表示货架列或货架格口组，可作为逻辑层级使用。

说明：

1. v1 可不单独落独立表，可由 Rack + ColIndex 表达。
2. 如果客户需要按货架列管理，可在 Location 中保留 ColIndex。
3. 编码规则可使用 Bay / ColIndex 作为编码段。

### 5.6 Level

Level 表示货架层。

说明：

1. v1 可不单独落独立表，可由 Rack + LevelIndex 表达。
2. Location 必须记录 LevelIndex。
3. 编码规则可使用 LevelIndex 作为编码段。
4. 3D 渲染时 LevelIndex 决定 Z 轴高度。

### 5.7 Location

Location 是最小库存位置，是 Space 与 WMS 之间的核心业务对象。

关键字段：

| 字段 | 说明 |
|---|---|
| LocationId | 稳定 GUID 主键 |
| LocationCode | 库位编码，发布后冻结 |
| WarehouseCd | WMS 仓库编码 |
| RackId | 所属货架 |
| FloorId | 所属楼层 |
| ColIndex | 列 |
| LevelIndex | 层 |
| DepthIndex | 深度 |
| AbsX / AbsY / AbsZ | 绝对坐标缓存 |
| Status | 草稿 / 已发布 / 停用 |
| CodeOrigin | 引擎生成 / 外部采纳 |
| Placed | 是否已放置到货架 |
| Capacity | 容量 |
| CapacityUom | 容量单位 |

规则：

1. `LocationId` 终生稳定。
2. `LocationCode` 发布后冻结。
3. `LocationCode + WarehouseCd` 是 WMS 关联锚点。
4. Space 只发布库位目录，不发布几何。
5. WMS 持有库存真相，Space 不写库存数量。
6. 已有库存的库位不能停用。

### 5.8 Device / Facility

设备设施对象用于展示仓库中的设备、工作台、月台、门、输送线等。

v1 范围：

1. 支持设备设施静态占位。
2. 支持在 3D 场景中展示设备图元。
3. 支持接口预留。
4. 不接真实 IoT 实时流。
5. 不做 AGV 实时调度。

对象示例：

| 对象 | 说明 |
|---|---|
| Dock | 月台 |
| Door | 门 |
| Workstation | 工作台 |
| Conveyor | 输送线 |
| Camera | 摄像头 |
| Sensor | 传感器 |
| AGV | AGV，占位 |
| Forklift | 叉车，占位 |

## 6. 空间建模方式

### 6.1 手工建模

支持用户通过表单或编辑器手工创建：

1. Warehouse / Site。
2. Floor。
3. Zone。
4. Aisle。
5. Rack。
6. Location。
7. Marker / Device。

手工建模用于小规模仓库、修正导入结果或补充特殊区域。

### 6.2 Excel 导入

支持通过 Excel 导入库位和空间主数据。

导入内容：

1. 库区。
2. 货架。
3. 库位。
4. 库位编码。
5. 容量。
6. 库位类型。
7. 状态。
8. WMS 既有码。

规则：

1. 导入前进行格式校验。
2. 导入时校验编码唯一性。
3. 已发布库位不允许通过导入重建 `LocationId`。
4. 存量客户可通过“采纳模式”绑定既有 WMS 编码。

### 6.3 地图编辑器

地图编辑器是 P1 的主要建模入口。

能力：

1. 2D 俯视画布。
2. 底图描图。
3. 网格吸附。
4. 模板化货架生成。
5. 受控自由布局。
6. 属性面板。
7. 草稿保存。
8. 发布前预检。

### 6.4 CAD 解析，后期

CAD 自动解析不进入 P1。

后期目标：

1. 上传 CAD 图纸。
2. 自动识别墙体、区域、通道、货架。
3. 转换为 Space 几何对象。
4. 允许人工修正。
5. 发布为 Space 场景。

阶段：P3+。

## 7. 地图编辑器

### 7.1 画布

画布使用 2D 俯视建模。

要求：

1. 支持缩放、平移。
2. 支持网格显示。
3. 支持底图显示。
4. 支持图层显示。
5. 支持坐标从屏幕像素转换为数据 mm。
6. 支持保存前校验。

### 7.2 拖拽

支持拖拽对象：

1. Rack。
2. Zone，P1 可限制整体移动。
3. Marker。
4. Device / Facility，占位。

拖拽规则：

1. 支持网格吸附。
2. 支持货架边缘吸附。
3. 支持越界提示。
4. 支持碰撞提示。
5. 越界和碰撞 P1 只提示，不强制阻断。
6. 发布时由硬闸门校验关键规则。

### 7.3 批量生成

支持模板化批量生成：

1. 选择货架模板。
2. 设置行、列、层、深度。
3. 设置间距。
4. 设置起始坐标。
5. 一次生成 Rack + Location。
6. 生成后 LocationCode 为空，交由编码引擎生成。

### 7.4 批量编码

批量编码由编码引擎负责，不在编辑器直接写死规则。

要求：

1. 支持规则预览。
2. 支持按楼层 / 库区 / 货架范围生成。
3. 支持编码冲突预检。
4. 支持草稿重排。
5. 已发布库位不允许重编码。
6. 采纳码不参与自动重编码。

### 7.5 属性编辑

支持编辑：

1. Zone 类型。
2. Rack 尺寸、列数、层数、深度。
3. Location 类型。
4. Location 容量。
5. Location 状态。
6. Marker 文本。
7. Device / Facility 类型。

关键规则：

1. 已发布 LocationCode 不允许修改。
2. 已发布库位纯几何调整不触发 WMS 发布。
3. 层级路径或业务属性变更需要重新发布。
4. 有库存库位停用需要 WMS 同步确认。

### 7.6 版本发布

P1 暂不做完整地图版本管理，但需要支持：

1. 草稿保存。
2. 发布前预检。
3. 发布库位目录到 WMS。
4. 发布后冻结编码。
5. 发布失败支持重试和死信。
6. 未来可扩展地图版本：Draft / Published / Archived。

## 8. 3D 可视化

### 8.1 2D / 3D 切换

P1 支持：

1. 2D 编辑器用于建模。
2. 3D Viewer 用于只读浏览。
3. 二者不共享前端渲染对象，只共享后端场景数据。
4. 3D 不承担编辑职责。

### 8.2 视角控制

支持：

1. 旋转。
2. 平移。
3. 缩放。
4. 俯视视角。
5. 侧视视角。
6. 复位视角。
7. 聚焦选中对象。

### 8.3 库位搜索

支持按库位编码搜索。

流程：

1. 用户输入 `LocationCode`。
2. 系统查询 Location 所在楼层、货架、坐标。
3. 如果不在当前楼层，先切换楼层。
4. 3D 相机飞到目标库位。
5. 高亮闪烁目标库位。
6. 展示库位详情。

### 8.4 点击详情

用户点击库位后展示：

1. LocationCode。
2. WarehouseCd。
3. Zone。
4. Aisle。
5. Rack。
6. Col / Level / Depth。
7. 状态。
8. 容量。
9. WMS 库存状态，P2。

## 9. 货场可视化

说明：本章只做“货”和“场”的可视化，不做“人”的定位和轨迹。

### 9.4 库存分布

目标：

1. 按楼层查看库存状态。
2. 按库区查看库存分布。
3. 按货架查看库存密度。
4. 按库位查看空 / 满 / 锁定 / 在拣状态。

数据来源：

1. Space 提供空间结构。
2. WMS 提供库存状态和数量。
3. 前端通过 `WarehouseCd + LocationCode` 叠加。

### 9.5 SKU 属性分布

支持按 SKU / 物料查询其所在库位。

能力：

1. 输入 SKU / 物料编码。

3. Space 定位对应库位。
4. 3D 高亮所有命中库位。
5. 支持点击查看库存详情。

后期可扩展：

1. 批次。
2. 容器。
3. 客户。
4. 货主。
5. 温区属性。
6. 危险品属性。

### 9.6 动销 ABC 分布

目标：

1. 展示 A / B / C 类物料在仓内分布。
2. 分析高频物料是否靠近拣货区或出库口。

阶段：

1. P2.5 支持静态导入或 WMS 查询。
2. P3 支持结合出入库流水自动计算。
3. 不进入 P1。

### 9.7 库容利用率

目标：

1. 展示库位利用率。
2. 展示货架利用率。
3. 展示库区利用率。
4. 发现低利用率区域和超容区域。

计算方式：

1. 优先使用 WMS 返回 Capacity。
2. 如 WMS 无 Capacity，使用 Space Location 容量。
3. 利用率 = 当前库存量 / 容量。
4. 容量单位必须明确，避免重量、体积、数量混用。

阶段：

1. P2 支持状态着色。
2. P2.5 支持利用率热力。

| 发货暂存 | Shipping |
| 质检位 | Inspection |
| 退货位 | Return |

## 10. WMS 业务联动

### 10.1 入库上架

Space 提供：

1. 已发布库位目录。
2. 库位类型。
3. 库位容量。
4. 库位状态。
5. 3D 定位。

WMS 负责：

1. 入库单。
2. 上架策略。
3. 库存写入。
4. 批次和容器管理。

联动方式：

1. WMS 根据 Space 发布的库位目录建立 Bin。
2. WMS 上架时可参考库位类型和容量。
3. Space 可显示上架目标库位。
4. Space 不执行库存写入。

### 10.2 波次拣货

Space 提供：

1. 波次涉及库位高亮。
2. 按库位编码定位。
3. 拣货路径动画，P3。
4. 跨库区可视化提示，P3。

WMS 提供：

1. 波次单。
2. 拣货任务。
3. 拣货顺序。
4. SKU 和数量。

说明：

拣货路径动画基于 WMS 拣货任务中的库位序列，不代表真实人员轨迹。

### 10.3 补货

Space 提供：

1. 来源库位和目标库位定位。
2. 存储位到拣货位空间关系展示。
3. 补货前后库存状态变化展示。

WMS 负责：

1. 补货任务生成。
2. 补货数量。
3. 库存扣减和增加。

### 10.4 移库

Space 提供：

1. 目标库位是否存在。
2. 目标库位是否已发布。
3. 目标库位是否停用。
4. 目标库位是否冻结。
5. 目标库位容量属性。

WMS 负责：

1. 移库单。
2. 库存转移。
3. 批次和容器更新。

### 10.5 盘点

Space 提供：

1. 按楼层生成盘点范围。
2. 按库区生成盘点范围。
3. 按巷道生成盘点范围。
4. 按货架生成盘点范围。
5. 3D 高亮盘点区域。

WMS 负责：

1. 盘点单。
2. 账面库存。
3. 实盘数量。
4. 差异处理。

### 10.6 库存查询

Space 提供：

1. 3D 查询入口。
2. 按库位查看库存。
3. 按物料定位库位。
4. 选中信息卡展示库存状态。

WMS 提供：

1. 库存数量。
2. SKU。
3. 批次。
4. 容器。
5. 锁定状态。
6. 在拣状态。

### 10.7 异常处理

异常类型：

| 异常 | 处理 |
|---|---|
| 库位已停用但 WMS 仍有库存 | 阻断停用，提示异常 |
| Space 已发布但 WMS Bin 不存在 | 告警，支持重发 |
| WMS 库存查询失败 | 使用上次快照或显示不可用 |
| 编码冲突 | 阻断生成或发布 |
| 路径不连通 | 降级直连并提示 |
| WebGL 不可用 | 降级提示 |
| 已发布库位路径陈旧 | 提示需要重新发布 |
