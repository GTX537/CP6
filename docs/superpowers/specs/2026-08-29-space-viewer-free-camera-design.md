## 目标

解除 Viewer 只能围绕仓库固定中心旋转和缩放的限制。用户应能把任意区域移动到观察中心，并直接放大鼠标所指向的货架，同时保留现有预设视角、选中聚焦和楼层切换能力。

## 用户交互合同

- 左键拖动：围绕当前观察目标旋转。
- 右键拖动：同时平移相机与观察目标，使任意仓库区域可成为新的画面中心。
- 鼠标滚轮：以鼠标指针方向缩放，不再固定朝仓库原点缩放。
- 双击货架区域内可拾取的库位：沿用既有拾取链选中该库位并平滑聚焦。
- 触控：单指旋转，双指缩放和平移。
- 手动开始旋转、平移或缩放时，立即取消正在执行的预设视角或聚焦飞行动画，确保用户输入拥有最高优先级。
- Home、俯视、等轴、正视、整层概览和投影切换保持现有语义；执行这些命令时可重新设置观察目标。

页面在不遮挡场景的位置显示简短提示：`左键旋转 · 右键平移 · 滚轮指向缩放 · 双击聚焦`。画布的辅助技术说明同步包含鼠标和键盘操作。

## 技术设计

### 相机控制层

在 `CameraController` 中集中配置 Three.js `OrbitControls`：

- 明确启用平移和屏幕空间平移。
- 启用 `zoomToCursor`，让透视相机沿鼠标指针方向缩放。
- 明确绑定左键旋转、中键缩放、右键平移。
- 明确绑定单指旋转、双指缩放和平移。
- 监听控制器 `start` 事件并清除当前 `flyTo` 状态，避免动画与手动输入争夺相机。
- 保留现有距离、阻尼和极角限制，避免穿过场景或翻转到地面下方。

相机控制逻辑继续封装在 `CameraController` 内，不在 Vue 页面重复维护三维数学或鼠标状态。

### Viewer 页面层

`FloorViewer` 只负责展示操作提示和辅助技术文案。现有点击、双击拾取、工具栏和快捷键事件不改变。右键拖动期间禁止浏览器上下文菜单，避免打断平移操作。

### 数据流

1. 用户在 Canvas 上开始鼠标或触控操作。
2. `OrbitControls` 发出 `start`，`CameraController` 取消未完成的 `flyTo`。
3. `OrbitControls` 根据固定映射更新相机位置和观察目标。
4. `change` 事件沿用现有 `requestRender`，触发按需渲染、LOD、视锥裁剪和标签更新。
5. 库存、任务、人员和设备 Runtime 数据不参与相机控制，不新增后端或数据库变更。

## 边界与失败处理

- 鼠标位于场景空白区域时，原生指针缩放仍沿当前鼠标射线工作，不引入额外货架射线检测。
- 相机仍受最小/最大距离限制，不允许无限穿透或离开可用范围。
- 楼层切换继续执行 Home 复位，避免把上一楼层的观察目标错误带到新楼层。
- 无 WebGL、场景加载失败和 Runtime 数据不可用仍沿用现有错误处理，不由本任务改变。
- 不实现第一人称行走、碰撞检测、相机书签、自动巡航或自定义键位。

## 测试设计

### 自动化

- 控制器配置测试：平移、屏幕空间平移、指针缩放和鼠标/触控映射符合合同。
- 手动接管测试：存在活动 `flyTo` 时触发控制器 `start`，后续更新不再把相机拉回动画目标。
- 现有缓动、聚焦、预设视角和 Viewer 测试继续通过。
- 执行 Vue type-check、相关 Vitest 和生产构建。

### 浏览器验收

在本地 `CP6DB` 的两层、10,000 库位 Published 场景中验证：

1. 把鼠标移到画面左上区域的货架并滚轮放大，该区域持续留在指针附近且明显变大。
2. 右键拖动后仓库中心离开画面中心，松开后可继续围绕新观察点旋转。
3. 双击货架区域内的可拾取库位可选中并聚焦。
4. 在预设视角飞行动画过程中开始拖动，手动视角立即接管且不回弹。
5. Home 可恢复默认视角；F1/F2 切换后交互仍正常。
6. 浏览器控制台无新增错误，场景与 Runtime 请求无新增失败。

## 验收标准

- 用户无需先把目标货架移动到仓库原中心，即可直接对其缩放。
- 平移后的旋转中心随观察目标移动，不再固定为世界原点。
- 所有既有 Viewer 入口和快捷键保持可用。
- 10,000 库位场景不新增逐滚轮实例射线检测，维持现有性能边界。
- 自动化门禁和真实浏览器验收全部通过。
