# 单点登录（SSO / OIDC）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在已加固的自研认证（#1）之上叠加 SSO——**CP6 作 SP，OIDC 单协议（Authorization Code + PKCE）消费外部 IdP**，按租户配置 IdP + JIT 自动供给 + 并存/按租户强制/break-glass + SSO 跳过 CP6 2FA + 复用现有会话签发，全栈 + 五语 + gstack QA。

**Architecture:** 方案 = ①新实体 `Sys_TenantSsoConfig : BaseTenantEntity`（每租户一行 OIDC 配置，ClientSecret 经 DataProtection 加密列）+ `Sys_User` 加 3 字段（联邦身份链 `ExternalSubject`/`ExternalProvider` + break-glass `AllowPasswordFallback`）；②state/nonce/PKCE 暂态走 `IDistributedCache`（不建表，一次性）；③3 个单一职责服务（`ITenantSsoConfigService` 配置 CRUD+密钥边界 / `ISsoStateStore` 暂态 / `ISsoService` 编排）+ 2 个可注入 seam（`IOidcDiscovery` 拉 discovery/签名键、`ISsoTokenClient` 换码）令验证可单测；④AuthController 加 `/auth/sso/authorize`+`/auth/sso/callback`(302 流) + `/auth/profile`(落地拿菜单) + 密码 Login 强制 SSO 拦截；⑤租户配置管理端点 + 权限点 + 五语 + 前端登录/落地/配置屏。命名空间 **Sys**，错误码 **E-SEC-020~029**，审计事件 **15~18**。**自洽不硬依赖 #2 2FA**（spec §11 R1）。所有约束对齐 spec §1 现状锚点（已经 3 个只读 subagent 核验实代码）。

**Tech Stack:** .NET 8 + EF Core 8 / `Microsoft.IdentityModel.Protocols.OpenIdConnect`（**新增**，OIDC discovery `ConfigurationManager<OpenIdConnectConfiguration>`，spec R2）/ `System.IdentityModel.Tokens.Jwt`（v8.17.0 已引，验 ID Token）/ `IDataProtectionProvider`（**显式 `AddDataProtection()`**，ClientSecret 加密，R7）/ `IHttpClientFactory`（命名 client `"sso"` 换码）/ `IDistributedCache`（已配，state/nonce/PKCE）/ xUnit + EF InMemory / Vue 3.5 + element-plus + vue-i18n + axios。源 spec：`docs/superpowers/specs/2026-06-22-sso-design.md`（定稿 `22950b8`）。

### 关键类型签名（跨 Task 一致，勿改名）
```csharp
// CP6.Entity/DomainModels/Sys/Sys_TenantSsoConfig.cs  (: BaseTenantEntity)  —— 每租户一行
//   Authority/ClientId[Required] · ClientSecretProtected?(密文) · Scopes="openid email profile" · EmailClaim="email"
//   Enabled · Enforced · AutoProvision=true · DefaultRoleId?(AutoProvision 时必填,R5)
// Sys_User 加 3 字段：ExternalSubject?[200] · ExternalProvider?[300] · AllowPasswordFallback(bool)

// CP6.Core/Services/Sys
public interface ITenantSsoConfigService {
    Task<Sys_TenantSsoConfig?> GetByTenantIdAsync(Guid tenantId);     // IgnoreQueryFilters
    Task<Sys_TenantSsoConfig?> GetByTenantCodeAsync(string tenantCode);
    Task UpsertAsync(Guid tenantId, SsoConfigInput input);            // ClientSecret 空=不改;非空=Protect 覆盖
    string DecryptClientSecret(Sys_TenantSsoConfig cfg);             // 仅内部供 SsoService;密钥不出边界
}
public record SsoConfigInput(string Authority,string ClientId,string? ClientSecret,string Scopes,string EmailClaim,
                             bool Enabled,bool Enforced,bool AutoProvision,int? DefaultRoleId);

public interface ISsoStateStore {                                    // IDistributedCache 一次性
    string Create(Guid tenantId,string nonce,string codeVerifier,string? returnUrl);   // 返 state
    SsoState? Get(string state);
    void Consume(string state);                                      // = Remove
}
public record SsoState(Guid TenantId,string Nonce,string CodeVerifier,string? ReturnUrl);

public interface IOidcDiscovery { Task<OidcEndpoints> GetAsync(string authority); }    // seam:可注入(测试免连 IdP)
public record OidcEndpoints(string AuthorizationEndpoint,string TokenEndpoint,string Issuer,
                            System.Collections.Generic.ICollection<Microsoft.IdentityModel.Tokens.SecurityKey> SigningKeys);

public interface ISsoTokenClient {                                   // seam:换码(测试注假 id_token)
    Task<string?> ExchangeCodeForIdTokenAsync(OidcEndpoints ep,Sys_TenantSsoConfig cfg,string clientSecret,
                                              string code,string codeVerifier,string redirectUri);  // 返 id_token;失败 null
}

public interface ISsoService {
    Task<string> BuildAuthorizeUrlAsync(string tenantCode,string redirectUri,string? returnUrl);    // 返完整 authorize URL
    Task<Sys_User> HandleCallbackAsync(string code,string state,string redirectUri);                 // 验+映射/JIT,返已登用户
}

// SecurityOptions 加根 Sso
public class SsoOptions {
    public int StateMinutes{get;set;}=10; public string CallbackPath{get;set;}="/api/auth/sso/callback";
    public string PostLoginRedirect{get;set;}="/sso/landing"; public int HttpTimeoutSeconds{get;set;}=15;
    public string? PublicBaseUrl{get;set;} public string? FrontendBaseUrl{get;set;}
}
// SecurityEventType 追加：SsoLoginSuccess=15, SsoLoginFailed=16, SsoUserProvisioned=17, SsoConfigChanged=18
```
