# WFS 审批工作流 培训手册（用户册 + 管理员册） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐 Task 执行。步骤用复选框（`- [ ]`）跟踪。本计划是**文档波**（无 spec，无产品代码）：每个 Task 产出一章手册正文，**照本计划已写死的章节大纲逐节填肉**（大纲即小节标题 + 要点清单，均写实，非「待补」）。**唯一允许的占位符** = 截图占位约定 `[截图: 场景描述]`（格式统一，执行时补图），除此之外禁任何 `TODO`/`待补`/空节。

**Goal:** 为 WFS 电子审批工作流出两册**最详细用户操作培训手册**，纳入既有 `docs/manuals/user-training/` 体系（现有 6 册：销售/MES/WMS/采购/财务/闭环集成）：
- **用户册**（`11-WFS审批流程-最详细用户操作培训手册.md`）：面向发起人/审批人/抄送人——发起（含草稿暂存）/待办办理（同意·驳回·退回三目标·加签·委派·转交）/抄送/收藏与偏好（通知设定矩阵·rowMode·pageSize）/移动端/稟議書打印。
- **管理员册**（`12-WFS审批流程管理-最详细用户操作培训手册.md`）：面向流程设计者/运维——设计器双模式（图形·状态机）/审批人八策略 + When/Filter/会签串签/网关（并行·inclusive·剪枝）/serviceTask 三 kind/子流程/触发器三型/连接器（租户级 + 密钥）/工作日历/版本发布与 diff/驾驶舱（检索·job 运维·干预四动作·分析）/权限点清单。

**Architecture:** 两册**照抄既有体例**（范本 = `docs/manuals/user-training/03-库存物流WMS-...md` / `04-采购管理-...md`）：册头三块引用（作用/基准/在闭环中的位置）→ §0 培训样例数据（表）→ §1 模块业务定位 → §2 适用角色与职责（角色表）→ §3 模块完整业务流程（mermaid）+ §3.1 跨模块接缝 → §4 菜单页面总览（页表）→ §5 逐页/逐功能详细操作说明（核心页 14 小节含 `5.x.1a~1e` 增强块，`5.x.1e` = 详细操作场景 SOP，`5.x.13` = 标准操作步骤）→ §6 模块级业务场景（≥5）→ §7 测试矩阵 + §7.1 可执行用例（≥10）→ §8 验收标准（表）→ §9 术语 → §10 待业务确认 → §11 代码与文档来源 → §12 待补清单 → §13 培训讲解脚本（90~110 分钟，分阶段表）→ 最后更新来源。每章 = 一个 Task；本计划为每章写死小节标题 + 要点清单，执行者照纲填肉 + 补 `[截图: 场景描述]`。

**Tech Stack:** 纯 Markdown 文档；mermaid 流程图（§3）；表格化 SOP/角色/页面/测试/验收；无代码、无测试、无构建。语言与语种见下「体例结论」。
