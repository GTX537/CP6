# Space Design API v1 TypeScript client

`spaceDesignV1Client.ts` is generated from the authoritative Design API
OpenAPI document. Do not edit it by hand.

From the repository root:

```powershell
./tools/generate-space-design-sdk.ps1
./tools/generate-space-design-sdk.ps1 -Check
```

The generated client uses the Fetch API. Pass an authenticated `fetch`
implementation or the browser global through the generated constructor.
