# GR-VP T7：部署与一般用户端到端冒烟

状态：已执行

## 目标

在 T6 合入 `main` 后，从干净提交构建并部署 API/Web 镜像，验证标准一般用户角色的菜单、动作、后端权限闸和工作流归属闸。

## 验收项

1. T6 以 no-ff 合入并推送 `main`。
2. API 由 Release publish 产物构建，镜像不包含 Local/Development 配置。
3. Web 从干净 `main` 生产构建，不带入并行菜单设计改动。
4. 对当前租户注册表中的全部启用租户核对 RoleId=10、4 菜单、8 动作和 admin 零扰动。
5. `qa_general` 登录后只有 4 个 OA 菜单和 8 个精确动作。
6. 一般用户本人待办审批成功；他人待办被归属闸拒绝；无权批量转交返回 403。
7. 测试流程实例与临时流程定义清理，保留 `qa_general` 常驻测试用户。
8. HTTP、容器状态与 API 错误日志检查通过，更新项目记忆并推送 `main`。

## 环境约束

权威计划按“四租户”编写，但当前恢复的 `CP6DB.Sys_Tenants` 仅注册并启用 `DEFAULT/A1`。本任务验证全部现存租户，不创建虚构的 B1/C1/D1；跨租户种子语义由 `StandardRoleSeedTests` 的多租户场景继续兜底。
